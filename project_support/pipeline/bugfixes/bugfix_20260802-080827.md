# Bugfix: M46-SHC config not found on remote (parent vs submodule path mismatch)

- **时间**: 2026-08-02 08:03
- **实验**: M46-SHC
- **错误类型**: FileNotFoundError (deployment path mismatch)
- **错误日志摘要**:
  ```
  FileNotFoundError: file `/data/songcl/Project/Cluster_project/Cluster/configs/Quard/shc/model_base1_quard2_c2f_enc_lite_posA_l1_shc.yaml` not exist or is a directory
  ```
- **根因**: tick#239 commit ae5ae06cf placed SHC config+model under parent repo path `cluster_project/configs/Quard/shc/` and `cluster_project/framework/model/Quard_model/...` instead of Cluster submodule path `cluster_project/Cluster/configs/Quard/shc/`. Remote sync (`sync_model.sh`) transfers files inside the Cluster/ submodule, so the parent-level files were never deployed to server-4.

- **修复**:
  ```bash
  # Copy files into submodule boundary
  cp -r cluster_project/configs/Quard/shc cluster_project/Cluster/configs/Quard/shc
  cp -r cluster_project/framework/model/Quard_model/model_base1_quard2_c2f_enc_lite_posA_l1_shc \
        cluster_project/Cluster/framework/model/Quard_model/model_base1_quard2_c2f_enc_lite_posA_l1_shc
  # Commit in submodule + sync to server-4
  cd cluster_project/Cluster && git add ... && git commit
  bash scripts/sync_model.sh server-4
  ```

- **重试**: 第 1 次，结果: fixed (已验证远程文件存在)
