# Bugfix: M44-CSF launch crash — missing optimizer config + unregistered CSF mode

- **时间**: 2026-08-01 11:03:43
- **实验**: M44-CSF
- **错误类型**: config (missing optimizer/lr_scheduler sections) + code (C2F_ClusterAttn_CSF not imported/registered)
- **错误日志摘要**:
  ```
  (process not detected after launch — training script failed at config parsing
   because optimizer section was missing from config YAML)
  ```
- **根因**: Two issues: (1) CSF config was created from DRP config but optimizer/lr_scheduler sections were truncated; (2) dec.py imported C2F_ClusterAttn_DRP but not C2F_ClusterAttn_CSF, and 'csf' mode was not registered in cluster_att_classes — the CSF attention class existed in hier_postprocess.py but was unreachable.

- **修复**:
  ```diff
  # dec.py: add import + register 'csf' mode
  + from .hier_postprocess import C2F_ClusterAttn_CSF
  + 'csf': C2F_ClusterAttn_CSF,  # in cluster_att_classes
  
  # config: add cluster_mode + optimizer/lr_scheduler
  + cluster_mode: csf
  + optimizer: {type: AdamW, lr: 0.0001, ...}
  + lr_scheduler: {type: PolyLR, max_iters: 70, ...}
  ```
- **重试**: 第 1 次，结果: fixed, re-enqueued as waiting
