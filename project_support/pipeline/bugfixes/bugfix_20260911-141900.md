# Bugfix: Explicit UTF-8 Queue Read In Tick Renderer

- **Time**: 2026-09-11 14:19 Asia/Shanghai
- **Experiment**: Tick reporting only; no training or diagnostic worker
- **Error type**: Windows default encoding
- **Error excerpt**:
  ```
  UnicodeDecodeError: 'gbk' codec can't decode byte 0x94 in position 80
  ```
- **Root cause**: Report renderer read UTF-8 queue.json without an encoding.
- **Fix**:
  ```diff
  - (P/"queue.json").read_text()
  + (P/"queue.json").read_text(encoding="utf-8")
  ```
- **Retry**: Attempt1. Retry writes the report only after state/evidence checks;
  no queue/model modification. No GPU or diagnostic rerun.
