# Bugfix: M92-CTF-HCG-ORT 三处 bug (启动即 crash + ORT 梯度断流)

- **时间**: 2026-08-14 03:22:00
- **实验**: M92-CTF-HCG-ORT (waiting, 未启动 — 预推送修复)
- **错误类型**: NameError (缺参数/缺 import) + 梯度断流 (dead code)

## 错误日志摘要 (代码审查, 未实际运行)
```
1. DEC.__init__: 'orth_weight' 未定义 (line 400) — 启动即 NameError crash
2. cluster_att_classes 引用 C2F_ClusterAttn_CTF_HCG_ORT 但未 import — NameError
3. C2F_ClusterAttn_CTF_HCG_ORT.forward 计算 orth_loss 后丢弃 (return result 不含 loss),
   且老 ORT 实现 (ort 包) 用 detached 累积 + 重建常数 tensor → 梯度从不回流
```

## 根因
ctf_hcg_ort 包复制自 ctf_hcg 后, ORT 接线不完整:
- 缺 `orth_weight=0.01` 于 DEC.__init__ 签名
- 缺 `C2F_ClusterAttn_CTF_HCG_ORT` 的 import
- 缺 dec.py 的 reset_orth_accum()/get_orth_loss() 收集
- 缺 loss.py 的 orth_reg_loss 加权
- 继承自 ort 包的梯度断流 bug (detach 后重建常数 tensor)

## 修复
```diff
# dec.py
+ from .hier_postprocess import (..., C2F_ClusterAttn_CTF_HCG_ORT,
+                                 reset_orth_accum, get_orth_loss)
- cluster_mode='legacy', ... cluster_pool_type='mean',
+ cluster_mode='legacy', ... cluster_pool_type='mean', orth_weight=0.01,
  def forward_iter_pred(...):
+     reset_orth_accum()
      ...
+     orth_reg_loss = None
+     if self.cluster_mode.endswith('_ort'):
+         orth_reg_loss = get_orth_loss()
  return {
+     'orth_reg_loss': orth_reg_loss,
      ...
  }

# hier_postprocess.py: 可微累积
+ _orth_loss_accum = None
+ def reset_orth_accum(): global _orth_loss_accum; _orth_loss_accum = None
+ def get_orth_loss(): global _orth_loss_accum; val = _orth_loss_accum; _orth_loss_accum = None; return val
  # forward 末尾
- _orth_loss_accum = _orth_loss_accum + (orth_loss * self.orth_weight).detach().item()
+ _orth_loss_accum = ((_orth_loss_accum if _orth_loss_accum is not None else orth_loss.new_zeros(()))
+                     + orth_loss * self.orth_weight)

# loss.py
+ if 'orth_reg_loss' in pred and pred['orth_reg_loss'] is not None:
+     loss = loss + pred['orth_reg_loss']
+     loss_out['orth_reg_loss'] = pred['orth_reg_loss']
```
