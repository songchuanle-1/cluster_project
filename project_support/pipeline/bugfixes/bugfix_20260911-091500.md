# Bugfix: Portable SHA256 For Python 3.10 CPU Audit

- Time: 2026-09-11 09:15 Asia/Shanghai.

- Error type: Python version API incompatibility.
- Error excerpt:
  ```text
  AttributeError: module 'hashlib' has no attribute 'file_digest'
  ```
- Root cause: local Python supports file_digest; server-4 Python3.10 does not.
  Worker failed on initial audit SHA check, before point data or GPU operations.
- Fix: use existing project pattern of 4MiB chunked hashlib.sha256.update.
  No hash algorithm, data, thresholds, protocol, model or queue changed.
  ```diff
  -return hashlib.file_digest(stream, "sha256").hexdigest()
  +digest = hashlib.sha256()
  +for block in iter(lambda: stream.read(4 * 1024 * 1024), b""):
  +    digest.update(block)
  +return digest.hexdigest()
  ```
