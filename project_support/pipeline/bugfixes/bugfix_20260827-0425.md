# Bugfix: cluster loss cluster_ids 层级组合映射 (CLICA/CSIC/OBJG/LQA 共用)

- **时间**: 2026-08-27 04:25:00
- **实验**: M140-CTF-HCG-CLICA (crashed@04:09, 影响 M141/M142/M143/M144 潜在)
- **错误类型**: dimension mismatch / IndexError
- **错误日志摘要**:
  ```
  File "...ctf_hcg_clica/loss.py", line 392, in loss_cluster_inst_align
      cids_v = cids[in_inst]
  IndexError: The shape of the mask [1586] at index 0 does not match the shape of the indexed tensor [256] at index 0
  ```
- **根因**: cluster_ids_list 是层级结构 — lvl0 = 超点→细簇映射 (长度=超点数 N);
  lvl>0 = 簇→父簇映射 (长度=簇数: lvl1=[256], lvl2=[64])。CLICA/CSIC/OBJG/LQA
  四个 loss 把所有 lvl 的 cluster_ids 都当 [N] 超点映射使用 → lvl>=1 时
  cids(长度=簇数) 与 sp_ins_labels(长度=超点数) 形状不匹配 → IndexError。
- **修复**: 逐级组合回超点 (同 `C2F_ClusterAttn_CTF_HCG._cluster_to_points`):
  ```diff
  -                cids = cluster_ids_list[lvl][b].long()  # [N_b] local cluster ids
  +                ids_l0 = cluster_ids_list[0][b].long()
  +                n_b = ids_l0.shape[0]
  +                level_ids = [ids_l0]
  +                for lvl_i in range(1, len(cluster_ids_list)):
  +                    par = cluster_ids_list[lvl_i][b].long()
  +                    par = par.clamp(min=0, max=par.shape[0] - 1)
  +                    level_ids.append(par.gather(0, level_ids[-1].clamp(min=0, max=par.shape[0] - 1)))
  +                cids = level_ids[lvl]                    # [N_b] 超点→lvl 簇 id
  ```
  应用到 5 个包: ctf_hcg_clica / ctf_hcg_csic / ctf_hcg_clica_csic / ctf_hcg_objg / ctf_hcg_lqa。
- **验证**: 服务器端构造层级 cluster_ids (N=1586, [256]/[64]/[8]) 单测 loss_cluster_inst_align
  → 0.0634 正常; py_compile 全过; M140 已 reset 回 waiting。
