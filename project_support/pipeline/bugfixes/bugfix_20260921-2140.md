# Bugfix: model resolver silently falls back to the default network

- **时间**: 2026-09-21 21:40:00 +08:00
- **实验**: M197-diagnostic-boundary
- **错误类型**: harness identity / network resolution
- **错误日志摘要**:
  ```
  ValueError: Resolved Network is not the bound champion package:
  framework.model.Quard_model.model_base1_quard2_c2f_enc_lite_posA_l1.network
  ```
  (observed while the resolver was exercised with the champion package name
  `model_base1_quard2_c2f_enc_lite_posA_l1_ctf_hcg_csort`)
- **根因**: `framework/__init__.py::resolve_network` resolves a variant by config
  basename and then swallows `ImportError`/`AttributeError`:
  ```
  try:
      mod = importlib.import_module(module_path)
      return mod.Network
  except (ImportError, AttributeError):
      return _get_default_network()
  ```
  A variant whose package is missing, misnamed or fails to import therefore does
  not raise: it silently trains `_DEFAULT_MODEL`
  (`model_base1_quard2_c2f_enc_lite_posA_l1`). The first boundary probe hit
  exactly this path and reported the default package while the bound config
  digest was the champion's.
- **影响**: a broken variant would produce a run that looks like the intended
  variant in queue/log naming while actually training the default architecture.
  This is a silent-identity hazard for every future admitted candidate.
- **修复**: none applied in this tick. The resolver sits on the lineage path that
  historical source digests were computed over, so the change is deferred to a
  controlled edit. Proposed fail-closed guard, replacing the fallback branch:
  ```
  except (ImportError, AttributeError) as exc:
      raise ImportError(
          "Network package %s did not resolve; refusing to fall back to %s"
          % (module_path, _DEFAULT_MODEL)) from exc
  ```
- **缓解 (applied)**: the boundary check now asserts the resolved module equals
  `framework.model.Quard_model.<config-basename>.network`, so any silent fallback
  fails the check instead of being recorded as a success.
- **重试**: 第 2 次，结果: fixed-within-check. The corrected assertion passed and
  the champion package resolved to its own `Network`.
