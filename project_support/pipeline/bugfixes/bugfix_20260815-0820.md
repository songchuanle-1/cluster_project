# Bugfix: M94-HCG-ORT 缺 orth_weight 参数 + M95-CTF-HCG-CSORT 跨尺度映射方向反转

- **时间**: 2026-08-15 08:20
- **实验**: M94-HCG-ORT (hcg_ort), M95-CTF-HCG-CSORT (ctf_hcg_csort)
- **错误类型**: NameError (缺参数) + IndexError (映射方向反转)

## 错误日志摘要
```
M94: File ".../model_base1_quard2_c2f_enc_lite_posA_l1_hcg_ort/dec.py", line 401, in __init__
     dropout=dropout, orth_weight=orth_weight)

     IndexError: index 177 is out of bounds for dimension 1 with size 64
```

## 根因 (每实验一条)
1. **M94 (hcg_ort)**: dec.py DEC.__init__ 签名未加 `orth_weight=0.01` 参数, 但内部
   `if cluster_mode.endswith('_ort')` 分支引用了它 → 启动即 NameError。对照 champ_ort
   已有该参数 (working), hcg_ort 复制时漏了。
2. **M95 (ctf_hcg_csort)**: `_cross_scale_orth_loss(coarse, fine, child_maps)` 直接
   `for p, children in mapping.items()` — 但 `child_cluster_maps[lvl]` 是 partitioner
   按**最近邻把粗 token 归属到细 parent** 构建的映射 {fine_parent: [coarse_child]},
   key 是 fine 层索引 (最大 255/64), 被误当作 agg 的行号 (agg shape = coarse 层, 仅 64/8)
   → 越界。需要逆映射: {coarse p: [fine f where p ∈ mapping[f]]}。
