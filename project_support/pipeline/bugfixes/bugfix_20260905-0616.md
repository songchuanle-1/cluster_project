# Bugfix: M175 hierarchy IDs on the wrong device

- **时间**: 2026-09-05 06:16:00
- **实验**: M175-CTF-HCG-CSORT-MQHF
- **错误类型**: CUDA device mismatch
- **错误日志摘要**:
  ```
  RuntimeError: Expected all tensors to be on the same device,
  but got index is on cpu, different from other tensors on cuda:0
  ```
- **根因**: The new hierarchy-flow pool used cluster ID tensors directly as
  scatter/gather indices without moving them to the mask probability device.
- **修复**:
  ```diff
- point_ids = cluster_bank.cluster_ids_list[0][b].long()
+ point_ids = cluster_bank.cluster_ids_list[0][b].to(
+     device=probs_b.device, dtype=torch.long)
  ```
  The same conversion is applied to every parent hierarchy map.
- **重试**: 第 1 次，结果: fixed. Remote CUDA forward/backward passed on
  server-4 with finite nonzero gradients for query, masks, and point features.
