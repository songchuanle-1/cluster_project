# Bugfix: M177 hard branch selection blocked mask gradients

- **时间**: 2026-09-05 23:13:00
- **实验**: M177-CTF-HCG-CSORT-MQBC
- **错误类型**: gradient disconnection in remote smoke test
- **错误日志摘要**:
  ```
  AssertionError: masks
  ```
- **根因**: `argmax` plus `index_select` made the selected hierarchy branch
  discrete, so bottleneck occupancy scores could not receive gradients from the
  query refinement output.
- **修复**:
  ```diff
- selected branch tokens via index_select(argmax(score))
+ use hard one-hot in the forward pass with a softmax straight-through
+ gradient path, then aggregate each hierarchy level through branch maps
  ```
  No temperature, threshold, coefficient, loss, or schedule change is added.
- **重试**: 第 1 次，结果: fixed. Remote CUDA forward/backward passed with
  finite nonzero gradients for query, mask scores, and point features.
