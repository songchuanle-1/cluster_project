# Bugfix: M40-SWI duplicate process on GPU0

- **时间**: 2026-07-30 21:03:01
- **实验**: M40-SWI (model_base1_quard2_c2f_enc_lite_posA_l1_swi)
- **错误类型**: duplicate process / stale process
- **错误日志摘要**:
  ```
  GPU0 had TWO python processes training the same config:
    pid 1799178 (started ~14:03, 12466 MB) — stale duplicate
    pid 1849933 (started ~14:11, 19566 MB) — active run
  Both: python tools/train.py configs/Quard/swi/model_base1_quard2_c2f_enc_lite_posA_l1_swi.yaml --gpu_ids 0 --num_gpus 1
  ```
- **根因**: M40-SWI 被双次启动（14:03 首次 + 14:11 二次），旧进程未被 kill，双进程争抢 GPU0 导致 ~32h/epoch（正常 ~3h/epoch）
- **修复**:
  ```bash
  ssh songcl@192.168.1.137 "kill 1799178"
  ```
- **重试**: 无需重试 — 保留 pid 1849933 继续运行，已释放 ~12.5GB 显存，预期速度恢复正常
