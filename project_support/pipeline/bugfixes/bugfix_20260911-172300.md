# Bugfix: CPU head audit helper repairs

- **时间**: 2026-09-11 17:23:00
- **实验**: D1-head-owner / D1-head-coupling
- **错误类型**: diagnostic implementation error, not a training crash
- **错误日志摘要**:
  ```text
  RuntimeError: grad can be implicitly created only for scalar outputs
  KeyError: "An object named 'Criterion' was already registered in 'losses' registry"
  synthetic finite-difference sign mismatch in the first completed attempt
  ```
- **根因**:
  1. the synthetic margin indexed the batch dimension instead of returning a
     scalar margin for candidate 0 versus candidate 1;
  2. loading baseline and M95 in one process collided on the project's global
     gorilla loss registry;
  3. the finite-difference direction was compared with the opposite sign.
- **修复**:
  ```diff
  - d = logits[:, 1] - logits[:, 0]; return d[s] - d[h]
  + return logits[0, s, 1] - logits[0, s, 0] - logits[0, h, 1] + logits[0, h, 0]

  - import both packages in one process
  + run one worker process per checkpoint/package

  - finite_difference_margin(..., direction, ...)
  + finite_difference_margin(..., [-delta for delta in direction], ...)
  ```
- **重试**: 第 3 次，结果: fixed. Final CPU run passed with CUDA hidden.
