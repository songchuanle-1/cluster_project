# Bugfix: M17-ORT DEC.__init__() got unexpected keyword argument 'orth_weight'

- **时间**: 2026-07-22 09:05
- **实验**: M17-ORT (model_base1_quard2_c2f_enc_lite_posA_l1_ort)
- **错误类型**: TypeError / config-model mismatch
- **错误日志摘要**:
  ```
  TypeError: DEC.__init__() got an unexpected keyword argument 'orth_weight'
  ```
- **根因**: config YAML `model.dec` 段包含 `orth_weight: 0.01` 但 DEC.__init__ 签名没有该参数。network.py 用 `DEC(**dec)` 展开所有 config key 导致 TypeError。
- **修复**:
  ```diff
  -        cluster_message_type='context',
  -    ):
  +        cluster_message_type='context',
  +        orth_weight=0.01,
  +    ):
  ```
  同时移除 dec.py 中已无效的 `orth_weight = kwargs.get('orth_weight', 0.01)` 行（DEC 无 **kwargs）。
- **重试**: 第 1 次，结果: fixed — model builds OK (155,905,850 params), re-queued as waiting
