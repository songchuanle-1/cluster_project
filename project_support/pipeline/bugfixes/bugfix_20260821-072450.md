# Bugfix: M116-CGA fill_diagonal_ 3D tensor crash (torch>=2.8)

- **时间**: 2026-08-21 07:24:50
- **实验**: M116-CTF-HCG-CGA
- **错误类型**: RuntimeError — `fill_diagonal_` 在 torch 2.8.0 对 3D tensor 要求全维度相等
- **错误日志摘要**:
  ```
  File ".../model_base1_quard2_c2f_enc_lite_posA_l1_ctf_hcg_cga/hier_postprocess.py", line 706, in _build_adj_mask
      sim.fill_diagonal_(-1e9)
  RuntimeError: all dimensions of input must be of equal length
  ```
- **根因**: `_build_adj_mask` 中 `sim` 为 `[B, K, K]` (batch, cluster, cluster),
  torch ≤2.7 `fill_diagonal_` 只要求最后两维相等即可逐 batch 填对角线;
  torch 2.8.0 收紧为**所有维度相等** (仅 `[K, K, K]` 立方才接受), 因此
  `[B, K, K]` (B≠K) 直接抛错。
- **修复**:
  ```diff
  - sim.fill_diagonal_(-1e9)
  + eye = torch.eye(K, dtype=torch.bool, device=sim.device)
  + sim = sim.masked_fill(eye.unsqueeze(0), -1e9)
    ...
  - adj.fill_diagonal_(True)  # self-loop
  + adj = adj | eye.unsqueeze(0)  # self-loop (broadcast [1, K, K])
  ```
  用 eye-mask + masked_fill / 按位或替代 fill_diagonal_, 版本无关
  (同时支持 2D/3D, 不依赖 torch 版本对 3D 对角线的语义)。
- **重试**: 第 1 次，结果: **fixed** — 重新 launch 后通过 model_profile,
  正常进入 epoch 1/50 训练 (iter_time≈0.72s, ~1.8 it/s)。
