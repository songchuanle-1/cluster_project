# Bugfix: M70-REAGG/M76-DET-REAGG crash — C2F_ClusterAttn_REAGG 类名与 dec.py import 不一致

- **时间**: 2026-08-08 09:07:25
- **实验**: M70-REAGG (running→crash), M76-DET-REAGG (waiting, 同源 bug)
- **错误类型**: ImportError (AttributeError 在 import 阶段)
- **错误日志摘要**:
  ```
  File ".../model_base1_quard2_c2f_enc_lite_posA_l1_reag/dec.py", line 18, in <module>
    from .hier_postprocess import (
  ImportError: cannot import name 'C2F_ClusterAttn_REAG' from
    'framework.model.Quard_model.model_base1_quard2_c2f_enc_lite_posA_l1_reag.hier_postprocess'
  During handling of the above exception, another exception occurred:
  KeyError: "An object named 'Criterion' was already registered in 'losses' registry!"
  ```
- **根因**: `reag/hier_postprocess.py` 定义了类 `C2F_ClusterAttn_REAGG`（多一个 G），而 `dec.py`
  第 21 行 import 的是 `C2F_ClusterAttn_REAG`。import 失败 → resolve_network 回退到默认
  base 包 → base 包重复注册 Criterion → gorilla registry KeyError。`det_reag` 包为复制品，
  带同样 bug。
- **修复**:
  ```diff
  - class C2F_ClusterAttn_REAGG(C2F_ClusterAttn_Lite):
  + class C2F_ClusterAttn_REAG(C2F_ClusterAttn_Lite):
  ```
  在 `reag/hier_postprocess.py` 与 `det_reag/hier_postprocess.py` 各改 1 处类名。
  dec.py 的 import + `'reag': C2F_ClusterAttn_REAG` 映射保持不变（类名与模式名对齐，
  与 iter 包的 `C2F_ClusterAttn_ITER` 命名惯例一致）。
- **重试**: 第 1 次，结果: fixed。M70-REAGG 已重置为 waiting 重入队，M76-DET-REAGG
  保持 waiting（同源修复已覆盖）。已 sync server-4 + server-6。
