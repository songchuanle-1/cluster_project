# Bugfix: ELF section parser used an invalid struct prefix

- **时间**: 2026-09-21 21:24:00 +08:00
- **实验**: M197-diagnostic-boundary
- **错误类型**: native dependency observation / ELF parsing
- **错误日志摘要**:
  ```
  struct.error: unpack_from requires a buffer of at least 14527256 bytes
  for unpacking 72 bytes at offset 14527184
  ```
- **根因**: `byte_order[0]` is `l` or `b`, not a Python `struct` byte-order prefix. On Linux it parsed as a native signed long and made the section-header struct 72 bytes instead of the ELF64 size of 64.
- **修复**:
  ```diff
  + struct_prefix = "<" if byte_order == "little" else ">"
    sections.append(struct.unpack_from(
  -     byte_order[0] + dynamic_format, data, offset))
  +     struct_prefix + dynamic_format, data, offset))
  ```
  The synthetic ELF fixture was also reduced to the exact section-table end so this boundary cannot regress unnoticed.
- **重试**: 第 2 次，结果: fixed. Server-6 collection then parsed the 14,527,248-byte extension and validated all eight `DT_NEEDED` rows.
