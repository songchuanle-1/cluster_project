# Bugfix: M93-CTF-SEF + M94-HCG-ORT 启动崩溃 (集群模式未注册 / 梯度断流)

- **时间**: 2026-08-14 21:20
- **实验**: M93-CTF-SEF (ctf_sef), M94-HCG-ORT (hcg_ort)
- **错误类型**: ValueError (Unknown cluster_mode) + NameError (类未 import) + 梯度断流 (loss 惰性)

## 错误日志摘要
```
M93: ValueError: Unknown cluster_mode: ctf_sef. Expected one of ('legacy','noroute','true_route','drp','ctf')
M94: NameError: name 'C2F_ClusterAttn_HCG_ORT' is not defined. Did you mean: 'C2F_ClusterAttn_HCG'?
```

## 根因 (每实验一条)
1. **M93 (ctf_sef)**: ① dec.py 的 cluster_att_classes 未注册 `'ctf_sef'` 模式 → 启动即 ValueError;
   ② hier_postprocess.py 的 `C2F_ClusterAttn_CTF_SEF._apply_se` 定义了但 forward 从未调用 →
   即使修好注册, SE channel attention 也不会生效 (静默空转)。
2. **M94 (hcg_ort)**: ① dec.py 引用了 `C2F_ClusterAttn_HCG_ORT` 但未从 hier_postprocess import →
   NameError; ② forward 计算了 orth_loss 但**从未累积/返回** → ORT 组件梯度恒为 0
   (与 M17-ORT/M56/M57 相同的梯度断流 bug 变体)。

## 修复
```diff
# ctf_sef/dec.py
@@ cluster_att_classes @@
+            'ctf_sef': C2F_ClusterAttn_CTF_SEF,
# ctf_sef/hier_postprocess.py (forward)
-        result = super().forward(point_feats, query, point_mask,
-                                 cluster_feats_list, child_cluster_maps, cluster_ids_list)
+        refined = self._apply_se(cluster_feats_list)   # SE 实际施加到 cluster tokens
+        result = super().forward(point_feats, query, point_mask,
+                                 refined, child_cluster_maps, cluster_ids_list)

# hcg_ort/dec.py
@@ import @@
+    C2F_ClusterAttn_HCG_ORT,
+    reset_orth_accum,
+    get_orth_loss,
@@ forward @@
+        if self.cluster_mode.endswith('_ort'):
+            reset_orth_accum()
@@ return @@
+        if self.cluster_mode.endswith('_ort'):
+            orth_reg_loss = get_orth_loss()
+        else:

```
