# NSD CPU preparation

Stable ID: `hierarchy-native-spatial-dirichlet-composition`.
Proposed experiment: M232-NSD. Registration, source commit and deployment belong
to root; this packet does not perform them.

The structural hypothesis is that spatial variation of native superpoint
features inside fixed fine leaves and between true child centers can supply
useful hierarchy responsibilities before the original single `inst_feats`
delivery. This is an unmeasured task hypothesis. It is not a claim of a
population deficit, trained benefit or novelty.

For each fixed parent, merge exact-coordinate coincidences by their feature
mean. Lexicographically order the distinct original coordinates. Connect each
consecutive pair; no edge crosses its original parent, no learned edge choice,
new membership, language/query source or content routing is used. Let
`E_parent = mean_edges (f_u - f_v)^2` componentwise, with zero for a group having
fewer than two distinct coordinates. At native vertices this produces the fine
energy; on true fine-child means/centers it produces middle energy, and on true
middle-child means/centers it produces coarse energy.

This energy is not a total-variance decomposition and no such identity is
claimed. Unlike a change from second to third marginal moment, the input
contains explicit geometry-selected pair relations.

Bottom-up shared nonlinear analysis uses
`A([normalized_bank, local_energy, mean_analyzed_true_children])`, with the
absent fine child-state block set to zero. Top-down shared nonlinear synthesis
uses `S([analyzed_node, synthesized_original_parent])`, with the absent coarse
parent block set to zero. A is 3C→C→C and S is 2C→C→C with the original GELU.
Each original supported node is analyzed and synthesized once. Deltas then use
the original raw-bank skip, HCG readback and original single `inst_feats` path.
The existing FFN construction and RNG fork keep the common initialization
contract available for the future actual paired check.

The exact rational counterexample uses eight native vertices at x coordinates
`[-7,-5,-3,-1,1,3,5,7]`. Feature A is `[1,1,-1,-1,-1,-1,1,1]`; B is
`[1,-1,1,-1,-1,1,-1,1]`. Both have mean 0, feature variance 1 and signed
position-feature cross scatter 0. Their pair energies are 8/7 and 24/7.
The actual source statistic was executed using a rational array adapter, not
Torch. This proves an information distinction from HVD/PSC summaries in this
constructed case; it does not prove a task-relevant deficit.

Bounded history review found no native geometric edge-energy route among the
157 current IDs. FLE is recipient-specific point exchange; PCE crosses original
fine leaves; MDC/AEF operate on middle-token communication; HRC/BEC compose
original token means; HVD and PSC preserve marginal and joint moments. NSD
changes the input relation graph and bottom-up/top-down factorization together.
It does not restart any of those realizations or erase their failures.

Known risks are coordinate-order anisotropy, original-precision finite gradient
behavior, geometry/feature copy cost and resource budget. Exact coordinate ties
are merged to remove row-order dependence. General rotation invariance is not
claimed. The original YAML, data, seed1999, loss, schedule, optimizer, precision
and bans remain unchanged. Full forward, Torch/autograd, original two natural
TRAIN batches, common initialization, whole-core updates, original resources,
efficacy and novelty are all NOT_RUN/UNKNOWN.
