# M229 MIC private source prototype

The actual helper gathers one normalized fine/middle/coarse tuple for each deduplicated true fine ID. It evaluates the shared C-to-C Linear and original GELU once on concatenated 8F subset rows [a+b+c,a+b,a+c,b+c,a,b,c,0], slices their actual outputs and applies coefficients [+1,-1,-1,-1,+1,+1,+1,-1]. The same q is fine delta; middle/coarse outputs directly average all original fine paths, including unequal middle degrees. Unsupported rows remain zero. Scene offsets are separate. Original raw banks, grouping, FPS, geometry, HCG, CSORT, mask and single inst_feats injection are unchanged.

APF feeds one raw concatenated 3C triplet to a 3C learned map and splits three role values. AOC uses two ordered two-layer binary compositions and their antisymmetric difference. MIC instead samples one shared C-to-C nonlinear function at eight subset vertices and forms a symmetric third mixed finite difference. It is neither a persistent node/edge recurrence (NEC/SFC/ELC/PES), signed edge flux nor a wedge incidence graph (WFC). These bounded graph differences do not establish novelty, efficacy, task bottleneck or new information. Real raw ancestors already contain descendants.

Original three FFNs and three LNs are constructed in exact original order, then the new core is constructed inside CPU fork_rng, then the three FFNs become Identity. Forward uses original three LNs once, new core, original three raw skip additions and original HCG tail. The six remaining model files and original a18 YAML are byte copies from frozen c777; original hier was recovered and pinned to 7e1488, without reading the 28 user dirty files.

New core parameters C*C+C=65792 at C256. Eight subset evaluations per true fine give at most 8*256*C*C=134217728 linear MACs versus original 8*(256+64+8)*C*C=171966464. These omit elementwise/metadata/scatter costs and are not total resource evidence. Metadata traversal/dedup sorting and packed buffers also cost time and memory. Original native whole-function/unsupported counting is still required.

Risks: subtraction can lose small interaction signals; affine or zero-input limits annihilate the interaction in real arithmetic; saturation can give weak gradients; ancestry permutation symmetry and common q can alias scale roles; means may cancel or wash out detail. None is a new FP32 cancellation/conservation/Jacobian/coverage or per-row positivity gate. The only future new training gate is actual original-loss whole-new-core aggregate finite/nonzero weight gradient and aggregate parameter/module update, not old FFN gradients. Individual subset/map/node/column/bias zero is legal.

Software scope: 33 actual bounded checks passed, including 17 executions of production forward AST with Fraction/list cubic or affine stand-ins and one scalar-erf GELU case, eight invalid metadata cases, IDs/batch/holes/duplicates/empty/pad support, unequal-degree direct path means, source compile and integration AST. The first report manually listed 15 forward calls; a separate count correction preserves it. Two wrapper string syntax failures happened before any builder/model write and are retained as authoring-only failures. No Torch, model import, autograd, native data, backward, resource, lease, admission or queue execution occurred. All actual code/source/parent versions remain NULL; 94c4 is only a reference.
