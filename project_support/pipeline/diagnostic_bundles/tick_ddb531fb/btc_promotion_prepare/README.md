These private sources are drafts only. No ff, dispatch, SSH, GPU computation,
shared write, receipt or approval result was executed or generated here.

`promotion_common.py` defaults `DRAFT_EXECUTION_ENABLED=False`; both mains also
require `--execute-root`. Both local semantic and independent review path/SHA
bindings deliberately remain `None`. No invented review hash is supplied. Root
must bind actual frozen results and review the resulting concrete scripts before
enabling them. Without the flag the mains only print DRAFT_DISABLED; with the
flag but unchanged draft settings they refuse before Git, pipeline imports,
transport or any output artifact. Static code hashes are not an approval.

The local review contract follows the actual pce schema: frozen SHA, status
RAW_SEMANTICS_VALIDATED_NOT_ADMISSION, actual native-semantic/pairing and resource
protocol observations true, and standard_PASS_receipt_queue_written false.
That local schema has no material_concerns field. The external independent
review must have its actual BTC validation status and material_concerns=[] plus
all four original execution path/hash/request/result references. No artifact is
modified to invent a missing field. The four raw names are the actual
{smoke,resources}_{champion,candidate}_execution.json files, not CLI stdout.

All six original owner fields and unextended 2026-10-24T17:06:44.679939Z deadline
are fixed in the common guard. Actual environment thread and foreground target,
context/pending hashes, goal and original diagnostic binding must match. Never
override CODEX_THREAD_ID or renew an old lease/deadline to use these drafts.
