# M222-AOC source prototype

For each original true-supported fine row, normalize original fine/middle/coarse bank features with their original three LayerNorms, producing a,b,c. With one shared default binary cell T(x,y)=originalGELU(W[x,y]), compute two private compositional paths: p=T(T(a,b),c) and r=T(T(a,c),b). The contrast q=p-r is the fine delta, and original supported middle/coarse rows receive equal means of the same q over their true fine-descendant paths. Coarse means count fine paths directly, not middle means or raw point counts. Existing raw banks, FPS/membership/IDs, CSORT, raw skips, HCG, point readback and one instance-feature update remain unchanged.

Production batches the two first-stage branches in one actual 2F-row cell/GELU call, then the two second-stage branches in another 2F-row call. Both calls share the same cell. No parent bank feature is overwritten, no recurrent state is carried across sibling paths, and no extra residual is injected into inst_feats. Unsupported/padded rows receive zero delta. Empty true support returns zero deltas without cell/mean calls. Duplicate points do not duplicate a fine path. A singleton path is valid and uses the same two-stage graph with no special fallback.

APF is the nearest family: it uses one raw 3C-to-3C joint map/GELU and three independently sliced messages. AOC instead uses a shared binary operator twice along two different ancestor orders and subtracts their final C outputs, then shares the same contrast among levels. AEF uses endpoint-swap responses on a middle-sibling geometric MST with equal/opposite incidence updates; AOC holds fine a fixed, swaps normalized ancestor roles, uses no MST and has no signed incidence/conservation claim. PES repeatedly updates persistent node states along original-tree walks; AOC creates only per-fine private intermediate paths. These are bounded graph distinctions, not a proof of general novelty or a newly discovered information deficit. No new input source or downstream coverage is claimed.

The contrast intentionally suppresses ancestor-order-common responses. This can discard useful semantics. At normalized operator inputs, swapping b/c negates q and b=c gives q0 algebraically; neither is whole-model scale invariance or an FP32 equality guarantee. If the shared cell degenerates to an affine function, fine a cancels entirely. Nonlinearity permits fine-dependent modulation, but does not prove actual fine dependence or useful learned behavior. Parameter settings and some rows may legitimately produce q0. These risks add no extra Jacobian, per-branch or per-row positive-gradient gate.

The original three FFNs/LNs are constructed in their original RNG order. A CPU fork_rng creates the new default cell, then FFN modules are replaced with Identity shells. Actual common initialization must still be checked under the same original pretrain; no common weights are manually copied. At C256, cell parameters 2C^2+C=131328 replace 24C^2+15C=1576704, source delta -1445376 and inferred full count156038714. Four cell rows per true fine imply <=1024 rows at original K0=256 and inferred linear MAC134217728 versus original three-FFN171966464. Whole-model FLOPs, memory, latency and efficacy are unmeasured. Fixed private means/metadata are O(paths+upper rows); actual kernel/Python cost awaits the original native resource protocol.

static_check.py extracts actual production functions and forward AST, executes a Fraction/list carrier, and compares with an independent per-original-ID vector/path oracle. Its nonlinear polynomial cell substitutes only demonstrate path/control-flow and ID arithmetic, not actual GELU, Torch, FP32, gradients or model efficacy. Six other model files and original native YAML are exact byte copies; only CTF constructor/forward change in hier_postprocess.py. All prototype code/source/actual-parent metadata stays null. Current source5c is a compatibility reference, not a future fast-forward promise.
