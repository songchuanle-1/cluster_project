# M221-PES implementation

The sole structural change replaces the original three per-token FFNs by one shared receiver-state cell on the original supported fine-middle-coarse forest. Initialize each supported node state from its own original pre-LayerNorm bank token. For every actual coarse-root component, walk the original-ID-sorted DFS Euler closed tour, then its reversed closed tour. At each directed event u to v, set h_v = originalGELU(W[h_v,h_u]); only the receiver changes. The second walk uses all states left by the first walk. Final states supply the three deltas to the original raw-bank skips and original downstream HCG/single instance path.

Each component with E true edges uses exactly 4E actual updates. Active components batch by event position, with no fake padding update. Python row-reference replacement retains old Tensor nodes for autograd instead of in-place feature mutation or a full-bank copy after every event. Final functional index_copy restores original IDs once per level. Metadata alone is detached; feature rows remain connected to the original loss. Graph-derived two walks are fixed, not a tuned number of layers or repeated instance-feature injection.

Support comes only from actual point-to-fine IDs composed through both original parent lists. Unsupported empty banks/rows and padding have zero delta. No true support means zero events and no cell call; a single true fine still has a fine/middle/coarse chain and eight events. No isolated-node own-cell fallback exists. The original six other model sources and native YAML are byte copies. Only CTF constructor and CTF forward change in hier_postprocess.py. The constructor first builds all three old FFNs/LNs in their original order, creates the new default cell under CPU fork_rng, then replaces old FFNs with Identity. Actual matched common initialization equality is still a future native check.

Nearest graph comparisons: PSBR and BCR retain fixed middle token inputs and compressed directional accumulator contexts with separate directional recurrences; PES retains a C-state for every original node, revisits internal nodes, reads senders after their earlier receiver updates, and continues the same states through the reverse walk. BTC uses artificial middle-sibling binary summaries, BFC/CTS use synchronous same-parent n-state rounds, DCE computes directed recipient-excluded edge messages without persistent node overwrites, HPC sandwiches independent FFNs by a fixed linear resolver, and APF uses one raw three-scale joint factor. These are bounded whole-graph distinctions, not a complete historical/literature novelty proof. PES belongs to recurrent graph message passing. It is not permutation invariant, generally invertible, or a proof of useful new global coverage; original downstream HCG/mask paths may already read broader context.

At C256, new parameters = 2C^2+C = 131328 versus three original FFNs 24C^2+15C = 1576704; inferred delta -1445376 and inferred full inventory 156038714. For actual native widths [256,64,8], E<=320, total rows<=1280, shared-cell linear MAC inference <=167772160 versus original three-FFN linear MAC inference 171966464. This excludes other operators and does not establish whole-model FLOPs, latency or memory. Metadata grouping/events are O(nodes+edges+events); total cell rows are 4E, while serial depth is up to 4E of the largest component. Kernel launches, Python Tensor-row references and long recurrent autograd chains may be costly despite parameter reduction. Vanishing/exploding gradients, forgetting, traversal-order sensitivity and accuracy remain unknown.

Run static_check.py with python -B. It extracts the actual production plan and forward AST into a stdlib-only integer/list carrier, compares it with an independently built original-node adjacency DFS and independent per-component scalar recurrence, and checks integration/byte hashes. Its numerical substitutes are software control-flow witnesses, not actual Linear/GELU, Torch, FP32, backward, resource or model results.
