# M224-SFC source-only prototype

Each true original fine/middle/coarse node starts from its one original LayerNorm output. On each original coarse-root component, compute the genuine tree diameter D using two BFS traversals. For exactly D rounds, each node concatenates its OLD own state with the equal mean of ALL OLD adjacent node states, applies the same default2C-toC Linear/original GELU, and simultaneously replaces its state. Final hD supplies the three original-ID deltas directly before the original raw skips, HCG and single point/instance path. No hD-h0 contrast, new state residual, fake donor or repeated instance injection is introduced.

True support is composed from actual point-to-fine and both original parent maps; an unsupported middle/coarse row cannot create a component. Each point-supported fine counts once regardless of point multiplicity. Actual degree includes each fine child and the one parent separately, not parent plus childmean as equally weighted groups. The production round builder batches only components with r<D and gathers every receiver/neighbor from one old packed-state Tensor before one functional index_copy. D2 components keep their finished states while D4 components continue. Empty support returns zero deltas without cell calls; unsupported/padding always has zero private delta. Original raw aggregation/FPS/IDs/CSORT/HCG and all other hierarchy methods remain unchanged. Six other original model sources and original native YAML are byte-identical.

PES is the closest recurrent family but updates one current receiver from one current sender along an ordered Euler tour/reverse; SFC adds full-neighbor reductions and full-node old-state stage barriers. CTS uses middle-sibling geometric cycles and own/plus/minus3slot maps; SFC uses the original three-level undirected membership forest and genuine degree. HPC composes fixed linear resolventS, original3FFNs once, thenS; SFC inserts shared nonlinear state composition at each finite hop. DCE excludes reverse recipient messages; SFC permits feedback/backtracking. These are bounded graph distinctions within standard synchronous GNN/message passing, not research novelty, new-information or task-deficit proof. Original raw/ancestor features can already contain broader or self-descendant information.

Oversmoothing, degree averaging, repeated self-information, shared fine/middle/coarse role capacity and weak/exploding gradients are risks. Diameter potential reachability neither guarantees retained information nor nonzero learned influence. This is not a repair or diagnosis of PES's unknown parameter-enumeration crash. No new FP32/Jacobian/convergence/gradient-coverage threshold follows. Only future wholecore aggregate original-loss gradient/update is a trainability positivity control; per-round/node/column/bias0 remains legal.

Original three FFNs/LNs are constructed in the original order, the new default cell is created inside CPU fork_rng, then old FFNs become Identity.
