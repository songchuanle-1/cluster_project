Root-only local transport helper; default invocation is NOP. Author has not used SSH.

Use python -B -X utf8 with PROJECT_ROOT=D:/project, PYTHONDONTWRITEBYTECODE=1 and GIT_OPTIONAL_LOCKS=0. Exact current six-field foreground owner and the current unchanged SERVERS hash are mandatory. This helper is only for the reviewed current tick, before the separate runtime/SERVERS switch.

1. After root review: `--execute-root --action stage` creates the three frozen controller producer files once. It refuses any existing producer stage.
2. After independent source deployment to exact PSC runtime0ccc: `--execute-root --action collect` saves a separate current-owner collect request and actual observation wrapper.
3. Root and peer inspect the returned real source/YAML/interpreter/original-three-inode facts. Create a real activation receipt with six-field owner, decision ALLOW_PRODUCTION_PATH_RENDER, exact observation SHA, exact canonical admission SHA, training_launch_authorized=false, and draft_not_an_actual_receipt=false.
4. After that review: `--execute-root --action render --admission <absolute canonical admission JSON> --activation <absolute actual reviewed activation receipt JSON>` embeds those exact bytes, saves a separate render request, then invokes only the reviewed CPU render controller.

Outputs are stage_actual.json, collect_actual.json and render_actual.json in this directory. Remote result bytes are preserved as base64 with their remote SHA256, together with parsed result and controller stdout/stderr. Each action first creates an immutable intent. Any existing intent/request/stage/output means reconcile; never delete or replay. Timeouts retain uncertainty and PID without signals.

This helper does not admit, deploy source, change YAML/main/index/SERVERS/queue/goal/scheduler, query/use GPUs, acquire the GPU locks, or launch training. UUID/20GB/max1 are verified as current policy metadata; root's existing actual resource/occupation checks remain mandatory for subsequent real training.
