# 本轮原生前缀重复性诊断

## 结论
本轮没有新的训练或 mIoU 提升证据。历史最佳 M95 为0.5020，目标0.5100，
差0.0080。M203-FLE 正常早停23/50、最佳0.4885315597为缓存，不重启。
研究仍服务于层级点云/超点特征更新并与 query 共同生成 mask 的主线，
数值诊断既不是新的注意力机制，也不是可替代主线的论文创新。

## 实际证据
| 对照 | 实测 | 可得结论 | 不能推出 |
|---|---|---|---|
| 两个模型各一对原生跟踪 | 权重、输入、四种RNG相同；各354个边界；最早原始差异均在unet.conv.2输出 | 下采样稀疏坐标行顺序先分叉 | 不是已证明的原子操作原因 |
| M95固定输入与原生cotangent | 跨进程按坐标对齐后特征max差3.3378601074e-6，输入VJP差0 | 某些新进程存在真实算术差异，不只是行重排 | 不能当训练种子方差、效应噪声区间或放宽1e-6的理由 |
| FLE相同稀疏对照 | 坐标对齐后的首下采样特征和输入VJP差0，权重VJP存在极小差异 | 该配对的第一层主要是排列变化 | 不代表整条前缀确定性 |
| FLE首残差块对齐 | 下采样特征差0，训练态BatchNorm首先出现9.5367431641e-7差异 | 定位到第一个数值分叉边界 | 还不能仅靠相关性归因 |
| FLE只改行排列A/A/B | A/B分别重建原生结果误差0；A重复输出及全部VJP差0；B复现9.5367431641e-7差异；零cotangent全部0 | 行排列足以导致该固定批次BN局部数值变化 | 不等于整网训练差距由此造成或已找到有效修复 |
| M95算法只读观测 | 两个新进程均选同一Simt描述且对齐输出哈希相同，TF32均关闭 | 此有限配对没有解释此前的跨进程算术分叉 | 不能声称已证明自动选核导致，也不重试至出现想要结果 |

## 边界与负面证据
全部测试保留原生参数requires_grad、seed1999、训练batch2、clip0.1及源配置。
不冻结模型参数，不切换精度/后端，不清缓存，不做optimizer/scheduler步骤。
保存最初失败、严格1e-6/float64 1e-12门槛；不将旧缓存或重复调用计作新训练。
观测钩子可能改变执行时序；单批/有限进程不量化泛化或总体不确定性。
只用已授权server4物理GPU0；GPU1未获授权，本轮不使用server3。

## 产出与后续
本轮11次原生整网前向和11次原生整网反向；另外15次固定输入算子前向、
15次普通VJP和7次零VJP。新训练、新VAL、新模型、准入和优化步骤均为0。
准确累计由final_progress.json计算，完整原始结果保留；单步显存非训练全程峰值。
同一稳定候选保持validation，M95原生首层实际选择/索引表与算术差异的机制仍未知。
下一项具体测试是将实际原生首层所选描述及indice表与跨进程坐标对齐差异绑定，
并对后续因果特征测试使用精确保存前缀和原生参数标志，而非新种子或放宽门槛。
四个未到期的人工/范围保留原样不动；不新增占位候选或为填GPU重启FLE。

执行收尾状态与用量以本轮收据及释放核验为准，本文不提前宣称完成。
