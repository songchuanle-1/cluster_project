## 5. Design Rationale

field -> shared-prefix pairing -> observed actual matching ->2x2 sender/receiver
factorial each answer a distinct interpretability gap. Frozen preregistrations
precede each execution and remain separate from this retrospective synthesis.
No threshold, amplitude, sample, seed, schedule or model was selected by result.
Original SPFormer methodology was checked at arxiv2211.15766, sections3.2-3.3:
superpoint-conditioned query decoding and query/mask-feature interaction are
existing mechanisms, not this project's new contribution. This is a bounded
original-source check, NOT an exhaustive novelty review for a new architecture.
Historical rejected cluster-instance-purity and instance-identity-representation
were queried byID and preserved; they were not renamed/reopened. Earlier BCCA,
HDS/FLE and normalization limits remain in force.
