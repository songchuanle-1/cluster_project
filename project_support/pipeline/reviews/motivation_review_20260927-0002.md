# Motivation Review - Physical Seed Context

## 1. Goal
ScanRefer Phase 1 target mIoU 0.5100 remains unmet (M95 0.5020,
baseline 0.4894). The goal requires a concrete, lightweight,
falsifiable structural mechanism, not a selector, pooling change,
renamed ranking loss, or parameter sweep.

## 2. Story Status
Multiscale cluster context is historical benefit; routing was harmful.
The changed-producer frozen TRAIN cohort has 256 expressions, 220 scenes,
56 deployed failures, and a separate failed strict 26/65 historical
cross-capture gate. No candidate is admitted; server-6 GPU7 has two
authorized project slots, with foreign memory occupancy preserved.

## 3. Experiment Assessment
Two new source/hash-bound screens rejected distinct realizations:
physical target semantic conflict occurs in 2/80 exact-class eligible
rows, both successes; all 256 native expressions have one GT instance,
so the synthetic multi-GT mask-index bug has zero exposure. Both have
preregistration, row identities, focused tests and decision receipts.

The existing `m95-sample-context-support` ID was extended beyond its
negative literal-word screen. Exact physical query-seed/class mapping
found 17/17 exposed selected ambiguous failures, one exposed
class-unique success, and 92 selected unresolved seeds. All 18
exposures are among 49 native-negative selected queries; zero occur
in the other 207 expressions. Within-expression all-query score
control has 160 paired expressions/145 scenes, context-class minus
non-context native-negative score +0.11387 on average, positive in
114/160. This is observational, not a native intervention.

## 4. Gap Analysis
`sample_loss` applies exact class-context support to 256 FPS seeds,
halves it, then overwrites matched and top-k seed targets. Deployed
selection scores 128 sampled queries. The frozen capture lacks final
post-overwrite `ref_padding_seed`, top-k seed indices and a component-
isolated gradient comparison. The score association could follow
class semantics, geometry or the known native-negative ranking error.
No same-scene exposure-discordant selected-query control exists.

## 5. Design Rationale
Keep the one stable ID at diagnosis. Bind an exposed and matched
non-exposed frozen native batch, record original and final seed
targets, repeat unmodified forward, then remove only unmatched
non-target class context versus a count/class/instance-matched
placebo while all other loss components remain fixed. The first
readout is whether the intended target/gradient changes separately
from referent selection; no benefit or novelty claim follows.
Native backward, resources, independent model/config and all goal
constraints remain unverified.
