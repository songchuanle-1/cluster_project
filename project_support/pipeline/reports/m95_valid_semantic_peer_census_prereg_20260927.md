# Valid-semantic missed-support peer census

Stable candidate `m95-sample-context-support`, diagnosis only. On the immutable
256-expression M95 TRAIN capture and its exact saved query artifacts, test whether
the prior same-class proximity comparison used actual class identity or the
unknown semantic sentinel `-100`. No fitting or cohort replacement.

For every manifest row, bind scene, annotation, native mask/logit threshold
and physical-instance axis. Classify the modal target semantic label as
unknown (`<0`) versus valid (`>=0`). Count target superpoints missed by all
128 final masks. For valid-class cases, count unseen non-target superpoints
with the same valid category and a nonnegative physical-instance label.
Report all 256 rows, disjoint strata (16 preselected mask-limited, 16
target-size-matched covered controls, and the remaining 224), scene
denominators and the exact four fragmented row IDs. The primary readout is
how many missed-target rows have an actual same-class peer under this
definition, compared to the older sentinel-permissive comparison.

If most previously eligible limited rows used unknown labels, the earlier
same-class conclusion is invalid, and any proximity mechanism must await
a valid category diagnosis. This is a source-contract test, not a model
intervention, training benefit or admission.
