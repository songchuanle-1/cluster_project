# Query-support frequency specificity screen

Stable diagnostic ID `m95-sample-context-support`; frozen M95 256-expression TRAIN capture and SHA-bound feature artifacts. Read `query_masks` from the exact same forward, never use target labels to choose queries or change prediction. Predefine per-superpoint frequency as the fraction of all 128 query masks covering it. Only for retrospective readout, compare the mean frequency on physical target superpoints to the mean on all *other physical instances of the same semantic category* in the same expression. Require a nonempty target and same-category physical competitor; report missing denominators rather than imputing zero.

Primary comparison: all 16 no-adequate-mask expressions against eligible 240 covered expressions, with scene counts, per-expression contrast and direction. Also report any same-scene mixed-outcome paired differences. Prediction-blind query frequency is observable, but physical target identity/category is not an inference-time gate. A failure-specific lower target-versus-competitor frequency would indicate a possible missing selection signal; a shared frequency loss or null contrast would disconfirm this specific route. Duplicate-mask suppression and score/ranking are previously closed, so even a positive screen does not authorize their relabeling. This is diagnostic only; no admission without a novel information/supervision unit, matched causal controls, native full-model backward, same-standard resources, independence and goal constraints.
