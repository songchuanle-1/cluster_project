# Modality support integrity before causal design

Stable `m95-sample-context-support`, diagnosis. The pre-fusion
`1-cos(projected_2d, projected_3d)` screen retained a positive target-minus
hard-peer contrast in only two fragmented scenes. Before interpreting it,
measure actual projected 2D and 3D vector norms on the same frozen 26 rows
and exactly the already selected target/peer pairs from the hard-peer test.
The modality cosine is meaningless if zero/missing image support dominates
the target side. Report the minimum, median and fraction of exactly zero
vectors on each side and the matched norm ratios. Do not reselect controls,
choose an epsilon after results, or convert a norm difference into a new
gate. The signal survives this prerequisite only if neither fragmented row
contains zero 2D/3D vectors in the target or matched peer sets. This
is support diagnosis, not intervention or admission.
