# Frozen M95 native-group pair audit

- Stable candidate: `m95-sample-context-support` (diagnosis). This is an outcome-blind analysis of the already frozen 31-expression manifest, not a new cohort or efficacy result.
- The original TRAIN config uses `lang_num_max: 4`. The native dataset sorts by scene and partitions each scene's original annotations into four-expression groups. A prior read-only server-6 check verified 55/50 unique annotation IDs ordered 0..54/0..49 in the two frozen scenes; the source code and grouping test are recorded in `m95_native_31_group_coverage_20260928-0414.md`.
- Mapping each frozen pair to its actual within-scene native four-expression group yields **0/30 exposed-control edges sharing a native group**, and **0/11 exposed expressions with any same-group control**. The 30 edges re-use 20 distinct controls and are not independent.
- In the planned native TRAIN capture, each group invokes `source.__getitem__` independently. Original TRAIN config enables augmentation/elastic transform; `gorilla.set_random_seed(1999)` is called before each model forward but after the loader has materialized that group's transformed input. The matched descriptions therefore do not have a guaranteed identical geometry/FPS path. They also differ in multiple text tokens. Descriptive outcome deltas from the 31-row capture cannot establish the causal effect of context support even when grouped by scene and physical target.
- Rejection criterion for a causal interpretation: all frozen pairs fail the same-native-group control requirement. This does **not** reject the candidate's unresolved task hypothesis, and it does not cancel the preregistered descriptive capture.
