## Necessary Distinction
Write the existing candidate scores as s(X,t)=h(Z(X,t)), where X is the complete
available scene input, t the expression and Z all inputs actually received by
the downstream computation under examination. Candidate IDs must be aligned.

A structural indistinguishability claim requires an explicit pair (X,t),(X',t')
for which Z is identical under a documented correspondence but the required
candidate ordering differs. For deterministic h, equal Z entails equal scores,
so both incompatible strict target orderings cannot be satisfied. This is a
conditional algebraic statement, NOT an observed property of M95.

Showing that one argument is unused is insufficient: its information may reach
Z through other paths. Approximate feature equality is also insufficient without
a sensitivity bound. No such real-input pair or bound has been established.
Failure to find one does not establish that the model uses relations correctly.
