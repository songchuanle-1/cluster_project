# Frozen same-target expression discordance screen

Independent diagnostic route `m95-same-target-description-discordance`; do not relabel prior mask-support or contrastive/ranking candidates. Freeze the M95 256-expression TRAIN capture SHA256. For every unordered pair of distinct expressions from the same scene and same physical target-instance tuple, compare deployed selected IoU >0.5 and whether any native query has IoU >0.5. Use different-target pairs within the same scene as a negative control; report pair and distinct-scene denominators and all pairs, with duplicate annotations or unavailable target IDs excluded. No threshold search.

An error where one description has an adequate native mask and another description of the same physical target has no adequate mask could indicate expression-conditioned mask-generation discordance; otherwise same-target consistency is a selection/ranking issue or lacks exposure. The earlier 128-expression same-target census found eight success disagreements with both sides adequately covered; this full-capture test checks whether the unresolved no-mask subgroup exists at all. Same-target labels are oracle readouts, not an inference-time available signal. Even positive diagnosis requires an independent causal information/supervision unit, same-forward controls, native backward, resources, independent code and goal constraints; generic consistency loss or renamed selector is not admitted.
