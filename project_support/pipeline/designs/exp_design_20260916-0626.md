## 3. Analysis & Direction
Let F[S,d] be pre-language scene features; FPS seeds f[K,d] are already present.
An independent instance branch predicts logits A[K,S] from seed and point
projections. P=sigmoid(A). Each seed with valid owner k has TRAIN label
u_ks=1[instance(s)=owner(k)];invalid seeds are ignored,not background.
Use BCE+Dice with the parent's existing mask coefficients. This auxiliary branch
does not receive referent labels or overwrite the native fallback matcher.
The original target branch predicts T[Q,S]=sigmoid(B),supervised unchanged.

Normalize P and T over valid support to probability masses p and t. For fixed
heights z, define H_ks=sum_{j:z_j>z_s}p_kj and L_ks=sum_{j:z_j<z_s}p_kj.
Define r_qk=[sum_s t_qs H_ks,sum_s t_qs L_ks].
Compute H,L by one stable sort and tied-group exclusive prefix sums.
No dense SxS attention;cost O(SlogS+KS+QKS),storage O(KS+QS+QK).
Each r_qk retains a single instance index;do not collapse P over category first.
Vertical coordinates use the same native support for both branches.

Instance visual descriptor v_k=sum_s p_ks F_s.
Proposed final query read has affinity
e_qk=(Wq q_q) dot (Wv v_k)/sqrt(d) + (Wr q_q) dot r_qk.
Values are Wv v_k;read softmax_k(e_qk) values using a final query attention
update before final mask/indicator prediction. q_q already includes language.
This is a complete forward proposal,not a proven new mechanism.
Projection width would inherit parent256,not be scanned;full cost may fail10G.
Zero-support instances excluded;if none valid,identity update.

Gradient boundaries:auxiliary owner loss reaches A branch only directly;
target loss reaches B/nativebranch and may reach A via the relation read.
Shared backbone gradients may interact;separate mask outputs do NOT imply
orthogonal shared-parameter updates. No detach chosen to conceal this interaction.
No GT masks,owners,categories or anchorIDs are inputs at inference.
