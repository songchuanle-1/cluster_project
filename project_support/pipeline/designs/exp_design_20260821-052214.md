## 1. Motivation（为什么设计这批实验）
  - 项目动机（直接引用 goal.json description）: "cluster: 多尺度 cluster context 机制 —
    cluster bank 聚合点云特征→cluster_attn 把多尺度 context 回写更新 inst_feats→提升
    定位精度。注: 原'聚类路由'假设已被证伪(routing 生效反降点), 收益来自 context 而非
    routing。目标 mIoU ≥ 0.51"
  - 故事线当前状态:
    已验证: 多尺度 context 有效 (+0.0118); CTF+HCG 1层 ~0.501; MLay (2层 legacy) 单 seed
      0.5010; detail 独立有效 (D1=0.5003)
    已证伪: routing / CSORT / ORT / MEMBANK / SRL / QMOD(gate) / CSF/XCA / gate系
    已排队 (M115-M119): CCL/CGA/BCF/LCC/MFP — 全部 encoder-side cluster token 机制
    已运行 (M120/M121): MLay seed 对照 + 2层×detail 组合
    缺口: **decoder 侧从未直接访问 cluster tokens** — 所有机制都只改进 encoder 侧
      cluster token 表示/交互, writeback 是单通道有损和 (inst_feats + gate*message),
      decoder 只看到有损后的 inst_feats
  - 触发原因: 队列深度 waiting=5 < 可用卡数5+1=6; server-4 队列 4 waiting,
    server-6 队列 1 waiting, 需补 1 个新方向
  - 这批变体在故事线中的角色: 验证假设X — "0.501 平台源于 writeback 有损瓶颈;
    decoder 直接 cross-attend 多尺度 cluster tokens 可绕过瓶颈"

## 3. Analysis & Direction（方向分析）
  ### 3.1 哪些方向有效（> baseline）
    - 多尺度 context 深度 (2层 legacy): M86=0.5010, γ=+0.0116 — 无解相关机制即达
      champion 水平
    - CTF+HCG 1层: M81=0.5012, γ=+0.0118 — 核心架构确定
    - detail message: D1=0.5003, γ=+0.0109 — 消息粒度独立有效
  ### 3.2 哪些方向失败（< baseline 或持平）
    - QMOD (gate 版 decoder query 调制): 0.4930 — gate 实现失败, 但作用点=writeback message
    - CSORT / ORT / MEMBANK / SRL / CSF / XCA: 均关闭
    - ctf_hcg 模式 2层 (M96=0.4940): 多层注入退化仅限该模式
  ### 3.3 哪些尚未消融
    - **decoder 直接访问 cluster tokens** (DCA): 从未尝试 — 新计算图 (decoder query ↔
      cluster tokens attention), 绕过 writeback 单通道有损瓶颈
    - 已排队 CCL/CGA/BCF/LCC/MFP (M115-M119): 全部 encoder-side, 等运行
    - MLay seed 稳健性 (M120/M122): 已运行/排队
  ### 3.4 结论
    - 0.501 平台不随 encoder-side 机制变化 → 瓶颈可能在 writeback→decoder 通路
    - DCA 是唯一未探索的结构轴, 直接验证"writeback 有损瓶颈"假设
    - 与已排队批次完全正交 (encoder-side vs decoder-side), 可并行

## 7. Risk Assessment（风险评估）
  - 代码风险: 中。新 model 包 + dec.py 修改 (decoder 层新增 attention 分支)。
    复用现有 CrossAttentionLayer, forward 逻辑简单 (qia→qca→qla 串联)。
    cluster_tokens 形状 [B, K_lvl, C] 经 cat(dim=1) → [B, ΣK, C]; pad 掩码用
    (abs().sum(-1)==0) 识别 — 与 encoder 侧 bank 填充一致
  - 资源风险: 低。qca 为 d_model=256 标准 CrossAttentionLayer (~0.26M 参数/层),
    FLOPs 增加 <2%; server-4 RTX5090 显存充足
  - 数据风险: 无。同一 ScanRefer 数据
  - 失败回退: 如 crash 3 次 → 放弃 DCA, 标记 question; 资源回已排队 M115-M119 批次
