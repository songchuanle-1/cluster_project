## 3. Analysis & Direction（方向分析）
  ### 3.1 哪些方向有效（> baseline）
    - context 回写 (A1): 0.5012, γ=+0.0118 (核心, 已确认)
    - decoder-access 轴 DCM (qla): 0.5010, γ=+0.0116 (方向①最优)
    - 多层注入 MLay (2层 legacy): 0.5010, γ=+0.0116 (方向②)
  ### 3.2 哪些方向失败（< baseline 或持平）
    - {② legacy}×{qla} (M126): 0.4980 — 组合不叠加 (本 tick 新证据)
    - ctf_hcg 2层 (M96): 0.4940 — **退化, 这是 M138 的 base 问题**
    - DCMV qia 单轴: 0.4950 — qia 视觉通路访问 cluster KV 弱
    - MFP/CSORT/encoder-token 质量轴: 全灭
  ### 3.3 哪些尚未消融
    - **{② legacy 2层}×{DUAL 双通路}: 未测** (本次设计 M139, 用正确 legacy base)
    - M138 已排队但 base 错误 (ctf_hcg) → M139 是其修正版, 构成消融对
    - seed 矩阵: M135/M137/M122 queued
  ### 3.4 结论
    - 平台 ~0.501-0.502 由 seed-1999 决定, 单轴机制已到天花板。
    - M126 证明组合不叠加; M138 的 base 缺陷需修正。剩余唯一未测且正确的结构格:
      legacy 2层 × DUAL 双通路。若该格不破顶, 当前机制空间已探尽。
