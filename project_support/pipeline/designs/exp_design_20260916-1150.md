## 3. Analysis & Direction
### 3.1 Defect, stated numerically
Of the queries whose own predicted masks reach IoU > 0.5 with the referred instance,
783 carry the referent label and 2455 carry the no-object label. The discriminator is
provenance (did the query's seed superpoint fall inside the referred instance), not the
hypothesis. The head accordingly scores .848 for (seed+, mask-) and .130 for
(seed-, mask+), and 27.3% of expressions select an unacceptable query although an
acceptable one exists.

### 3.2 Mechanism
Referent target t_i = IoU(mask_i, referred instance); referent loss = BCEWithLogits
on the existing logit s_i; no seed-derived term anywhere in the referent supervision;
architecture, query set, matcher, mask losses, score loss and contrastive term
unchanged; training from the existing checkpoint with epochs=50 / max_iters=70
unchanged.

### 3.3 Whole-mechanism difference vs prior art (required by the goal)
| Work | What it changes | Why it does not cover this defect |
|---|---|---|
| RefMask3D (2407.18244v1) | one-to-one Hungarian assignment then cls+BCE+dice on the matched object, plus contrastive | changes *which* query is positive; the 2455 mask-OK duplicates remain no-object, so the contradiction is untouched |
| DETR-style set prediction | one-to-one matching with a set loss | same argument |
| IoU/quality-aware classification (2D dense detectors) | confidence tied to localisation quality per anchor | no seed-derived positives and no provenance notion; the defect here is created by provenance |
| set / cardinality losses | mass normalisation across a positive set | changes normalisation, not what the label depends on |
| mask-aware contrastive alignment | re-weights existing scores | re-weighting was measured to fail (23 variants, nonlinear probe 59-65% vs 87.0%) |

The claim under test is narrow and falsifiable: **making the referent label depend on
the hypothesis instead of on the hypothesis's provenance.**

### 3.4 Phase 1.6 smell check
- New computation graph: yes - the referent target becomes a differentiable function of
  the predicted mask, changing the loss landscape; not elementwise rescaling of an
  existing score.
- Hyperparameters: none introduced. g is fixed to identity; no weight, temperature,
  threshold or window is free. A BCE weight already exists in the criterion's
  loss_weight vector and is not changed.
- Not summarisable as "added a LayerNorm / Linear(d,d) / sigmoid gate at X": no module
  is added and no parameter is created; the change is to the loss's dependence
  structure.
Verdict: PASS on the three criteria; no smell signal applies.

## 7. Risk Assessment
The head may ignore a soft target and keep ranking by whatever residual seed
information survives in the query embedding; P1 is designed to detect exactly that. A
second failure mode is that the head simply tracks the mask head's quality without
improving selection, detected by the third rejection condition. A third is that the
contradiction is not the true cause even though removing it causally helps in the
oracle test - the intervention established causality for *restricting to positives*,
not for *relabelling negatives*, so this variant tests an inference, not a measured
fact. That inference is the main scientific risk and is stated as such.

Resource risk is low: one elementwise IoU per query, no new parameters. Data risk is
none: no new dataset or annotation. If the first screen fails its pre-registered
criteria the branch closes with no successor, per the branch-stop constraint.
