## 3. Analysis & Direction（方向分析）
  ### 3.1 哪些方向有效（> baseline）
    - context 回写 (A1): 0.5012, γ=+0.0118 (核心, 已确认)
    - decoder-access qla (DCM): 0.5010, γ=+0.0116 (单通路最优)
    - 多层注入 legacy 2层 (MLay): 0.5010, γ=+0.0116
  ### 3.2 哪些方向失败（< baseline 或持平）
    - {qla,qia} 双通路 (M134): 0.4970 — 不叠加
    - {②}×{DCA,DCM,DCMV}: M125/M126/M136 — 全部不叠加
    - MFP/CSORT/CTF token-FFN: 全灭 (无监督 token 变换无增益)
  ### 3.3 哪些尚未消融
    - **cluster token 同尺度实例判别 (CLICA)**: M140 queued
    - **cluster token 跨尺度实例一致 (CSIC)**: M141 queued
    - **双监督交互 (CLICA×CSIC)**: 未测 (本设计 M142)
    - {MLay 2层 legacy}×{DUAL}: M139 queued
    - seed 矩阵: M122 / M137 queued
  ### 3.4 结论
    - 平台瓶颈在 cluster token 信息量。CLICA (判别) 与 CSIC (一致) 是两条独立
       loss 路径, 已 queued。本设计补第三条组合格 — 双监督交互测试。
    - 若双监督叠加 (γ≥+0.003) → 判别性与一致性独立贡献, 信息瓶颈可被联合修复;
      若 ≈0.501 → 与单测交叉确认"loss 监督轴饱和", 平台需范式级新方向。
