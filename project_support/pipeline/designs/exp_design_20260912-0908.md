## 3. Analysis And Direction

### 3.1 Effective directions

- Multi-scale context remains the historical champion family; it is not a new
  mechanism claim.
- Frozen D1 evidence supports candidate competition, not candidate absence.

### 3.2 Failed or closed directions

- Per-bank calibration, quality-head reranking, language-support reranking,
  semantic-projection reranking, simple mask-conditioned selection, and early
  decoder-layer selection are closed.
- Decoder-layer selection-mask gradient alignment is weak and mixed.

### 3.3 Remaining unmeasured locus

- Text encoder, 3D backbone, scene encoder, and decoder-common parameters.

### 3.4 Conclusion

Run one bounded upstream parameter-group audit before declaring the existing
checkpoint incapable of a joint selection-mask direction. Do not train the
result.

## 7. Risk Assessment

- Code risk: reuse of the frozen diagnostic path; no model package edits.
- Resource risk: gradients for all upstream parameters require more memory
  than the decoder-only audit; use a 7 GiB process cap and 2 GiB free-memory
  guard.
- Data risk: repeated mining of the same 284 validation-derived banks; this is
  exploratory and cannot be presented as independent confirmation.
- Failure fallback: if the group audit is not resource-safe, record the
  failure and retain the existing decoder-level closure; do not switch to a
  renamed selector or enqueue training.
