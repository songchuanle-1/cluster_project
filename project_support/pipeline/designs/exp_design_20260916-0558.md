## 3. Analysis & Direction
Candidate computation considered: predict per-support category probabilities
s_c(j) from visual features, supervised by existing raw TRAIN labels. Transform
each category support into spatial distance fields; use phrase category and
predicate to obtain scene-relative features for the existing decoder. Labels
would be loss-only, never inference inputs. This is not yet an admitted architecture.

For fixed coordinates x, a possible min-plus field is
D_c(x)=min_j (distance(x,x_j)-log s_c(j)).
Away from ties, gradient with respect to winning probability is -1/s_c(j);
other support gradients are zero. Empty supports need explicit missing state.
The coefficient between meters and negative log probability lacks justification;
no arbitrary temperature/unit conversion may be selected to pass admission.
Brute all-support computation is quadratic and cannot be deployed; exact spatial
acceleration or a bounded graph would need a separate approximation analysis.
Hard support transforms remove probability gradients instead of solving this.

Critical information contract: deterministic transforms of a category union
cannot reconstruct its instance partition. Two points can belong to one object
or two; union distance fields remain identical but a same-object conjunction
can differ. Even exact target-mask exclusion cannot restore other partitions.
Seven static checks pass; this rejects the field-only binding rationale, not
all geometry fields or a mechanism retaining independent instance evidence.
