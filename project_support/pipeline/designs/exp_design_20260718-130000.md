## 3. Analysis & Direction（方向分析）
  ### 3.1 哪些方向有效（> baseline 0.4894）
    - cluster_attn 路由: γ=+0.0118 (0.5012 vs 0.4894), 核心增益已确认
    - PosA 编码: +0.0006 (over l1 alone), 小幅增益但方向正确
    - L1 loss: +0.0003 (over posA alone), 边际增益
    - layerscale (C1 当前) 0.4998: 接近 champion, 但 ep19 见顶后连跌, 可能无效

  ### 3.2 哪些方向失败（< champion 且确定）
    - true_route: 0.4468 (-0.0544), 显式路由严重损害性能
    - noroute (posA_l1): 0.4800 (-0.0212), 路由必不可少
    - posB: 0.4953 (-0.0059), 不如 posA
    - posC: 0.4952 (-0.0060), 不如 posA

  ### 3.3 哪些尚未消融
    - **cluster_token refine 机制**: 现有 champion 用 legacy (C2F_ClusterAttn_Lite)
      → refine (MultiScale_Gather_Refine): cluster token self-attn + sigmoid gate + distance cue — 未测试
    - **message_type**: 现有用 context → detail (点-簇独立残差 + 归一化) — 未测试
    - **residual attention**: B5-residual 已在队列, cluster_mode=residual → 补 Q/K/V 梯度 — 待运行
    - **scheduler**: cosine/poly50/step — 训练配方, 低成本

  ### 3.4 结论
    - 核心方向 cluster_attn 路由已确认有效 (γ=+0.0118)
    - 下一步应探索: cluster_token 的 refine 机制、message_type 消息传递方式
    - refine 和 residual 是两种互补机制: refine 增强 cluster token 内部表示, residual 增强梯度流
    - 两者可以独立验证, 成功后可以组合
