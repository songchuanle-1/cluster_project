## 3. Analysis & Direction（方向分析）
  ### 3.1 哪些方向有效（> baseline 0.4894）
    - 多尺度 context 回写: DRP 0.5012, γ=+0.0118 — 核心机制
    - detail message: 0.5003, γ=+0.0109 (D1) — 残差 message 有效
    - 内容自适应融合 (SCF, running), 顺序依赖 (SCT, waiting) — 待验
  ### 3.2 哪些方向失败（< baseline 或持平）
    - readback expressiveness: BIL(0.4919)/NLR(0.4948)/FILM(0.4936)/FLM(0.4865) 全 < champion
    - token 级跨尺度交互: XCA(0.4954)/CSF(0.4958) 无益
    - 组合: M24-ORT-D(0.4955)/M26-ORT-HYB(0.4998)/E4(0.4944) 无叠加
  ### 3.3 尚未消融 / message 构造空白
    - champion: message_l = cluster_token_l (绝对), 逐尺度 gate 融合
    - D1-detail: 融合后单残差 layer_norm(point − fused_msg)
    - **PSR (本次): 逐尺度残差 layer_norm(point − cluster_token_l), 再逐尺度 gate 融合**
      两个正交维度的空白格: {残差 message} × {逐尺度(pre-fusion)}.
  ### 3.4 结论
    - D1-detail (0.5003) 证明"残差 message"有效但略低于 champion (0.5012) — 融合后单残差
      把所有尺度的偏差混合成一个标量残差, 丢失"该点相对各尺度簇的偏差"的尺度分解。
      边界点/离群点相对细簇(256)偏差大、相对粗簇(8)偏差小; 融合后单残差稀释了这个信号。
      PSR 在融合前逐尺度取残差, 让 per-point gate 自主决定每尺度偏差的权重 — 是
      "残差 message" 与 "逐尺度信息分解" 的结构性结合, 不与任何已跑变体重叠。

    复用 level_gate/point_out_proj, 新增 0 个可学习参数 (LayerNorm 无参数)。不涉及 CUDA 扩展。
  - 资源风险: 无。无新增参数/FLOPs (LayerNorm O(NC)), 远低于 FLOPs≤10G 约束。

## 8. Smell Check（Phase 1.6 调参气味检测）
  - 气味信号: rule 3 表面命中 ("数值分布") — 残差 = point − token 是数值变换?
  - 辩护 (通过三标准):
    1. 新计算图结构: message 从"簇的绝对表示"变为"点−簇的逐尺度偏差", 信息流路径改变:
       点特征在融合前与每个尺度的簇 token 直接相减产生 S 个独立偏差信号, 而非 champion 的
       S 个绝对 token 或 D1 的融合后单残差。这是一个新的信息聚合路径, 不是对同一信号的
       数值缩放 (残差保留了尺度分解, 而非单一数值分布调整)。
    2. 超参有依据: 无新超参 (LayerNorm 无参数; gate/out_proj 复用 champion 默认)。
       非"先试中间值"。
    3. 因果机制清晰: "边界点相对细簇(256)偏差大, 相对粗簇(8)偏差小; 融合后单残差 (D1)
       把多尺度偏差混合成一个标量, 稀释尺度信息。PSR 在融合前逐尺度保留偏差, per-point
       gate 可对每尺度偏差独立加权 → 精确利用 '点相对哪个尺度簇偏离最多' 的定位线索"。
  - 判定: 无实质气味信号 (结构性 message 构造变化, 非调参), 正常入队。
