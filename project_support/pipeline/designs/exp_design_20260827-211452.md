## 3. Analysis & Direction（方向分析）
  ### 3.1 哪些方向有效（> baseline）
    - context 回写 (A1): 0.5012, γ=+0.0118 (核心, 已确认)
    - **cross-scale orth (CSORT): 0.5020 (唯一破 0.5012 平台)**
    - legacy 2 层 (MLay): 0.5010
    - detail message (D1): 0.5003
    - CSORT 位置 (token/message): M109=0.5010 非关键变量
  ### 3.2 哪些方向失败（< baseline 或持平）
    - 结构变换: C2C/CSF/FLM/pool/TrueRoute 全灭
    - 通路组合: M125/M126/M134/M136/M138/M139 全不叠加 (5 次, 正式关闭)
    - 判别性 loss: M140-CLICA=0.4970
  ### 3.3 哪些尚未消融
    - **champion CSORT × detail message_type: 未测 (本设计 M146)**
    - champion CSORT 全尺度对 (M145 queued) / loss 监督轴 (M141-144 queued/running)
    - CSORT × MLay legacy@2: 未测 (留作 M146 后的候选)
  ### 3.4 结论
    - 组合轴关闭的是 delivery×delivery 同类结构组合; CSORT×detail 是跨类组合
      (正则化 × delivery), 位点正交, 未被先前失败覆盖。两者均单独有效且是
      当前 top-3 机制, 组合格是最高性价比补格; 纯 config 实现, 零 crash 风险。
