## 3. Analysis & Direction
### 3.1 Definitions
The model partitions superpoints by FPS into 256/64/8 clusters. For a cluster c let
S(c) be the set of distinct native instance ids among its member superpoints; c is
mixed iff |S(c)| >= 2. A target superpoint is contaminated at level l iff its
level-l cluster is mixed. The "winner" is the scene instance with the largest
overlap with the selected query mask.

### 3.2 Executed results (fixed 16 TRAIN batches, M95 eval forward)
| Quantity | l0 (256) | l1 (64) | l2 (8) |
|---|---|---|---|
| mixed-cluster fraction | .2669 | .6477 | .9746 |
| target superpoint contamination, all | .4823 | .8901 | 1.0000 |
| target superpoint contamination, success (85) | .4383 | .8902 | 1.0000 |
| target superpoint contamination, failure (38) | .5806 | .8901 | 1.0000 |
| wrong winner shares a cluster with target (33 wrong) | .1818 | .3030 | .5455 |

Null control on the same wrong cases: the average other instance in the scene
shares an l0 cluster with the target in .0667 of cases, so co-clustering is
enriched about 2.7x. Centroid distance: wrong winner 2.0315 m vs average other
instance 2.8441 m.

### 3.3 Conclusion
The strong form of the hypothesis is refuted. Geometric cluster mixing is enriched
among wrong selections but is absent in 81.8% of them, so an instance-pure
partitioner cannot explain most same-name errors. Contamination of the target's
own evidence is real (48.2% at l0; 58.1% on failures vs 43.8% on successes) and is
recorded as a stable representation fact with a weak causal link.

contamination is partly unavoidable and partly definitional at coarse scales.

independent samples. The winner proxy uses mask overlap, not the matcher's own
association. No efficacy, novelty or resource claim is made.
