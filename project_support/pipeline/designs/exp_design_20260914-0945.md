### 3.2 Variables And Objective Derivation
One expression, Q=128 valid queries, N valid superpoints, post-augmentation
coordinates x_n in R^3, binary target mask y_n from existing instance labels.
Use the original target mask construction, NOT an oracle candidate mask.
Skip invalid/no-target or zero-spatial-extent samples and count each reason.
For multiple target IDs use their mask union, not the nearest target.
Superpoints have unit mass, consistent with existing mask BCE/Dice; no new
point-count weighting. Coordinates/labels are detached training targets.

Let l_qn be final mask logits; d_q = indis[q,1]-indis[q,0].

    m_qn = sigmoid(l_qn)
    a_q = log(sigmoid(d_q))
    alpha_q = softmax_q(a) = sigmoid(d_q) / sum_r sigmoid(d_r)
    b_qn = m_qn / sum_j m_qj
    p_n = sum_q alpha_q b_qn
    t_n = y_n / sum_j y_j

Compute b using softmax_n(logsigmoid(l)) and a with logsigmoid for stability.
Exclude padding before normalization. No temperature, epsilon mass, top-k,
learned scalar, learned transport matrix or adjustable loss weight.
alpha preserves the deployed selection ordering; p is TRAINING ONLY.
The normalization itself is standard, not the proposed contribution.

Take D=||max_n x_n - min_n x_n||_2. For each a in {x,y,z}, sort coordinates
by pi_a, and define k=1,...,N-1:

    delta_ak = (x_pi(k+1),a - x_pi(k),a) / D
    C_ak = sum_{i<=k} (p_pi(i) - t_pi(i))
    L_SCM = (1/3) sum_a sum_k delta_ak |C_ak|.

Derivation: move probability mass along each ordered spatial axis; the net mass
crossing each interval is its prefix imbalance C. Unit transport cost is interval
length, giving sum delta*|C|. Average the three physical axes to retain their
symmetry. This is an exact 1D W1 cost per marginal, a finite-projection
pseudometric, NOT exact3D transport or a novel OT distance.
D makes the objective invariant to translation and positive isotropic scaling.
Three axes are fixed physical coordinates, not a sampled/swept direction count.
L_SCM is bounded by1; no claim that its gradient scale matches Dice.

Change ONLY final-layer mask Dice:

    L_new = L_M95 - w_Dice * L_final_Dice + w_Dice * mean_valid(L_SCM)

Existing w_Dice=1.0 retained. All intermediate-layer Dice/BCE, final BCE,
indi CE, semantic alignment, sampling loss and CSORT remain unchanged.
Replacing rather than adding avoids a new mixing coefficient but remains a
substantive loss change. Different reduction versus matched-query Dice is part
of this intervention; matching controls below share the same reduction.

Training graph: final indis + final masks -> mixture p -> ordered spatial
prefix sums -> target-distribution discrepancy. Both prediction branches get
the same output-level supervision; inference stays M95's argmax indis mask.

### 3.3 Gradients And Testable Mechanism
Choose sign(0)=0, and:

    g_n = (1/3) sum_a sum_{k: rank_a(n)<=k} delta_ak sign(C_ak)
    h_q = sum_n g_n b_qn
    h_bar = sum_q alpha_q h_q
    dL/dd_q = alpha_q (h_q-h_bar) (1-sigmoid(d_q))
    dL/dl_qn = alpha_q b_qn (1-m_qn) (g_n-h_q).

Thus a candidate transporting mass toward an under-covered target region can
receive a favorable selector gradient while its mask receives a spatial
correction. This is not universally beneficial: signs depend on the *mixture*,
and positive/negative query labels remain unchanged.
Unlike candidate-IoU ranking, no oracle or per-candidate quality target appears.
Identical candidate masks imply h_q equal and zero selection gradient.
That is an explicit non-identifiability, not a numerical bug.

Counterexample for the loss bias, NOT an architectural limitation:
unit target mass at x=0 and disjoint predicted unit masses at x=1 versus x=2
have equal Dice overlap but costs1/(3D) and2/(3D) for the same scene.
The loss distinguishes spatial displacement that overlap alone does not.

### 3.4 Degeneracies, Prior Art And Novelty
- Equal axis marginals may hide different joint3D supports: report this null.
- Same centroid is insufficient for zero loss; marginals, not centroids, matter.
- All masks may converge to one target to bypass selection learning. Monitor
  selected performance AND oracle/coverage AND pairwise mask diversity.
- Sigmoid-saturated positive scores/masks can attenuate gradients.
- Very low alpha suppresses a candidate's mask gradient; existing BCE is retained.
- Normalizing masks loses absolute area. Existing BCE and auxiliary Dice remain;
  no claim that SCM replaces all segmentation supervision.
- A soft mixture can look correct while hard argmax stays wrong. Hard inference
  gain is required; mixture-only gain is failure.
- Loss is axis permutation/reflection invariant but not arbitrary-rotation
  invariant. Existing augmentation unchanged; do not use rotation tests that
  silently invalidate spatial language.
