## 3. Analysis & Direction
SCM variables, exact equations, gradients and scientific protocol remain those
of exp_design_20260914-0945 sections3-4:
alpha=normalize(sigmoid(indi1-indi0)); b_q=normalize(sigmoid(mask_q));
p=sum(alpha_q*b_q), t=normalize(binary target union).
Loss averages interval-weighted absolute cumulative (p-t) over the three axes,
normalized by scene diagonal. Replace final Dice only; no inference change.
Complexity O(QN+3NlogN), not N^2. No new coefficients or model parameters.
CPU prototype implements valid-query/SP slicing BEFORE normalization, detached
coordinates/labels, float32 autocast island (float64 for reference checks),
explicit no-query/no-SP/no-target/zero-extent statuses, and rejects valid NaNs.
The prototype is NOT a production criterion or a deployable independent model.

Known risks: identical masks eliminate selector gradients; equal marginals hide
wrong joint support; mixture quality need not imply hard-selection quality;
normalization loses area; saturated sigmoid gradients attenuate.
Source reduction audit adds an explicit magnitude confound: parent matched-query
denominator differs from SCM valid-expression denominator at inherited weight1.
Do not silently change either or tune a replacement coefficient.

Prior-art status: the 0945 source audit already identifies metric-aware output
learning (arXiv1506.05439v3), projected transport (1902.00434v1), and target offset
supervision (2411.03405). Those are prior art, not new contributions.
This tick attempted targeted web queries for grounded segmentation/mixture OT,
plus open/find on arXiv2411.03405v1. Tools returned no usable source content.
No new original-paper verification or search-based absence claim is made.
Exact application novelty remains incomplete; no scientific clearance.
