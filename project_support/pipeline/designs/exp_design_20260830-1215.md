## 1. Motivation（为什么设计这批实验）
  - 项目动机（直接引用 goal.json description）: "cluster: 多尺度 cluster context
    机制 — cluster bank 聚合点云特征→cluster_attn 把多尺度 context 回写更新
    inst_feats→提升定位精度。注: 原'聚类路由'假设已被证伪(routing 生效反降点),
    收益来自 context 而非 routing。目标 mIoU ≥ 0.51"
  - 故事线当前状态:
    已验证: context 回写有效 (+0.0118); M86-MLAY 隔离出**多尺度 context 深度是
    核心收益**; 组合线 (architecture×loss / loss×decoder-access) 多例不叠加
    (M146-CSORT-DET=0.4970 / M147-MLAY-CSORT=0.4970 本tick / M148-CSORT-DCM=
    0.4990); M145-ALL 证伪"多对更好"。
    未验证: ① **CSORT 惩罚对象与交付消息错位** — 约束原始质心, 广播精炼 token;
    ② **粗尺度对 (64↔8) 单独作用域** (M152-F1 只测最细对)。
  - 触发原因: M150 推送后 waiting=4 < 容量4+1=5; server-6 M120 即将早停,
    队内无 waiting 防空转 → 补 2 个 (server-4 + server-6)
  - 这批变体在故事线中的角色:
    M155-RF: **验证假设X (regularizer-消息对齐)** — 去相关轴唯一有效方向上
      从未检查的对象错位; M156-CP: **补全消融网格 (粗对作用域)** — 与 M152-F1
      并行定位 CSORT 有效作用域。

## 3. Analysis & Direction（方向分析）
  ### 3.1 哪些方向有效（> baseline）
    - context 回写 (A1): 0.5012, γ=+0.0118 (核心, 已确认)
    - 多尺度 context 深度 (M86 legacy 2层): 0.5010, γ=+0.0116 (深度=核心收益)
    - cross-scale orth (CSORT): 0.5020 (破平台, seed 脆弱)
    - masked feature prediction (MFP): 0.5020 (破平台)
  ### 3.2 哪些方向失败（< baseline 或持平）
    - 交互/注意力: C2C/CCP/CSF/FLM/pool 全灭
    - loss 监督轴: M140-144 五连败 → 轴关闭
    - **M147-MLAY-CSORT (本tick)**: 0.4970 — MLay×CSORT 组合不叠加
    - M146-CSORT-DET: 0.4970 — CSORT×detail 负交互
    - M148-CSORT-DCM: 0.4990 — CSORT×decoder-access 负交互
    - M145-CSORT-ALL: 0.4920 — 全尺度对扩展失败
  ### 3.3 哪些尚未消融
    - **CSORT 对象对齐 (原始质心 vs 精炼 token): 未测 (本设计 M155)**
    - **粗尺度对单独作用域 (64↔8): 未测 (本设计 M156)**
    - write-back 正交 (soft/hard): M150-OWC(跑)/M151-ODW(队)
    - 全局场景尺度: M154-GSC(队)
    - loss×loss 双机制: M153-MFP(队)
  ### 3.4 结论
    - 去相关轴是唯一破平台方向 (CSORT 0.5020), 但该方向的所有变体都在"loss 的
      范围/组合"上做文章 (M145-152), 从没人检查过**loss 的约束对象**。champion
      里 CSORT 约束原始质心, 消息用精炼 token — 若 FFN 重新混合特征, 去相关被
      稀释。M155 是对象错位的首次检查, 且零新增参数, 是"去相关轴逻辑终点"的
      自然一步。
    - CSORT 尺度范围网格缺"粗对单独"一格 (champion 相邻对 / ALL 全对 / F1 最细对
      / CP 粗对)。M156 与 M152 并行补齐, 定位收益作用域。
    - server-6 资源窗口: M120 即将早停, 队内无 waiting → M156 挂 server-6 队尾
      防空转 (H100 槽位不浪费)。
