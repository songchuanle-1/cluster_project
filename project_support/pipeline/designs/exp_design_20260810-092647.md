    聚合点云特征→cluster_attn 把多尺度 context 回写更新 inst_feats→提升定位精度。注: 原'

  - 故事线当前状态: context 回写确认有效 (+0.0118); detail 确认有效 (D1=0.5003);
    HCG 交付轴闭合 (M65=0.5002 ≈ champion); **本 tick 三终态确认 message×HCG 全负交互

    (M58-DET-DRP 0.498)**; CTF (per-scale FFN 精炼 token) 单独 0.4995 接近 champion
    但从未与任何轴组合; REAGG 修复链 (M78/M79/M80) 在队。

    需补格保持深度。
  - 这批变体在故事线中的角色: **验证 R: token 质量轴 (CTF) 与已闭合的交付轴 (HCG) /
    已确认的 message 轴 (detail) 正交组合是否能破顶** — CTF 分析曾指出 "瓶颈可能不在
    token 质量而在 readback/融合机制", HCG 正是 readback/融合修复, 两者从未正交。
    同时给 REAGG 修复链补上 detail 残差 message 的最后一格。

## 3. Analysis & Direction（方向分析）
  ### 3.1 哪些方向有效（> baseline 0.4894）
    - 多尺度 context 回写: DRP 0.5012 (γ=+0.0118) — 核心机制
    - detail message: D1 0.5003 (γ=+0.0109) — 独立有效
    - HCG 正确交付: M65 0.5002 (γ=+0.0108) — 交付轴闭合
    - CTF token FFN 精炼: M41 0.4995 (γ=+0.0101) — 接近 champion, 从未组合
  ### 3.2 哪些方向失败（≤ champion 或已闭合）
    - 交付轴: HCG 0.5002 ≈ champion — 闭合 (修复短板不破顶)
    - **message×HCG 组合: M66/M67/M68 全部 ≤ HCG 单轴** — HCG 交付轴上叠加 message
      变换无价值 (detail/PSR/SSP 三格闭合)
    - **detail×DRP: M58 0.498 < DRP** — detail 与简洁回写不协同
    - routing: 证伪 (-0.0544)
  ### 3.3 尚未消融 / 结构空白
    - **{token质量 CTF}×{交付 HCG}**: 从未测 — CTF 0.4995 单轴未破顶, HCG 0.5002 单轴
      未破顶, 两轴从未正交 (M81-CTF-HCG 本次填补)
    - **{token质量 CTF}×{message detail}**: 从未测 — CTF 精炼 token 源 + detail 残差
      message, 两轴从未叠加 (M82-DET-CTF 本次填补)
    - **{重聚合修复}×{message detail}**: reag_casc×detail 从未测 — M76 是 reag×detail
      (双缺陷), M79 是级联修复×context, M83 同时修重聚合缺陷 + detail (M83-DET-REAG-CASC)
  ### 3.4 结论
    - 本批三终态 (M58/M67/M68) 再次确认: 组合负交互普遍, 单纯"加 message 变换"不破顶。
    - 但 CTF 是**唯一**接近 champion (0.4995) 却从未组合的机制, 且其分析明确指出瓶颈
      可能在 readback/融合 — 与 HCG (readback 修复) 组合是逻辑上最直接的破顶尝试。
    - 同时 REAGG 修复链 (M78/M79/M80) 已把 {重聚合}×{交付} 2×2 填满, 补上
      {重聚合修复}×{message detail} 格 (M83) 使修复链的 message 轴也闭合。
