## 3. Analysis & Direction（方向分析）
  ### 3.1 哪些方向有效（> baseline）
    - context 回写 (A1): 0.5012, γ=+0.0118 (核心, 已确认)
    - cross-scale orth (CSORT): 0.5020 (唯一破平台机制, 但 seed 脆弱)
  ### 3.2 哪些方向失败（< baseline 或持平）
    - 交互/注意力: C2C=0.4865 / CCP=0.4934 / CSF/FLM/pool 全灭
    - loss 监督轴: M140/141/142/143/144 五连败 → 轴关闭
    - **M145-CSORT-ALL (本tick)**: 0.4920, γ=-0.0100 vs champion — 去相关扩展
      到全对含非相邻失败, 多余/非相邻 loss 项有害
    - delivery×delivery 组合: 6 次不叠加 (关闭)
  ### 3.3 哪些尚未消融
    - **CSORT 尺度范围**: champion=相邻对(2对) / M145=全对(3对, 证伪) /
      **M152-F1=最细对(1对, 本设计)** — 补完第三个点
    - CSORT seed 鲁棒性: M149-SG (修复后) 在队
    - write-back 正交 (soft/hard): M150-OWC / M151-ODW 在队
  ### 3.4 结论
    - 去相关轴是唯一有效方向, 但 M145 揭示其**对 loss 覆盖范围敏感**。M145 往
      "多"方向失败 → 科学上必须往"少"方向对称消融, 确定收益的最小充分范围。
      这既是机制理解 (最细对应是否因果), 也是破平台机会 (若粗对是主动噪声)。

## 8. Smell Check (Phase 1.6)
  - 气味: 无新增模块 (非 LayerNorm/Linear/gate/scaling); 无新数值扫参;
    唯一辩护点: 它是 "在 CSORT loss 上去掉一个 scale 对"。
  - 辩: 这是**结构消融** (goal.json constraints Phase1 明确允许 "新 forward/新
    loss/新模块/**结构消融**"), 不是调参:
    1) 变体验证的是**因果假设** "最细尺度对应是去相关收益的因果位点", 而非
       "试哪个值更好" — 失败结论是 "粗对 loss 必要" (机制结论), 不是 "这个值
       不合适"。
    2) **消融干净性**: F1 保持 /num_pairs=2 归一化, 最细对的梯度贡献与
       champion 完全一致 — 排除 weight 放大混淆; 唯一变化是粗对项缺失。
    3) 有明确新证据支撑 (M145 往多失败 → 对称往少消融), 非拍脑袋。
    4) 无参数增量, 无超参推导需求 (零新增超参)。
  - 判: 无气味信号命中 + 通过三标准 (结构消融新图 / 零超参 / 因果机制清晰) →
    保留, 本段辩护。
