## 3. Analysis And Direction
### Variables And Derivation
For two expressions a,b in the SAME physical scene with single distinct
GT object IDs A,B, let J_a,J_b be actual selected seed SP IDs.
Intersection J=J_a intersect J_b;target sets I_A={j in J:GT_instance(j)=A},
I_B similarly. Require both nonempty;exclude ambiguous/no-instance IDs.
Use strict GT seed membership,not nearest-positive fallback or mask IoU.
All seed index alignment detached;no gradients through sampling/GT labels.
No cross-scene pairing even if object integer IDs coincide.
Duplicates of one object are not negatives;multi-target expressions skipped.

Native score d_a(j)=indis_a(j,1)-indis_a(j,0).
z_aA=mean_{j in I_A}d_a(j),z_aB=mean_{j in I_B}d_a(j),and similarly b.
Define Delta=(z_aA-z_bA)-(z_aB-z_bB).
Repair1 clarification2026-09-14:FPS legitimately repeats physical seeds when
sceneSPcount<256. Define d_r(j) as mean native logit difference over all queries
with physical IDj,before shared-set averaging. Unique-seed case unchanged.
Original uniqueness rejection was an invalid runtime assumption,not a new
scientific exclusion. Bias cancellation remains exact;see bugfix202300.
Likelihood of two possible one-to-one assignments, energies E_correct=z_aA+z_bB
and E_swap=z_aB+z_bA:

    P(correct | one A,one B)=exp(E_correct)/(exp(E_correct)+exp(E_swap))
    L_pair=softplus(-Delta).

Conditioning on column counts cancels additive object salience;conditioning
on one score per row cancels expression intercepts. If z_ro=u_o+v_r+w_ro,
Delta=w_aA+w_bB-w_aB-w_bA. This is a standard conditional-logistic identity,
not new probability theory. Common physical support is essential to cancellation.

dL/dDelta=sigmoid(Delta)-1. Four cell derivatives have signs (+,-,-,+)
times this scalar;each is distributed equally across its matched shared seeds.
Changing any row/column additive offsets leaves loss/gradient exactly invariant.
Under gradient descent on four independent cells,Delta always increases.
Network gradients need not share that guarantee.
Object-swapped GT yields the opposite preference;simultaneous row/column
permutation leaves the likelihood unchanged.

### Training Integration
Independent copy of M95,NOT SCM. Keep full parent loss. Additional pair
observations use inherited final indi coefficient w_indi=.1:

    L_total=L_M95+w_indi * sum_scene mean_eligible_pairs(L_pair)/global_num_matches.

This is a fixed composite likelihood of unary and conditional assignment
observations. Equal coefficient is an explicit modeling choice inherited from
the same score event family,NOT theoretically optimal or magnitude matching.
No sweep,temperature,new head,margin or arbitrary hidden width.
Per-scene pair mean avoids quadratically overweighting scenes with more text.
Ineligible scene contributes connected zero;report coverage and effective mass.
Preserve inherited DDP global matched reduction and gradient scaling.

Loss-only coupling across existing expressions;no query-to-query attention,
no learned gate,routing,contrastive embeddings,IoU rank labels or residual readback.
Inference and all masks/selection/sampling stay unchanged. Zero added inference
parameters/ops expected;must measure with identical historical firstVAL inputs.
Training complexity O(L^2 Q log Q) per scene with L<=4,Q=128,
no N^2 SP tensor. At most6 unordered expression pairs per normal full scene.

### Risks And Prior-Art Comparison
Correct pair assignment does not require BOTH rows correct individually.
For example z=[[10,9],[100,101]] is correct, but other positive-Delta matrices
can keep one row wrong;retain unary CE and evaluate both-expression success.
Shared-seed coverage may be low,especially same-category/distant targets.
Different targets can have valid overlapping context;only target seed identity
is supervised,not a global prohibition on shared masks/context.
Same-target paraphrase consistency is NOT enforced or claimed.
Existing per-expression CE already supplies corrective labels;incremental benefit
is unverified. Training sampler may group homogeneous descriptions and nullify loss.

Original full-text nearest sources checked:
- ConcreteNet arXiv2309.04561 Eq11:sentence/instance cosine InfoNCE,one row,
  temperature. CPS uses native logits,four-cell interaction,shared physical seeds.
- CLIP arXiv2103.00020 Figure3:row/column CE on batch similarity matrices.
  CPS cancels additive row/column biases exactly;not average two row CEs.
- Visual-Semantic Graph Matching for Visual Grounding,MM2020,
  DOI10.1145/3394171.3413902,section3.4.2 Eq16:Sinkhorn assignment+BCE over
  phrase/region graph nodes. CPS conditions two observed descriptions on strict
  shared physical seed memberships;no graphs/Sinkhorn/inference assignment.
- Rank&Sort arXiv2107.11669:per-image candidate ranking/IoU order,not paired
  description-conditioned switching. No IoU order is used by CPS.
The conditional assignment/logistic primitive and broad same-category task
are PRIOR ART. Experimental distinction is native multi-positive seed-intersection
cross-expression coupling. Additional exact-application searches returned no
usable results;search coverage is limited. Admission is for an explicitly
distinct experimental construction,not an exhaustive or first-ever claim.
Source originals stored under reports/;VSGM official author PDF:
https://jingchenchen.github.io/files/papers/2020/ACMMM_VSGM.pdf
