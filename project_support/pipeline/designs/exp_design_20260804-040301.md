## 3. Analysis & Direction（方向分析）
  ### 3.1 哪些方向有效（> baseline）
    - context 回读 (champion/DRP): +0.0118 vs baseline, 确认有效
    - token 正则 (ORT): 0.5005, 接近但未破 ceiling
    - NLR(0.4948) 有效但 < champion; M48-BIL(0.4919) 微弱
  ### 3.2 哪些方向失败（< champion）
    - 读回形式: BIL(0.4919)/NLR(0.4948)/FILM(0.4936)/FLM(0.4865) 全部 < 0.5012
    - 聚合: max(0.4910)/weighted(0.4890) 差于 mean
    - 交互: C2C(0.4865)/CSF(0.4958); 选择: NCR(0.4980); 融合: SWI(0.4970)
    - 尺度: M18[256,64]=0.4933, M19[256,8]=0.4944 (三尺度均有贡献)
    - 组合: M24-ORT-D=0.4955, M26-ORT-HYB=0.4998, E4=0.4944
  ### 3.3 哪些尚未消融
    - **cluster token 二阶统计 (variance)** — 从未测 (优先级: P0)
    - **cluster token 显式空间信号** — 从未测 (优先级: P0)
    - 多 seed 稳定性 (Phase 2 再做)
  ### 3.4 结论
    - 消息内容轴已饱和 (30+ 变体 ≤ 0.5012), 不再设计纯消息内容变体。
    - cluster token 表示 = 纯 mean 特征聚合, 是最后未探明的结构维度。M44/M47/M48/M49
      分析均指向"token 表示质量"; DCA/CCR 已覆盖聚合池化与级联, VAC/SAC 覆盖
      表示内容 (离散度/空间) 两个正交子维度。

## 7. Risk Assessment（风险评估）

    dual); SAC 新增可选 pos_embed + 聚合输入加法 (默认 spatial_emb=False 不影响其他变体)。
    均为 DRP baseline 的物理拷贝, 不影响其他变体。
  - 资源风险: 低。VAC 增加 ~131K params (var_proj); SAC 增加 ~21K params (pos_embed)。
    显存增量可忽略。
  - 数据风险: 无。同一 ScanRefer 数据集。
  - 失败回退: 若 crash 3 次 → 放弃该变体, 记录 question; 队列仍有 M52-CCR + 另一变体补位。

## 8. Smell Check (Phase 1.6)

  ### M53-VAC:
  - Smell signals: 无直接命中
    - #1 (params<5K): 131K params (var_proj Linear(2d,d) 2层 + LayerNorm), PASS
    - #2 (单算子): 二阶统计聚合 (mean + E[x²]-E[x]² → concat → MLP) = 新计算图, PASS
    - #3 (数值分布): 新增二阶统计信息路径 (离散度), 非纯缩放/归一化, PASS
    - #4 (超参): 无 (var 无温度/权重), PASS
    - #5 (换名绕过): 与 banned 的 attnpool/agg (attention 聚合) 不同 — VAC 是 scatter 统计,
      O(N) 无 attention, PASS
    - #6 (找数值配置): 新聚合计算图 (token 携带额外统计量), 非同一信息流改数值, PASS
  - 与 M51-DCA 区别: DCA=mean+max(显著信号), VAC=mean+variance(离散度/不确定性)。
    两者聚合不同的二阶信息; VAC 的因果是"簇可靠性", DCA 是"簇内极端信号"。
  - 因果机制: "mean 池化丢弃簇内离散度; 高离散簇(边界混合)的 mean token 是劣质代表,
    readback 无从折扣。token 携带 variance 后, 下游可隐式利用簇可靠性, 提升边界点定位。"
  - Verdict: PASS

  ### M54-SAC:
  - Smell signals: 无直接命中
    - #1 (params<5K): 21K params (pos_embed 3→64→d), PASS
    - #2 (单算子): 坐标 MLP 编码 + 加到聚合输入 = 新空间信息路径, 非单算子, PASS
    - #3 (数值分布): 新增显式空间输入通道, 非缩放/归一化, PASS
    - #4 (超参): 无 (embed 维度同网络约定), PASS
    - #5 (换名绕过): 与 posA/posB/posC(encoder 顺序) 不同 — 这是给 cluster 聚合输入加
      空间编码, 非任何 banned 机制, PASS
    - #6 (找数值配置): 新空间信息路径, PASS
  - 因果机制: "cluster token 由纯特征均值组成, 无显式空间坐标; 引用表达含空间关系
    ('桌子旁边'), 无空间信号的 token 无法表示场景区域。坐标 MLP 嵌入使 coarse token
    携带空间布局, 直接服务语言定位。"
  - Verdict: PASS
