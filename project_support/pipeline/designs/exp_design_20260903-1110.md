## 7. Risk Assessment
  - Code risk: medium. Cluster ID maps and padded cluster feature tensors must remain
    aligned at each level.
  - Optimization risk: hard branch selection does not propagate mask gradients
    through the selected index, but gradients still reach selected cluster features
    and the output projection.
  - Resource risk: low. Retrieval is O(BQK + BQL), with three hierarchy levels.
  - Failure fallback: normal patience=10 early stop; close hierarchy selection if it
    remains below champion.

## 8. Smell Check
  - M169 changes the information path from all-cluster averaging to one coherent
    fine-to-coarse branch.
  - It is not a threshold, temperature, top-k sweep, normalization, or loss weight.
  - No new tunable coefficient is introduced.
