## 3. Analysis And Direction
Let B be endpoints of GT-crossing contact edges, C the connected components
of G[B], n=|B|, k=sum(y), k_C=sum(y_C), and Z_k the fixed-count partition.
The 1308 identity gives L_c=L_g+log P(component counts|k)/n.
Gradient on component C is (P(i selected|k_C)-y_i)/n.
Component-wise shifts are null directions; a smaller L_c is not efficacy.
Connected B is a negative control because L_c=L_g.
Computing C requires boundary endpoints and contact edges (or saved component
membership), not the connected components of the entire target mask.
Native incidence is therefore a necessary gate, not an optional statistic.
DP cost O(sum_C |C|min(k_C,|C|-k_C)); traversal O(|V|+|E|).
Original-source comparison is incomplete; no new core novelty claim.
