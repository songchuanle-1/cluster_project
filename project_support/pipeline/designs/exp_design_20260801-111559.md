## 1. Motivation（为什么设计这批实验）
  - 项目动机: 多尺度 cluster context 机制提升 3D 定位精度。当前 champion=0.5012，多个方向触碰 ~0.5012 天花板 (ORT=0.5005, CTF=0.4995, ORT-HYB=0.4998) 但无法突破。
  - 故事线当前状态: cluster context 有效确认 (γ=+0.0118)，但 readback 机制可能已达信息提取上限。
  - 触发原因: waiting=2 < 3=2卡+1，需补 1 个变体。
  - 这批变体在故事线中的角色: 验证 "additive readback 是性能天花板" 假设。FiLM conditioning 让 cluster context 选择性调制特征维度。

## 3. Analysis & Direction（方向分析）
  ### 3.1 哪些方向有效（> baseline）
    - cluster context 本身: γ=+0.0118, 核心机制有效
    - DRP (去掉 routing): 性能等价 → routing 是死代码 ✓
    - ORT (正交正则化): 0.5005, near-champion，正则化有边际收益
    - CTF (token FFN refinement): 0.4995, token 质量提升有上限

  ### 3.2 哪些方向失败（< champion 或持平）
    - WCA (weighted aggregation): 0.4890, 学习权重反而有害
    - C2C (cluster-to-cluster): 0.4865, cluster 间 attention 无效
    - XCA (cross-attention): 0.4954, 低于 champion
    - Q2P (query→point direct): 0.4904, 证实 cluster token 中介必要
    - gate 系列 (cag/cfe/layerscale): 均 < champion, scalar gate 无效

  ### 3.3 瓶颈假设
    - 多个方向触碰 ~0.5012 但无法突破 → additive readback 可能是天花板
    - 当前 `feat += gate * message` 对所有维度等权处理
    - FiLM 提供 per-dimension conditioning: `feat = gamma * feat + beta`

  ### 3.4 结论
    - 下一步: M47-FILM — FiLM-conditioned readback。测试 readback 表达能力天花板假设。
    - 优先级: 高。这是当前唯一未测试的 readback 改进方向（NCR 改 assignment, SHC 改 channel split, FiLM 改 modulation paradigm）。
