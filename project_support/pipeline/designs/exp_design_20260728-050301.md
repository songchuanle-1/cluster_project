## 3. Analysis & Direction（方向分析）
  ### 3.1 哪些方向有效（> baseline 0.4894）
    - cluster context (champion): 0.5012, γ=+0.0118 — 核心机制
    - ORT orthogonality regularization (M17): 0.5005, γ=+0.0111 — token 质量提升
    - detail message_type (D1): 0.5003, γ=+0.0109 — message 变体有效但非超越
  ### 3.2 哪些方向失败（< champion 或持平）
    - Message_type 组合 (M24-ORT-D=0.4955, M21-HYB=0.4898, M26-ORT-HYB near champion but not above)
    - Cross-scale attention (M22-XCA=0.4954)
    - Iterative refine (M25-REF=0.4892, M16-CSR=0.4875)
    - Query-gated mechanisms (M1-QGC=0.4939, M6-QSF=0.4866)
    - 2-scale ablation (M18-S2FM=0.4933, M19-S2FC=0.4944)
  ### 3.3 哪些尚未消融
    - Attention structure: nhead variation, hidden_dim variation, dropout — P1
    - ORT optimal weight: M27(w=0.05)/M28(w=0.001) running — P0 (awaiting results)
    - DCA (dual aggregation): M29 waiting — P1 (awaiting slot)
    - ITK (increased topk): M30 waiting — P1 (awaiting slot)
    - Loss function tuning (loss_weight): unexplored — P2
  ### 3.4 结论
    - 下一步选择: nhead=4 (head_dim=64). 理由: (1) attention structure 方向完全未探索, 是最明显的空白; (2) larger head_dim (64→32) 理论上让每个 head 能捕获更复杂的 query-cluster 交互; (3) YAML-only 变更, 零代码风险; (4) 不与其他 waiting 实验冲突; (5) 不违反任何 banned[]/constraints[].
