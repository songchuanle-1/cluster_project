## 3. Analysis & Direction（方向分析）
  ### 3.1 哪些方向有效（> baseline）
    - context 回写: 0.5012, γ=+0.0118 — 核心已确认

    - QMOD/SWI/SEF/gate 族: 0.483-0.493, 已证伪或禁用
    - detail message 组合: 与强基底无正协同
  ### 3.3 哪些尚未消融 / 未验证
    - **champion 第三 seed (S2026)**: 最高优先级 — 完成 champion 3 点 seed 区间
    - **CTF×HCG 第三 seed (S2026)**: 高优先级 — 确认唯一 tie 机制是否真实
    - 多层注入 (M96 queued) / ORT 最后证据 (M97/M98 queued) / champion S42/S123 (M99/M100 queued)
  ### 3.4 结论
    - 选择理由: 08-14 定案 "破顶需跨 seed 验证", 但 champion 与 CTF×HCG 的非默认 seed
      点数不足 (champion 2 点 / CTF×HCG 2 点). 补齐第三点后, 0.5012 是否为 seed1999
      有利值可有统计上更稳健的判读. 这也是后续任何 champion 基底实验 (M97/M98) 的
      判读基准.
