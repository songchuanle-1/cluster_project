  ### 3.1 哪些方向有效（> baseline）

    - routing (A3=0.4468) — 已证伪
    - gate 系 (QGC=0.4939, QSF=0.4866, layerscale 虽高但 stopped) — 已入 banned
    - residual 系 (B5=0.4944, E4=0.4944) — 上限固定, 已入 banned
    - CSR (0.4875) — 低于 baseline
  ### 3.3 哪些尚未消融
    - cross-scale info exchange: 未探索, 优先级 high — 本批设计目标
    - context+detail hybrid: M21-HYB 在 queue
    - orthogonality regularization: M17-ORT 刚启动
  ### 3.4 结论
    - 下一步: cross-scale cluster attention — cluster tokens 在不同 scale 间目前完全独立, 加入交互是最自然的下一步
    - 不与 banned[] 冲突: 不是 gate, 不是 routing, 不是 residual, 不增 N² on points
