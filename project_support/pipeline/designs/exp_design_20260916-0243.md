## 3. Analysis And Derivation
Same scene S,descriptions a,b,target identity y;native augmented SP ordering
identical. Last encoder outputs V_a,V_b in R^(Nxd),language H_a,H_b and
incoming own queries Q_a,Q_b. Native output D(Q_a,H_a,V_a).
Provisional intervention D(Q_a,H_a,V_b);GT remains y because physical scene
and referred object are unchanged. No language tokens or query IDs transferred.
Hypothesis: enforcing supervised prediction under same-target context exchanges
discourages reliance on description-specific visual encoding artifacts.
Training objective,if admitted,would be expected inherited supervised loss under
the finite same-target interchange orbit;not a coefficient sweep or added rankloss.
For each original augmented dataset group,partition expressions by singleton
target identity. Let G be the direct product of permutation groups of those
partitions. Define L(theta)=E_{pi uniform G}[L_parent(F_theta^pi(batch),labels)].
Only final encoder visual state is permuted;parent loss terms,weights and global
matched-count denominator remain unchanged. Auxiliary decoder losses precede
the intervention and remain original. Orthogonality loss remains original.
No additional loss coefficient or tuned exchange probability. A singleton has
only the identity permutation;each m-member group includes identity naturally.
Uniform permutation sampling is an unbiased stochastic gradient estimator since
the finite distribution depends only on labels,not theta. No stop-gradient:
grad_V_j=sum_{i:pi(i)=j}grad_exchanged_i;recipient query/language paths remain.
Native cyclic-permutation probes on two original TRAIN batches have finite
full-model gradients and exact donor-gradient mapping(error0);these probes
do not yet test a production uniform-permutation implementation or AMP.
Permutation is O(BNd);inference identity;native costs UNMEASURED.
Identity/original repetition exact physical-support controls;same-target donor
versus same-scene different-target donor and donor-SP permutation.
No pretrained hard-IoU improvement prerequisite is invented.
But generic interchange alone is prior art,not established core novelty.
IIT original ICML2022 sec2-3 defines state interchange and supervised training;
SwapMix CVPR2022 sec3.3 swaps context object representations.
SelfEQ2312.04554sec3.2Eq7 aligns explanation maps,not scene-state interchange.
This proposal differs from CPS score assignment,closed headtying and routing:
no score ranking,learned routing or changed inference message path.
Potential language-routing overlap must be explicitly resolved before admission.
