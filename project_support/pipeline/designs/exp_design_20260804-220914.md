## 3. Analysis & Direction（方向分析）
  ### 3.1 哪些方向有效（> baseline 0.4894）
    - 多尺度 context 回写: DRP 0.5012, γ=+0.0118 — 核心机制
    - detail message: 0.5003, γ=+0.0109 (D1) — 残差 message 有效
    - token FFN (CTF 0.4995)、soft readback (NCR 0.4980) — 有效但未破 ceiling
  ### 3.2 哪些方向失败（< champion 或持平）
    - readback expressiveness: BIL(0.4919)/NLR(0.4948)/FILM(0.4936)/FLM(0.4865)/DGC(0.4913) 全失败
    - 聚合双分支: DCA(0.4893)/max/weighted < mean — mean 聚合仍最优
    - 融合: XCA(0.4954)/CSF(0.4958)/SWI(0.4970) 无益
    - 组合: M24-ORT-D(0.4955)/M26-ORT-HYB(0.4998)/E4(0.4944) 无叠加
  ### 3.3 尚未消融 / 结构空白
    - **投影放置轴**: champion = 融合后共享单投影 (point_out_proj); SSP = 融合前逐尺度
      独立投影 (scale_projs)。从未测过 (无任何变体改此结构)。
    - 该轴与 message 构造 (绝对/残差) 和融合权重 (SCF/SCT) 正交。
  ### 3.4 结论
    - 30+ 变体全收敛 ≤ 0.5012 天花板, 且所有失败都集中在 message 内容/融合权重/读回形式。
      "融合后单投影" 是所有这些变体共享的最后一个未变的 readback 结构件。细尺度 token
      (实例细节) 与粗尺度 token (场景布局) 语义空间不同, 共享投影是折中 — 逐尺度独立
      投影是直接检验该折中是否是瓶颈的精确探针, 不与任何在队列变体重叠。

## 7. Risk Assessment（风险评估）
  - 代码风险: 低。SSP 仅替换 DRP._cluster_to_points 的投影段 (共享 post-fusion proj →
    逐尺度 pre-fusion projs), 复用 level_gate/融合逻辑。新增 num_scales 个 Linear,
    不涉及 CUDA 扩展/新依赖。
  - 资源风险: 低-中。新增 (num_scales−1)×d×d = 2×256×256 = 131K 参数。FLOPs:
    投影路径从 O(N·d²) → O(3N·d²), 对整体模型 (~G FLOPs) 占比小, 远低于 FLOPs≤10G 约束。
    显存增量仅权重, 无新增激活, 低于 +15% 阈值。
  - 数据风险: 无。复用 ScanRefer。
  - 失败回退: 若 crash 3 次 → 放弃 SSP, 标记 question, 队列深度回落到 5 (需再补设计)。
    本变体与已跑通 DRP 仅差 ~20 行, crash 概率极低。
