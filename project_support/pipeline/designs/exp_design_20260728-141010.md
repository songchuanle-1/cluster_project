## 3. Analysis & Direction（方向分析）
  ### 3.1 哪些方向有效（> baseline）
    - cluster context: champion 0.5012, γ=+0.0118 vs base. Context 回写是核心有效机制
    - ORT orthogonality: M17 0.5005, γ=+0.0111. cluster diversity 正则有效
    - detail message: D1 0.5003, γ=+0.0109. 点级消息等效于 context
    - 三个有效机制均止步于 ~0.5005, 无一超越 champion 0.5012
  ### 3.2 哪些方向失败（< baseline 或持平）
    - true_route: A3 0.4468, γ=-0.0544. routing 生效反降点
    - refine系: M16-CSR 0.4875, M25-REF 0.4892. 两次 refine 均 < baseline
    - 机制组合: all < single mechanism. 组合轴饱和
  ### 3.3 哪些尚未消融
    - context 注入范式: additive 唯一范式，FiLM/gating/modulation 从未尝试 (priority: high)
    - cluster token 交互: intra-scale self-attention 从未尝试 (priority: high)
    - contrastive loss: 非 ORT 的 cluster 多样性 loss (priority: medium)
    - channel-wise 注入: context 按 channel 选择性注入 (priority: medium)
  ### 3.4 结论
    - additive context injection 天花板 ~0.5005 (三个独立机制均到此后无法超越)
    - 下一步: 测试 multiplicative modulation (FiLM) 是否突破 additive 上限
    - 并行测试: intra-scale cluster self-attention 是否提升 token 质量
