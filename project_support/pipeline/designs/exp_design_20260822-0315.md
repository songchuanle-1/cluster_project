## 1. Motivation（为什么设计这批实验）
  - 项目动机（直接引用 goal.json description）: "cluster: 多尺度 cluster context 机制 —
    cluster bank 聚合点云特征→cluster_attn 把多尺度 context 回写更新 inst_feats→提升
    定位精度。注: 原'聚类路由'假设已被证伪(routing 生效反降点), 收益来自 context 而非
    routing。目标 mIoU ≥ 0.51"
  - 故事线当前状态:
    已验证: 多尺度 context 有效 (+0.0118); CTF+HCG 1层 ~0.501; MLay (2层 legacy)
      M86=0.5010; detail D1=0.5003
    已证伪: routing / CSORT / ORT / MEMBANK / SRL / CCL(M115=0.4890) /
      CGA(M116=0.4926) / BCF(M117=0.4926) — encoder-side token 质量轴全灭
    已排队: M123-DCA (decoder 专用分支), M124-DCM (decoder 共享通路)
    缺口: **两个独立有效机制 (2层 context 深度 × decoder 直接访问) 从未组合** —
      当前队列只有单轴 decoder 变体 (DCA/DCM), 没有检验"context 深度与 decoder
      访问方式是否交互"的 2×2 满格
  - 触发原因: waiting=3 (M123/M124/M122) < 可用卡数4+1=5, 需补 2 个新方向
  - 这批变体在故事线中的角色: 组合验证 — "2层 context 深度 (encoder 侧最强) 与
    decoder 直接访问 (唯一未测轴) 是否可加; 若是, 叠加应破 0.501 平台"

## 3. Analysis & Direction（方向分析）
  ### 3.1 哪些方向有效（> baseline）
    - 多尺度 context 深度 (2层 legacy): M86=0.5010, γ=+0.0116 — encoder 侧最强
    - CTF+HCG 1层: M81=0.5012, γ=+0.0118 — 核心架构
    - detail message: D1=0.5003, γ=+0.0109 — 消息构造轴独立有效
  ### 3.2 哪些方向失败（< baseline 或持平）
    - encoder-side token 质量全灭: CCL=0.4890, CGA=0.4926, BCF=0.4926,
      (加 CSORT/ORT/MEMBANK/SRL 已关闭)
    - 结论: ~0.501 平台横跨所有 encoder-side 机制; 瓶颈在 writeback→decoder 通路
  ### 3.3 哪些尚未消融
    - **decoder 直接访问 cluster tokens**: M123-DCA (专用分支) + M124-DCM (共享通路) 排队
    - **2层 context × decoder 访问**: 从未组合 — 本次设计的 2×2 第 3/4 格
  ### 3.4 结论
    - 若 writeback 是瓶颈: decoder 直连 (DCA/DCM) 破 0.501; 若再叠加 encoder 侧
      最强的 2层 context, 应进一步上升 (两轴正交可加)
    - 若两轴冗余: MLay×DCA ≈ DCA 或 ≈ MLay, 说明 context 深度收益已被 decoder
      直连吸收 — 同样推进故事线 (判定哪个机制真正承载收益)
    - 2×2 满格 {1层,2层}×{DCA,DCM} 系统判定交互, 避免单轴结论的混淆
