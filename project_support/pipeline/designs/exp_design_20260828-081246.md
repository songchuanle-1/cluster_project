## 3. Analysis & Direction（方向分析）
  ### 3.1 哪些方向有效（> baseline）
    - context 回写 (A1): 0.5012, γ=+0.0118 (核心, 已确认)
    - **cross-scale orth (CSORT): 0.5020 (唯一破 0.5012 平台, champion)**
    - **decoder qla memory read (DCM): 0.5010 (独立有效 delivery 通路)**
    - legacy 2层注入 (MLay): 0.5010
    - detail message (D1): 0.5003
  ### 3.2 哪些方向失败（< baseline 或持平）
    - 结构变换: C2C/CSF/FLM/pool/TrueRoute 全灭
    - delivery×delivery 组合: M125/M126/M134/M136/M138/M139 6 次不叠加 (关闭)
    - HCG@2 注入: M96=0.4940 (有害; legacy@2 有效)
    - loss 监督轴: M140-CLICA=0.4970 / M141-CSIC=0.4960 (2 连败; M142/143/144 检验中)
  ### 3.3 哪些尚未消融
    - **champion CSORT × decoder qla memory read (DCM): 未测 (本设计 M148)**
    - champion CSORT × detail: M146 queued
    - champion CSORT × MLay legacy@2: M147 queued
    - champion CSORT 全尺度对: M145 queued
  ### 3.4 结论
    - 组合轴关闭的是 delivery×delivery 同类结构组合; CSORT×DCM 是跨类组合
      ({正则化 loss} × {decoder 读取通路}), 位点正交, 未被先前失败覆盖。
    - DCM (0.5010) 是独立有效 delivery 机制中**最强**者 (detail=0.5003 更弱),
      与 CSORT 组合是 CSORT×delivery 网格中成功概率最高的一点; 与 M146 互补
      (M146=message 构造轴, M148=decoder 读取轴)。
    - 若 M146+M148 均不叠加 → CSORT×delivery 网格两点关闭, 组合边界证据完整,
      故事只剩 loss 轴 (M142/143/144) 与 CSORT 扩展 (M145) 待终态 → 触发范式级
      question 的条件已基本齐备。
    - 实现为 csort 包 + DCM mem 通路移植 (dec.py 4 处), 复用已验证代码路径,
      crash 风险中低 (M124 mem 路径已稳定运行; CSORT 已有成熟实现)。

## 7. Risk Assessment（风险评估）
  - 代码风险: 中低。复制 csort 包 + 从 DCM 移植 mem 通路 (M124 已验证稳定运行);
    dec.py 改 4 处。保留 CSORT 全部代码不动。py_compile + 结构校验。
    若 crash → Phase 3b 自修复预算 ≤3 次。
  - 资源风险: 低。DCM 仅 concat cluster tokens 的 qla 注意力 (M124 已实测 ≤10G);
    csort loss 仅 (8×64+64×256) 对级 abs-cosine → 约束满足。
  - 数据风险: 无。复用 cluster_feats_list + child_cluster_maps。
  - 失败回退: 若 M148 增益 <0.002 → CSORT×DCM 格关闭, 与 M146 构成 CSORT×delivery
    网格边界证据; 若与 loss 轴/CSORT 扩展/在队组合全部不破 → 范式级 question,
    暂停自主设计。
