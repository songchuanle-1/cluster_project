## 3. Analysis And Direction
For independently parameterized Bernoulli occupancies p_i=sigmoid(z_i),
condition a physical crossing edge on one occupied endpoint:
q_ij=p_i(1-p_j)/(p_i(1-p_j)+(1-p_i)p_j)
     =exp(z_i)/(exp(z_i)+exp(z_j))=sigmoid(z_i-z_j).
For oriented target (y_i,y_j)=(1,0), negative log likelihood
L_pair=logaddexp(z_i,z_j)-z_i=softplus(z_j-z_i).
Gradient=(sigmoid(z_i-z_j)-1,1-sigmoid(z_i-z_j)).
Thus descent corrects a reversed pair, unlike unsigned disagreement supervision.
However, this is exactly the RankNet section3 equations(1)-(3) hard-label
primitive (Burges et al., ICML2005; source recorded in upstream review).
It is also twice M196's per-node BCA loss for n=2,k=1.
No source supports a novel primitive claim. Contact pair selection alone does
not establish an independent core mechanism under current admission policy.
IMPORTANT: a sum over crossing edges is NOT generally full-group BCA.
For three nodes, y=(1,0,0),z=(0,0,0), edges(0,1),(0,2):
summed pair loss=2log2, full-group unnormalized BCA=log3.
The discrepancy depends on z; it is not an additive constant.
Both remain invariant to common logit shifts; neither alone calibrates mask
threshold occupancy. Retained BCE could calibrate it; no full-loss failure claim.
Complexity O(|E|), no new parameters/dense attention; empty edge set gives zero.
