## 3. Analysis & Direction（方向分析）
  ### 3.1 哪些方向有效（> baseline）
    - context 回写 (A1): 0.5012, γ=+0.0118 (核心, 已确认)
    - decoder-access 轴 qla (DCM): 0.5010, γ=+0.0116 (单通路最优; 双通路已关)
    - 多层注入 legacy 2层 (MLay): 0.5010, γ=+0.0116
  ### 3.2 哪些方向失败（< baseline 或持平）
    - {qla,qia} 双通路 (M134): 0.4970 — 不叠加, 落在两单通路之间
    - {②}×{DCA,DCM,DCMV}: M125=0.4970 / M126=0.4980 — 全部不叠加
    - MFP/CSORT/CTF token-FFN: 全灭 (无监督 token 变换无增益)
  ### 3.3 哪些尚未消融
    - **cluster token 实例判别性监督 (CLICA)**: M140 queued (同尺度内判别)
    - **多尺度组合的实例一致性 (CSIC)**: 未测 (本设计)
    - {② legacy}×{DUAL} 正确格: M139 queued
    - seed 矩阵: M135 (running) / M137 / M122 queued
  ### 3.4 结论
    - 平台瓶颈在 cluster token 信息量。CLICA (判别) 是第一条 loss 路径, queued。
    - **本设计选择第二条正交 loss 路径 — 跨尺度实例一致性 (CSIC)**: 不依赖 CLICA
      结果, 即使 CLICA 失败 (判别性非瓶颈), CSIC 仍可能有效 (组合一致性是瓶颈)。
      两个独立赌注并行, 任一成功即打开新信息路径。

## 7. Risk Assessment（风险评估）
  - 代码风险: 低。纯 loss 级变更, 复用 CLICA 的 token 暴露机制 (已 py_compile 通过),
    不碰 cluster 注意力主干路径; 训练时开启, 推理不受影响。若 crash → 3 次自修复预算。
  - 资源风险: 低。零新增参数, 对比损失 ~328 token 级 cosine, 显存/FLOPs 增量可忽略。
  - 数据风险: 无。复用 ScanRefer GT 实例标签 (sp_ins_labels + object_idss 已在 loss forward)。
  - 失败回退: 独立实验, 不依赖 M140。若 crash 3 次 → 放弃标记 question, 继续监控
    M140-CLICA 与组合/seed 矩阵。
  - 备注: 若 CSIC 有效 (γ≥+0.003), 可与 M140-CLICA 组合 (判别+一致双监督);
    若无效, 与 CLICA 交叉确认"token 信息量"假设的两个子方向都排除, 平台需范式级
    新方向 (与 M139 结论交叉)。
