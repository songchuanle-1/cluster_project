## 3. Analysis & Direction（方向分析）
  ### 3.1 哪些方向有效（> baseline）
    - context 回写: 0.5012, γ=+0.0118 — 核心已确认
    - CTF×HCG (s1999): 0.5012 tie champion; **CTF×HCG×CSORT (s1999): 0.5020** 唯一活跃破顶候选
    - detail message (A1 基底): D1=0.5003 (γ=+0.0109 vs base), 但 detail×CTF×HCG (M84=0.4990) 负交互 → message 轴不与 CTF×HCG token 质量叠加
  ### 3.2 哪些方向失败（< baseline 或持平）
    - ORT 多样性: M92/M94 均 0.4930 → 轴收窄
    - 多层注入: M96 0.4940 2 层退化; 3/4/6 层 banned
    - QMOD/SWI/SEF/gate/residual 族: 已证伪或禁用
  ### 3.3 哪些尚未消融 / 未验证
    - **readback message 侧去相关**: 高优先级 — M95 只在 token 源侧做相邻尺度去相关,
      per-point 消息在 learned gate 融合时可能重新引入目标侧冗余; 故事线 CTF 分析
      结论"0.5012 瓶颈在 readback/融合"从未在消息侧直接测试
    - CSORT 跨 seed 矩阵 (M98/M103-M108): 已在队, 不重复
  ### 3.4 结论
    - 选择理由: CSORT 是唯一 > champion 的活跃方向, 但 M95 只覆盖源侧 (token) 冗余;
      若 message 侧冗余是 0.5012 平台的残余瓶颈, 目标侧去相关应 > token 侧 →
      直接补"去相关目标轴"缺失格, 与矩阵结果正交 (无论 CSORT 跨 seed 是否成立,
      M109 都回答"message 侧是否需单独去相关"这一独立问题)。
