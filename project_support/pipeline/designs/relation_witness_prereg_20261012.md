# Relation Witness Diagnosis

## Frozen Question
Candidate: m95-native-relation-witness-binding.
Hypothesis: native target-only supervision does not distinguish a correctly
bound geometric reference object from a same-category but incorrect witness.
Relation grounding may therefore be an identifiable missing supervision unit,
not a proposal to change language routing or tune a selector.

## First Discriminating Test
On the existing 32-scene / 128-expression TRAIN manifest, inspect original
annotations, native scene-graph schema and existing ground-truth instance
geometry. No VAL/test-based selection, extra labels or new dataset.
Record denominators and missing inputs. Use only explicitly named, geometrically
testable relations and unambiguous existing object categories. Keep ambiguous
or viewer-dependent left/right predicates separate from camera-independent
above/below and nearest/farthest predicates.

## Matched Control
Keep target, description, geometry and candidate support fixed; permute only
same-category reference-instance identities. A target-only native loss should
be unchanged, whereas an actually identified witness relation should change.
No GT-derived inference score or fitted threshold is a deployed improvement.

## Predeclared Dispositions
No identifiable witness on this frozen cohort: this realization is unsupported,
not proof that all relations are irrelevant. Native loss already explicitly
supervises the same witness unit: investigate exact equivalence before rejection.
A genuine control-separated deficit permits derivation, matched native backward,
resource and independent-package tests; none is granted PASS in advance.
All goal constraints, bans, seed1999 and training schedule remain frozen.

## Status
Diagnosis only. Novelty, efficacy, full native backward, resources and independent
implementation are unverified. An annotation audit is not training admission.
