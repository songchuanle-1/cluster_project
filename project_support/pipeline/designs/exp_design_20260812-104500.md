## 3. Analysis & Direction（方向分析）
  ### 3.1 哪些方向有效（> baseline）
    - CTF×HCG: best=0.5012 (tie champion), γ=+0.0118 vs baseline — 两个独立正交轴首次正协同, 最 promising
    - ORT: best=0.5005, γ=+0.0111 vs baseline — token 多样性通过正交正则有效
    - HCG: best=0.5002, γ=+0.0108 — 正确多尺度交付是必要修复
    - CTF: best=0.4995, γ=+0.0101 — token FFN 精炼有效但单轴未破顶
  ### 3.2 哪些方向失败（< baseline 或持平）
    - CCP 系列: 0.4934-0.4952 — 跨尺度传播无效, 已排除
    - residual 系: B5=0.4944 — 上限固定, 已排除
    - gate 系: 三连败, 已排除
  ### 3.3 哪些尚未消融
    - CTF×HCG×ORT 三轴协同: 最高优先级 — 三个独立有效机制的组合
    - SE 通道注意力替代 CTF FFN: 中优先级 — 替代 token 精炼方案
    - HCG×ORT 简化组合: 中优先级 — 对照验证 ORT 增益是否依赖 CTF
  ### 3.4 结论
    - 选择理由: CTF×HCG 是唯一突破 champion 的组合(持平), ORT 是下一个最有效的独立轴。三轴协同有最高突破概率。
    - SE 通道注意力提供不同的 token 精炼路径(通道重标定 vs FFN 逐元素变换), 可能捕获 CTF 遗漏的信息。
