## 3. Analysis & Direction
### 3.1 Bottleneck, now fully evidenced
85 success / 38 failure on the fixed forward. 33 failures already contain a query
whose mask exceeds IoU .5 with the target; only 5 are mask-limited. All 33 wrong
selections cleanly segment a *different* instance (median IoU .864, 11 perfect),
28 with exactly zero overlap with the target. Targets are small (median 9
superpoints) in scenes of ~40 instances, and the confused instance is a same-name
neighbour at median 2.03 m.

### 3.2 Why every cheap repair fails (all measured)
| Attempted repair class | Result |
|---|---|
| rescore / calibrate / rerank existing scores | correct query stays at median rank 12-13; mean gap -.409, only 10/33 near-ties |
| region-level language scoring (8 variants) | median rank 50-103, margins ~1e-3 |
| phrase-group recombination (15 variants) | best median rank 14, no group above 8% top-1 |
| linear readout on query + mask geometry + language attention | top-1 .110 vs deployed .178 |
| multi-scale / pooling / readback / scale-gate changes | decision-inert: 0/123 winner changes |
| mask-aware referent positives (OHRS) | prior art: RefMask3D Hungarian matching with cls+BCE+dice |
| native seed/mask contingency | head tracks seed containment (.848) not its own mask (.130) |

### 3.3 The structural fact that constrains any design
Correction: the query is not scene-blind (it cross-attends `inst_feats` and the
language). The accurate statement is that the referent decision never reads the
mask that the same query produces: `pred_masks` is an explicit inner product with
`inst_feats`, while `pred_scores` and `pred_indis` are read off the query alone.

Native contingency confirms the operational consequence. Mean deployed `indis`:
seed=0/mask=0 .047; seed=0/mask=1 .130; seed=1/mask=0 **.848**; seed=1/mask=1 .876.
A positive seed moves the score by about .80 while the query's own mask covering the
target moves it by .08. The head is a seed-containment detector that assigns .848 to
queries whose mask does not cover the target.

Meanwhile region pooling collapses same-name discriminability (cos .895 vs query
.677), so simply "giving the decision the mask" loses the signal it needs.
(Correction: this is about region-level language scoring; simply connecting a signal
does not necessarily cause the collapse, and the pooled-feature similarity was high)

## 7. Risk Assessment
The learnability probe is a linear readout on a frozen checkpoint, so its negative
result bounds readout-only repairs, not training changes. 91 of 123 expressions
repeat a scene geometry, so per-expression counts are not independent samples and
scene-level uncertainty is required later. Mean rank and top-1 are TRAIN
quantities, not mIoU.

The larger risk is scope: the diagnosed failure now has a known, prior-art fix, so
the project's contribution cannot come from the axis that the evidence most
strongly supports. Continuing to search inside the remaining bans without a scope
decision risks producing more negative diagnostics instead of a trainable variant.
