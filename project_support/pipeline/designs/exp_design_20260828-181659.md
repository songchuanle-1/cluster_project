## 1. Motivation（为什么设计这批实验）
  - 项目动机（直接引用 goal.json description）: "cluster: 多尺度 cluster context
    机制 — cluster bank 聚合点云特征→cluster_attn 把多尺度 context 回写更新
    inst_feats→提升定位精度。注: 原'聚类路由'假设已被证伪(routing 生效反降点),
    收益来自 context 而非 routing。目标 mIoU ≥ 0.51"
  - 故事线当前状态:
    已验证: context 回写有效 (+0.0118); **交互/注意力机制全灭** (C2C=0.4865 /
            CCP=0.4934 / CSF/FLM/pool); delivery×delivery 组合 6 次不叠加;
            loss 监督轴 4 连败 (M140/141/142/**M143-OBJG=0.5000 本tick**);
            CSORT 是唯一破平台机制 (0.5020) 但跨 seed 脆弱。
    未验证: **write-back message 与实例特征 (inst_feats) 的互补性**。champion 的
            residual write-back `feats + msg` 中, msg 聚合自 point_feats, 与
            实例特征高度相关 → 更新可能是"冗余再确认"。没有任何实验约束过
            (msg, point_feats) 这对关系。
  - 触发原因: M145 推送后 waiting=4 < 容量4+1=5 → 自主补设计 1 个
  - 这批变体在故事线中的角色: **验证假设Z5 (write-back 正交性)** — 去相关轴
    (唯一有效方向) 的**新操作数**: CSORT 去相关 cluster token 之间 (输入侧),
    OWC 去相关 write-back 与更新目标 (输出侧)。若有效 → 多尺度 context 既内部
    互补 (CSORT) 又与实例特征互补 (OWC) → 破 0.5020 候选。若证伪 → 澄清回写
    机制是 "reinforce" 而非 "complement", 排除一个方向也是故事推进。

## 3. Analysis & Direction（方向分析）
  ### 3.1 哪些方向有效（> baseline）
    - context 回写 (A1): 0.5012, γ=+0.0118 (核心, 已确认)
    - **cross-scale orth (CSORT): 0.5020 (唯一破 0.5012 平台, 但 seed 脆弱)**
  ### 3.2 哪些方向失败（< baseline 或持平）
    - 交互/注意力: C2C=0.4865 / CCP=0.4934 / CSF/FLM/pool 全灭
    - delivery×delivery 组合: 6 次不叠加 (关闭)
    - loss 监督轴: M140/141/142/143-OBJG 四连败 (判别/一致/双/目标感知)
  ### 3.3 哪些尚未消融
    - **write-back 正交性 (msg ⊥ inst_feats): 未测 (本设计 M150)**
    - champion CSORT 组合网格: M145-148 在队
    - CSORT seed 鲁棒性: M149 (SG) 在队
  ### 3.4 结论
    - 交互方向已被系统证伪 (C2C/CCP 是反面证据), 新机制不应再走 attention/交互。
    - 唯一破平台机制 CSORT 是去相关 loss。去相关轴的逻辑终点是: 不仅 cluster token
      之间互补 (CSORT), 而且 write-back 的 context 应与被更新的实例特征互补 (OWC)。
    - 在队 M145-149 全是 CSORT 的 token 侧变体, 无一个约束 write-back 输出侧。
      M150 是唯一未覆盖的故事缺口, 与在队变体正交。

## 8. Smell Check (Phase 1.6)
  - 气味: 无新增模块 (非 LayerNorm/Linear/gate); 无新数值扫参; 不是"在 X 加一个
    算子"式微调。唯一需辩护点: 它是 "在 loss 里加了一个 abs-cosine 惩罚", 与
    CSORT 同族。
  - 辩: OWC 改变的是**损失计算图的操作对象** (从 cluster token 之间的 CSORT,
    移到 write-back 与更新目标的 OWC) — 一个从未被约束的新关系 (fm, point_feats)。
    loss-only, 零新增参数, 无新超参 (owc_weight=0.01 与已验证 csort_weight 同尺度
    同族, 单点测试, weight 扫参显式留到 Phase 2)。因果机制清晰: residual 更新若
    与 inst_feats 相关则冗余, 强制正交 → 每次回写添加互补 context。若失败, 结论
    是"该机制假设不成立" (相关必要), 而非"这个值不合适"。
  - 判: 无气味信号命中 (有 CSORT 同族影子, 但操作对象全新) + 通过三标准 (新梯度
    约束路径 / 超参有依据 / 因果机制清晰) → 保留, 本段辩护。
