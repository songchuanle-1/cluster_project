## 3. Analysis And Direction

### 3.1 What Failed At T0

The original evidence term

    e_q = g(v_q^+, l) - g(v_q^-, l)

has two derived defects:

1. Trivial partitions do not vanish. A whole-scene mask gives
   `e_q = <l, scene_mean>`, a scene-level term with no candidate-specific
   information. An empty mask gives a complementary version of the same
   failure.
2. Unequal estimator variance. Under independent point features with common
   variance, `Var[e_q] = sigma^2 N / (|S_q||S_q^c|)`. Selection takes the
   maximum over candidates, so a 1-point mask with roughly 4x the standard
   deviation wins far too often. Measured null win rate for the smallest mask:
   0.285 against a uniform 0.125.

### 3.2 LMEC-v2 Formula

    v_q^+ = sum_n m_qn f_n / |S_q|
    v_q^- = sum_n (1 - m_qn) f_n / |S_q^c|
    e_q   = sqrt( |S_q| * |S_q^c| / N ) * ( g(v_q^+, l) - g(v_q^-, l) )
    s_q   = u_q + lambda * e_q

Derivation: the difference of two independent sample means has variance
`sigma^2 (1/|S| + 1/|S^c|) = sigma^2 N/(|S||S^c|)`. Dividing by the standard
error gives the scale-free factor `sqrt(|S||S^c|/N)`. The factor has no free
parameter, vanishes at both trivial partitions, peaks at the balanced
partition, and equalizes null variance across mask areas.

### 3.3 Gradient

    d e_q / d z_n = c_q * dDelta_q/dz_n + Delta_q * d c_q/dz_n
    c_q           = sqrt( |S_q| |S_q^c| / N )
    d c_q/dz_n    = (c_q/2)( 1/|S_q| - 1/|S_q^c| ) m_n (1 - m_n)
    dDelta_q/dz_n = m_n (1 - m_n)[ (l.f_n - <l,v_q^+>)/|S_q|
                                 + (l.f_n - <l,v_q^->)/|S_q^c| ]

Verified against finite differences to < 1e-6.

### 3.4 Novelty Boundary

N1 from 19:13 covered the four primary sources and found no per-candidate
`u_q + lambda(g(support,l) - g(complement,l))` with the split from the
candidate's own mask. The nearest prior art remains arXiv 2603.17753
PC-CrossDiff differential attention. LMEC-v2 adds an explicit two-sample
standardization, which is itself a standard statistic. The novelty claim
remains narrow and must be re-checked for the changed formula, including the
masked-attention and counterfactual-evidence literature recorded as open risk.

## 7. Risk Assessment

- Code risk: low for N1-v2/T2-v2; no production imports or checkpoint writes.
- Resource risk: none in this design; no CUDA worker.
- Data risk: none; synthetic and frozen artifacts only.
- Scientific risk: high. The repair trades tiny-mask sensitivity for an
  unbiased null (single-point target recovery 0.715 -> 0.575). With an affine
  or bilinear `g` the evidence is one scalar projection onto a single language
  direction. The variance model assumes independent point features, while real
  scene features are spatially correlated.
- Failure rollback: retain original logs, apply at most three documented helper
  repairs, and abandon LMEC entirely if N1-v2 or T2-v2 fails.
