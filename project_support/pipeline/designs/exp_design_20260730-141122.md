## 1. Motivation（为什么设计这批实验）
  - 项目动机: "多尺度 cluster context 机制 — cluster bank 聚合点云特征→cluster_attn 把多尺度 context 回写更新 inst_feats→提升定位精度"
  - 故事线当前状态: context injection 已确效 (γ=+0.0118 vs baseline), 但天花板 0.5012 持续未破. Routing 已证伪. Gate/modulation 系四连败. 当前五个 running/waiting 实验 (C2C/CTF/SWI/WCA/CLN) 全聚焦 token quality 和 readback 机制的单 scale 优化
  - 触发原因: Queue depth 2/2 < 3 (2GPU+1), 需补充至少 1 个变体
  - 这批变体在故事线中的角色: 验证 "跨 scale 信息交互能否突破 0.5012 天花板" — 这是当前故事线最大的未验证缺口

## 3. Analysis & Direction（方向分析）
  ### 3.1 哪些方向有效
    - Context injection: γ=+0.0118 vs baseline, DRP confirms routing-free equivalent
    - ORT (orthogonal regularization): +0.0007 vs champion-lite, consistent small gain
    - Detail loss: +0.0003 vs champion-lite, consistent small gain
    - **None exceed 0.5012 ceiling**

  ### 3.2 哪些方向失败
    - Gate/modulation 系: cag(0.4962), cfe(0.4901), layerscale(0.4921), flm(0.4865) — 四连败
    - Routing 系: TrueRoute(0.4468) — 证伪
    - M22-XCA (cross-scale attn before readback): 0.4954 — 之前尝试过的 cross-scale 方向失败
      ⚠ BUT: XCA modifies the readback/injection path; CSF modifies the token preprocessing path. Different mechanism.

  ### 3.3 哪些尚未消融
    - Scale 间信息交互 (token 级): **未验证** — 最高优先级缺口
    - Multi-head readback: 未验证 — 中优先级
    - Iterative refinement: 未验证 — 中优先级

  ### 3.4 结论
    - 0.5012 天花板暗示单 scale cluster token 的表达能力已达上限
    - 跨 scale 交互是当前最大的未探索方向
    - M22-XCA 失败不排除 CSF: XCA 在 readback 阶段操作 (改了 context injection 方式), CSF 在 preprocessing 阶段操作 (改了 token 质量). 类比: XCA 改了 "怎么用 token", CSF 改了 "token 本身是什么"
    - 如果 CSF 也失败 (γ≤0), 说明 scale 间 attention 整体无效 → 关闭方向, 省下后续探索
