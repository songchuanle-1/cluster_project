## 1. Motivation（为什么设计这批实验）
  - 项目动机: cluster: 多尺度 cluster context 机制 — cluster bank 聚合点云特征→cluster_attn 把多尺度 context 回写更新 inst_feats→提升定位精度。目标 mIoU ≥ 0.51
  - 故事线当前状态: context 有效性已证(+0.0118), ORT 多样性正则已证(+0.0111), DTW 0.4968 再次确认 additive 天花板。FLM(multiplicative) 和 C2C(intra-scale attn) 在队列中覆盖注入范式和 token 交互。但 cluster token 质量仅从多样性角度(ORT)测量, 缺少 "token 是否反映其点云区域" 的约束。

  - 这批变体在故事线中的角色: 填补 "cluster token quality" 缺口 — 测试 alignment 约束能否提升回写 context 质量。与 FLM/C2C 正交互补 (注入方式 / token 交互 / token 质量三个维度)。

## 3. Analysis & Direction（方向分析）
  ### 3.1 哪些方向有效（> baseline）
    - cluster context: champion 0.5012, γ=+0.0118 — 核心有效机制
    - ORT orthogonality: M17 0.5005, γ=+0.0111 — cluster 多样性重要
    - DRP delete routing: 0.4998@ep16 — routing 是死代码, 删除无损
    - detail message: D1 0.5003 — 独立有效
  ### 3.2 哪些方向失败（< baseline 或持平）
    - DTW density-weight: 0.4968 — 加密度先验不改善 additive 注入
    - ORT-W5 strong orth: 0.4959 — 正交过强反降点
    - refine系: 连续失败 (CSR 0.4875, REF 0.4892)
    - 机制组合: 全部 < 单机制
  ### 3.3 哪些尚未消融
    - Non-additive injection: FLM (queue中) — 最关键的未验证假设
    - Cluster token interaction: C2C (queue中)
    - **Cluster token alignment to points: 完全未探索** — 本次填补
    - Multi-loss synergy: ORT + alignment (未来可组合)
  ### 3.4 结论
    - 三个有效机制 (context/ORT/detail) 全部止步 ~0.5005, 天花板清晰
    - FLM 和 C2C 覆盖注入范式和 token 交互, PCL 补充 token 质量维度
    - 如果 FLM 或 PCL 突破 0.5012 → 找到天花板突破口; 如果都失败 → 需要重新思考假设
