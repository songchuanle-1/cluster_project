### 3.4 Derivation and falsification
For candidate q, let seed location x_q and superpoint instance label c_q
be gathered through saved FPS and sample indices. Let c be the target ID,
mu the unweighted mean of target-labelled superpoint centroids.
Source assignment for a single target:

    q0 = argmin_q ||x_q - mu||_2
    y_q = 1[c_q=c OR q=q0]
    p_q = softmax(z_q)[1]
    w_q = y_q + eos_coef*(1-y_q)
    M = sum_q y_q
    L = sum_q w_q[-y_q log p_q -(1-y_q)log(1-p_q)+log(1+1e-6)]/M
    dL/dz_q1 = w_q*(p_q-y_q)/M
    dL/dz_q0 = -dL/dz_q1

Source dataset uses strict >.5 instance majority; unresolved superpoints=199.
No target-majority superpoint => report missing centroid, do not fabricate.
For fixed labels, negative candidates have nonnegative z1-gradient, positives
nonpositive; this is a partial derivative, not the full shared-parameter update.
Actual mask BCE/Dice supervise matched queries too; auxiliary layers reuse
assignment. Other losses can alter net feature/parameter gradients.

Measure u_q = actual point maskIoU; G={q:u_q>.5}. Predefine counts:
positive/negative x usable/unusable, selected/oracle label, G empty,
G nonempty but G intersect positives empty, recoverable failures with/without
positive usable candidates. Also report both restricted oracle maxima; oracle
uses GT and is not deployable. Do not fit a threshold or choose samples.
Reject broad "no usable positives explains most failures" if absent/rare.
Any mismatch alone is insufficient evidence to change supervision.
Compute nearest ties/margin and float64 cross-check; CPU replay is not exact
historical GPU training replay. No mask/head weights trained or modified.
Complexity: O(N) mapping plus QxS stored bank, O(Q) label/loss; no NxN tensor.
