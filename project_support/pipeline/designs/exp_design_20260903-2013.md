## 3. Analysis & Direction
  ### 3.1 Effective directions
    - Multi-scale context readback remains the confirmed +0.0118 core mechanism.
    - M162 shuffled retrieval reaches +0.0086 over baseline, showing recurrent
      context capacity is useful even without point alignment.
  ### 3.2 Failed directions
    - Plain aligned MQF is 0.0060 below its shuffled control and 0.0100 below
      champion. Object semantic alignment alone does not explain the gain.
  ### 3.3 Unablated direction
    - Distribution-matched counterfactual subtraction: aligned retrieval minus
      shuffled retrieval from the same predicted mask.
  ### 3.4 Conclusion
    - Add M170-MQR. It directly follows from the paired M161/M162 result and tests
      a new causal mechanism rather than another context weighting rule.

## 7. Risk Assessment
  - Code risk: low-medium. The module performs two weighted pools using the same
    existing mask tensor and deterministic valid-point roll.
  - Resource risk: low. Pooling cost doubles but remains O(BQN), with no extra
    attention matrix and no new persistent mask state.
  - Data risk: none.
  - Failure fallback: normal patience=10 early stop; close the aligned-mask semantic
    branch if M170 remains below champion.

## 8. Smell Check
  - M170 changes the information path to a paired factual/counterfactual residual.
  - It is not a temperature, threshold, top-k, normalization, loss-weight, or
    schedule sweep.
  - No new tunable coefficient is introduced. The deterministic half-scene roll is
    inherited exactly from the preregistered M162 control.
