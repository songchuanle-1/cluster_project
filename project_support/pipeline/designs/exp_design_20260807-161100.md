    - 正确交付 (HCG) × 高质量 token (CCP) 组合: 未测试 — 本次

      结构性机制 (零参数, 新信息路径), 与 HCG 正交。

## 8. Smell Check（Phase 1.6 调参气味检测）
  对每个候选变体逐条对照气味信号表:
  - 气味 1 (参数<5K 无新图): 零参数但**有新计算图** (coarse→fine gather+add 新信息路径) → 不命中
  - 气味 2 ("加一个 LayerNorm/Linear/sigmoid"): 无, 纯层级传播 → 不命中
  - 气味 3 (只改数值分布): 加的是**新信号源** (父簇全局上下文), 非重缩放已有值 → 不命中
  - 气味 4 (超参无依据): 无新超参 → 不命中
  - 气味 5 (换名绕过 banned): 非 gate 系/非路由/非 residual → 不命中
  - 气味 6 ("找到更好数值配置"): 信息流路径改变, 非数值配置 → 不命中
  通过三标准: (1) 新计算图 ✓ coarse→fine 边在先前不存在; (2) 超参有依据 ✓ 无超参;
  (3) 因果机制清晰 ✓ 细簇 token 获全局上下文 → readback 消息质量提升 → 定位精度提升。
  **结论: 无气味, 正常入队。**
