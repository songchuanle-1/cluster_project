## 3. Analysis And Direction
Let a fixed physical contact graph partition boundary nodes into C_r.
Binary target y, logits z, and k_r=sum(y_i for i in C_r).
Independent Bernoulli weights conditional on each component count give
Z_r=sum_{S subset C_r, |S|=k_r} exp(sum_{i in S}z_i).
L_comp=(sum_r log Z_r - y dot z)/n.
Differentiation gives dL/dz_i=(P(i occupied | k_r)-y_i)/n.
This is BCA on separate groups, not a new likelihood primitive.
Complexity with feasible DP: O(sum_r n_r min(k_r,n_r-k_r)), plus graph traversal.
Each component has an independent common-shift null direction; global BCA has
one global shift null direction. Conditioning erases count-transfer evidence.
If k_r=0 or n_r, that component's loss and gradient are identically zero.
Counterexample: C1={0,1}, C2={2,3}, y=(1,1,0,0), z=(-4,-4,4,4).
All threshold labels are wrong, but component loss has zero gradient.
Global BCA with k=2 can transfer occupancy and has a nonzero corrective gradient.
This disproves a universal component-correction rationale, not full-loss efficacy:
retained BCE still supplies corrective gradients. Component graphs containing only
GT-crossing edges cannot contain such homogeneous nontrivial components; this
counterexample specifically addresses full induced physical-contact components.
For mixed components, independent shift invariance still removes calibration.
Prior-art retrieval yielded no usable content; source/novelty review incomplete.
