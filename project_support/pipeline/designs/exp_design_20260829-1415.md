## 1. Motivation（为什么设计这批实验）
  - 项目动机（直接引用 goal.json description）: "cluster: 多尺度 cluster context
    机制 — cluster bank 聚合点云特征→cluster_attn 把多尺度 context 回写更新
    inst_feats→提升定位精度。注: 原'聚类路由'假设已被证伪(routing 生效反降点),
    收益来自 context 而非 routing。目标 mIoU ≥ 0.51"
  - 故事线当前状态:
    已验证: context 回写有效 (+0.0118); 交互/注意力全灭; loss 监督轴关闭;
    CSORT (M95=0.5020) 与 MFP (M119=0.5020) 是**两个独立达平台的机制**;
    **M146 (本tick 终态)=0.4970 — CSORT×detail 消息负交互, message-type 轴
    关闭 (context 胜)**; 组合线 (architecture×loss) 多例不叠加。
    未验证: **loss×loss 且目标互补 (CSORT diversity × MFP completeness) 的
    双机制组合** — 两个平台机制从未正交, 是"组合不叠加"规律的最后一个
    未检象限。
  - 触发原因: M148 推送后 waiting=4 < 容量4+1=5 → 自主补设计 1 个
  - 这批变体在故事线中的角色: **验证假设X (双机制正交)** — 若组合破平台,
    "多尺度 context 质量 = diversity × completeness 双杠杆"; 若失败, 补全
    "组合不叠加"规律的 loss×loss 象限证据。

## 3. Analysis & Direction（方向分析）
  ### 3.1 哪些方向有效（> baseline）
    - context 回写 (A1): 0.5012, γ=+0.0118 (核心, 已确认)
    - cross-scale orth (CSORT): 0.5020 (破平台, seed 脆弱)
    - masked feature prediction (MFP): 0.5020 (破平台, 与 CSORT 平级)
  ### 3.2 哪些方向失败（< baseline 或持平）
    - 交互/注意力: C2C/CCP/CSF/FLM/pool 全灭
    - loss 监督轴: M140-144 五连败 → 轴关闭
    - **M146-CSORT-DET (本tick)**: 0.4970, γ=-0.0050 vs champion — CSORT×detail
      消息负交互, message-type 轴关闭 (context 胜)
    - M145-CSORT-ALL: 0.4920 — 全尺度对扩展失败
    - architecture×loss 组合: 6+ 次不叠加 (DET/DCM/MLay/DUAL...)
  ### 3.3 哪些尚未消融
    - **loss×loss 双机制组合**: CSORT×MFP 从未试过 (本设计) — 两机制均为
      0.5020, 目标互补 (去相关 vs 完整性)
    - CSORT seed 鲁棒性: M149-SG 在队
    - write-back 正交 (soft/hard): M150-OWC / M151-ODW 在队
  ### 3.4 结论
    - 0.5020 平台有多机制共存 (CSORT/MFP/MLay/DCM/MEMBANK)。已证 architecture×
      loss 组合不叠加。**剩最后一个未检象限: loss×loss 且目标互补**。MFP 是
      与 CSORT 最"同类" (都作用于 cluster token 表示, 都是 loss 级) 的平台
      机制, 组合成本低 (复用两边 head), 信息量大 (无论成败都推进故事线)。

    无新数值扫参 (csort_weight/mfp_weight/mask_ratio 均沿用验证过的固定值);
    不是"在 X 处加一个 LayerNorm/Linear/gate/scaling"。
  - 辩: 这是**双机制正交组合** (goal.json Phase1 明确允许"新模块/结构消融"):
    1) 验证的是**因果假设** "去相关 (diversity) 与重建 (completeness) 对 token
       表示是互补还是冲突", 而非"试哪个权重更好" — 失败结论是机制层面的
       (冗余/冲突), 不是"这个值不合适"。

       mask_ratio=0.15) 都是各自已验证的固定值, 直接组合, 无任何推导需求。
    3) 有明确新证据支撑 (M146 关闭 message-type 轴 → 组合线最后一个未检象限
       是 loss×loss; 两机制独立 0.5020), 非拍脑袋。

  - 判: 无气味信号命中 + 通过三标准 (新计算图: CSORT loss 与 MFP loss 共享
