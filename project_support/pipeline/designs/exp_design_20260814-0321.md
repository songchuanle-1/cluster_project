## 3. Analysis & Direction（方向分析）
  ### 3.1 哪些方向有效（> baseline）
    - CTF×HCG: best=0.5012 (tie champion), γ=+0.0118 — 两独立正交轴正协同
    - HCG: best=0.5002, γ=+0.0108 — 正确多尺度交付必要修复
    - CTF: best=0.4995, γ=+0.0101 — token FFN 精炼有效
    - ORT: 表面 0.5005 但**机制存疑** (梯度断流) → 修复后重测
  ### 3.2 哪些方向失败（< baseline 或持平）
    - CONS/QMOD/CCP/XCA/ITER/REAGG: 0.483-0.498, 约束/一致性/传播类机制均未破顶
    - detail 组合: M84 0.4990, 与 CTF×HCG 无正协同
  ### 3.3 哪些尚未消融
    - 跨尺度 token 多样性 (尺度间正交): 最高优先级 — 从未测试的优化轴
    - ORT (尺度内多样性) 真正生效: 高优先级 — M92 修复后首次真实施压
    - 多层注入 × CTF×HCG: 中优先级 — 突破②×强基底
  ### 3.4 结论
    - 选择理由: 本 tick 重大发现是 ORT 多样性轴梯度从未回流 → "多样性"是故事线中
      **空白但最 promising** 的轴。M95 跨尺度多样性是全新计算图 (尺度间 pairwise),
      M92 修复让三轴组合真正生效, M96 探索多层注入×强基底。
