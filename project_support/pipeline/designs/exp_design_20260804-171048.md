## 3. Analysis & Direction（方向分析）
  ### 3.1 哪些方向有效（> baseline）
    - context 回读 (champion/DRP): +0.0118 vs baseline, 确认有效
    - token 正则 (ORT 0.5005): 接近未破 ceiling
  ### 3.2 哪些方向失败（< champion）
    - 融合机制全部 < 0.5012: XCA(0.4954, token级跨尺度 self-attn), CSF(0.4958, 相邻尺度
      token 交叉注意), SWI(0.4970, sigmoid-vs-softmax gate), NCR(0.4980, soft readback)
    - 读回形式: BIL(0.4919)/NLR(0.4948)/FILM(0.4936)/FLM(0.4865) 全 < champion
    - token 精炼: CTF(0.4995) 有效但未破; 组合无协同
  ### 3.3 哪些尚未消融
    - **point-level 内容自适应尺度融合 (SCF)** — 从未测 (优先级: P0, CTF 结论直接指向)
    - 聚合池化 (DCA 在跑/VAC 待验)、级联 (CCR 待验)、空间 (SAC 待验) — 已在队列
  ### 3.4 结论
    - CTF 分析把瓶颈指向 "readback/融合机制", 但已试融合变体全是 token 级或 gate 形式级。
    - 唯一空白: readback 的尺度权重由静态 MLP 产生, 不感知各尺度 context 内容。
    - M55-SCF 让尺度权重由内容 QK 匹配决定 (per-point, O(N·3) 线性), 是对该假设的精确探针。

## 7. Risk Assessment（风险评估）
  - 代码风险: 低。SCF 仅替换 DRP._cluster_to_points 里的融合段 (静态 gate → 内容注意力),
    新增 3 个 Linear (scf_q/k/v)。不改 routing/聚合/readback 其余部分, 不影响其他变体。
  - 资源风险: 低。SCF 增加 ~196K params (3×256×256), 显存/FLOPs 增量可忽略 (3-token
    attention 是 O(N·3) 线性)。
  - 数据风险: 无。同一 ScanRefer 数据集。
  - 失败回退: 若 crash 3 次 → 放弃该变体, 记录 question; 队列仍有 M52/M53/M54 补位。

    - #3 (数值分布): 新增内容匹配交互 (注意力权重依 context 内容而定), 非缩放/归一化, PASS

      注意力 (O(N·3)), 非 attention-pooling (attnpool), 非 token 级 self-attention (XCA),
      非聚合加权 (agg), 非多尺度重复注入 (multi), PASS
    - #6 (找数值配置): 新信息交互路径 (尺度权重由内容决定), 非同一信息流改数值, PASS
  - 与已试融合变体的区别: XCA(0.4954)=token 级跨尺度 self-attn (328×328 N²); CSF(0.4958)=

    尺度 context 的内容匹配 — 三者均未让 readback 尺度权重感知 context 内容。
  - 因果机制: "静态尺度 gate 输入 [point_feats, global_mean] 不含各尺度 token 内容; 当某尺度
    context 与点语义不匹配 (边界点/噪声簇) 时无法降权。内容注意力使权重 = softmax(q_p·k_l),
    直接反映尺度 context 与点的匹配质量, 是 CTF 'readback/融合机制瓶颈' 的精确探针。"
