## 3. Analysis & Direction（方向分析）
  ### 3.1 哪些方向有效（> baseline）
    - context 回写 (A1): 0.5012, γ=+0.0118 (核心, 已确认)
    - decoder-access qla (DCM): 0.5010, γ=+0.0116 (单通路最优; qia 侧已关闭)
    - 多层注入 legacy 2层 (MLay): 0.5010, γ=+0.0116
  ### 3.2 哪些方向失败（< baseline 或持平）
    - qia/DCMV 通路: M133=0.4950 / M137=0.4920 — 双 seed 关闭
    - {qla,qia} 双通路 (M134): 0.4970 — 不叠加
    - {②}×{DCA,DCM,DCMV}: M125/M126/M136 — 全部不叠加
    - MFP/CSORT/CTF token-FFN / 池化类型 (mean/max/dual/var/weighted): 全灭
  ### 3.3 哪些尚未消融
    - **cluster token 同尺度实例判别 (CLICA)**: M140 queued
    - **cluster token 跨尺度实例一致 (CSIC)**: M141 queued
    - **双监督交互 (CLICA×CSIC)**: M142 queued
    - **cluster token 目标感知 (OBJG)**: 未测 (本设计 M143)
    - {MLay 2层 legacy}×{DUAL}: M139 running (本 tick 推送)
    - seed 矩阵: M122 / M120 queued+running
  ### 3.4 结论
    - 平台瓶颈在 cluster token 信息量。CLICA (判别)、CSIC (一致) 两条 loss 路径
      已 queued, 但它们都不覆盖"目标选择" — 语言查询指定唯一目标, 而当前 cluster
      token 不知道哪个簇属于目标。OBJG 直接监督这一维度, 是三者中最服务定位任务
      的监督信号, 且与 CLICA/CSIC 正交 → 独立赌注, 值得第三格。

    均已在 loss forward)。

    "loss 监督轴三维度全部饱和", 平台需范式级新方向 (记为 question, 暂停自主
