## 3. Analysis & Direction（方向分析）
  ### 3.1 哪些方向有效（> baseline）
    - Cluster context: champion 0.5012, γ=+0.0118. 核心机制已确认。
    - DRP (delete routing): 0.5012 ties champion. 确立干净基线，routing 为死代码。
    - Token refinement (CTF): 0.4995, γ=+0.0101 vs baseline. Token 质量提升有效但单靠不够。
    - ORT (orthogonality reg): 0.5005, γ=+0.0111. 正则化有效但天花板未破。
  ### 3.2 哪些方向失败（< baseline 或持平）
    - C2C (cluster-to-cluster self-attn): 0.4865. Intra-scale attention 无效。
    - FLM (FiLM modulation): 0.4865. Gate/modulation 方向持续失败。
    - CMX (max-pool): 0.4910. Max pool 不如 mean pool。
    - Q2P (direct query→point): 0.4904 ≈ baseline. 证实 cluster tokens 必要。
  ### 3.3 哪些尚未消融
    - Readback 维度假说: 当前 `inst_feats = inst_feats + gate * cluster_message` 覆盖所有 d_model 维度 → 可能破坏 point-private 信息
    - 跨尺度融合 (CSF queued): cluster tokens 之间 cross-attention
    - Neighborhood readback (NCR queued): per-point top-K cluster attention
  ### 3.4 结论
    - 0.5012 天花板: 多个机制 (CTF/ORT/ORT-HYB/SWI) 都能达到 ~0.50 但无人突破 0.5012
    - 瓶颈假说转移: token quality → aggregation quality → readback dimensionality
    - SHC 测试 readback 维度瓶颈: 如果突破 → 论文核心发现；如果持平 → 排除维度假说

## 7. Risk Assessment（风险评估）
  - 代码风险: 低 — 仅修改 dec.py Encoder_layer.forward 中 ~10 行，其他文件不变。改动局限在 split_head 分支，不影响 context/detail 路径。
  - 资源风险: 低 — split_head_proj 增加 Linear(d,d) ≈ 65K params (d=256), 内存/FLOPs 影响可忽略
  - 数据风险: 无 — 复用现有 ScanRefer 数据
  - 失败回退: 如果 crash 3 次 → 放弃 SHC，转考虑其他 readback 变体（如 channel-gated readback 或 dual-branch readback）
