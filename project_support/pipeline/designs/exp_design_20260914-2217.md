## 3. Analysis And Derivation
Construct scene SP graph from existing post-augmentation occupied voxels:
majority SP within voxel,tie smallestID;undirected physical six-face contacts.
No spatial kNN,radius or attention. Record mixed voxels and lost minority edges.
For existing matched target mask y define boundary set B=endpoints of edges
with unequal y. n=|B|,k=sum_B y. A crossing guarantees0<k<n.
For native final mask logits l_i,independent Bernoulli conditional on cardinality:

    P(Y=y | sum_B Y=k,l)=exp(sum_B y_i*l_i)/Z_k(l)
    Z_k(l)=sum_{S subset B,|S|=k} exp(sum_{i in S}l_i)
    L_BCA=(log Z_k(l)-sum_B y_i*l_i)/n

DP recurrence Z_(j,r)=Z_(j-1,r)+exp(l_j)Z_(j-1,r-1),evaluated in log space,
finite feasible states only. Complement labels/logits if k>n/2 for efficiency.
Gradient=(P(Y_i=1|count)-y_i)/n;sum gradients0. Hessian=conditional covariance/n,
nonseparable except degenerate cases. Uniform logit shifts cancel exactly.
Permutation and joint label/logit complementation invariant. Correct assignments
have infimum0. n2,k1 reduces standard pair logistic;not claim primitive novelty.
No boundary/empty target returns connected zero. Valid NaNs rejected.
Compute per-expression mean over its matched queries,then sum/global inherited
matched count. Replace ONLY final Dice at inherited weight1;BCE,selector,
sampling,semantic losses,all auxiliary losses/weights unchanged.
Fixed normalization by n is per-boundary-variable NLL,not a tuned temperature.
No new scalar/head/numerical sweep. Empty interface retains BCE/aux supervision.
Training cost O(voxels log voxels+edges+matched*n*min(k,n-k)),no SP N^2 tensor.
Inference identical M95;no train labels or graph at predict.
