## 3. Analysis & Direction
  ### 3.1 Effective directions
    - Multi-scale context readback remains the confirmed +0.0118 mechanism.
    - Semantic alignment has measurable value: M157 exceeds M158 by 0.0040.
  ### 3.2 Failed directions
    - Explicit routing, direct geometry, unconditional decoder access, repeated
      injection, token transformations, and auxiliary-loss combinations failed.
  ### 3.3 Unablated direction
    - Signed temporal correction from consecutive decoder mask predictions.
  ### 3.4 Conclusion
    - Add one mask-delta experiment. It answers a distinct causal question and
      restores queue depth without duplicating M161-M167.

## 7. Risk Assessment
  - Code risk: medium. The decoder must retain two mask states without changing
    auxiliary prediction outputs.
  - Resource risk: low. Two BxQxN mask tensors are retained and the new pooling is
    O(BQN); no N^2 attention is introduced.
  - Data risk: none.
  - Failure fallback: normal patience=10 early stop; if below champion, close the
    mask-delta branch.

## 8. Smell Check
  - M168 adds a temporal two-state information path and signed correction semantics.
  - It is not a threshold, temperature, loss-weight, schedule, or normalization sweep.
  - No new tunable coefficient is introduced.

## 9. Constraints And Banned Check
  - FLOPs <=10.0G: incremental operations are linear in existing mask size.
  - Seed=1999, epochs=50, and max_iters=70 remain unchanged.
  - No gate, explicit routing, language routing, large projection stack, residual
    message branch, or N^2 point attention.
