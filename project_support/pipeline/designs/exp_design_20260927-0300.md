## 3. Analysis And Direction
The same physical seed can be a target in expression a and non-target class
context (focal label 0.25) in expression b. Native `expand_and_fps` shares
scene geometry and FPS indices; language and referent identity differ.
Existing per-expression focal losses can therefore apply distinct directions
to repeated visual features. Whether gradients actually conflict at the
shared source tensor is unknown. The naive object-text contrast and
general-purpose gradient surgery are not new core mechanisms.

## 4. Experiment Plan
| ID | Purpose | Status |
|---|---|---|
| m95-sample-context-support | Diagnose actual same-instance cross-expression gradient interaction on server-6 GPU7; no training variant yet | DRAFT / not admitted |

Freeze the 32-scene/128-expression TRAIN manifest and M95 checkpoint.
For each role transition, bind the same physical superpoint via the scene
FPS array. Record per-expression *native* sample-loss gradients on the
pre-repeat visual feature `h_s`, separately for a's target and b's context
seeds: `g_t = dL_sample(a)/dh_s`, `g_c = dL_sample(b)/dh_s`. Readout:
`cos(g_t,g_c)` and `g_t . g_c`, grouped by scene, with finite/nonzero
denominators. Do not equate differing expression logits or local seed
indices without a captured shared FPS binding.

Controls in the same forward: matched same-scene target-to-zero instance
roles (306 ordered pairs in the current census), identical scene/FPS
and gradient extraction with only role membership changed, and
label-shuffled instance identities preserving per-scene role counts.
Pre-register expected direction: a *specific* conflict should be enriched
for target-to-context relative to target-to-zero, and should vanish after
identity-preserving matched control is broken. If either arm has no coverage,
or the effect is equally present under shuffled identities, reject this
route. Do not set a numerical effect threshold after inspection.

Even with a diagnostic conflict, the candidate must specify a new causal
information path or supervision unit. `L=-log p(o|text_a)-log(1-p(o|text_b))`
is generic object-text contrastive training; projecting conflicting
gradients `g_c <- g_c - min(0,g_c.g_t)/||g_t||^2*g_t` is PCGrad. Neither
constitutes this project's core innovation. Do not turn this draft into
training by renaming either expression.

Before any future launch freeze ScanRefer primary mIoU vs M95 and baseline,
native split, scene-clustered intervals, repeatability and meaningful
subgroup harm rule. No benefit can be claimed from this diagnostic.

## 7. Risk Assessment And Smell Check
Dataset source exposes only one target instance per expression, and the
captured two wrong-context selections may be too narrow. Generic
positive/negative contrast is prior art; scalar retargeting or weighting
is Phase 1 tuning; PCGrad is already published. A gradient conflict is
diagnosis, not a novelty or efficacy PASS. No model/config exists here and
no six-gate receipt can be issued.
