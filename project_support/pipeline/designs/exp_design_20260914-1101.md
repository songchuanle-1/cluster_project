## 3. Analysis & Direction
### 3.1 Boundary-Distance Supervision
Hypothesis: overlap-only supervision poorly distinguishes boundary displacement.
For each existing matched mask y on post-augmentation occupied voxels, derive
signed distance phi_y(x) to its boundary, negative inside. A boundary displacement
surrogate follows from integrating predicted occupancy against phi:

    L_B(q,y) = mean_n phi_y(x_n) * (sigmoid(l_qn)-y_n) / scene_diagonal

Aggregate over matches with the inherited expression-mean/global-match reduction,
replacing final Dice at its inherited coefficient; BCE/aux remain. Gradient:
phi_y(x_n)*m_qn*(1-m_qn)/(N*D). This supervises each matched mask directly,
with no selector mixture or transport/CDF. Distance transform runs on existing
voxel support, detached from predictions. Empty boundaries must be excluded.
Controls: permute phi relative to points while retaining its values/reduction.
Falsifier: only oracle masks improve, not hard grounding; no boundary-stratum
gain. Boundary-stratum prevalence not yet diagnosed; novelty UNVERIFIED.
HARD BLOCKER: unchanged sparse backbone alone71.045G MACs >10G. New loss
cannot subtract its calls. No production package or training proposal admitted.

### 3.2 Superpoint-Adjacency Supervision
Hypothesis: consistent labeling across spatial contacts reduces fragmented masks.
Construct undirected SP edges from occupied voxels sharing a face; use exactly
six physical face neighbors, not tuned k-nearest neighbors or N^2 attention.
For a matched binary target y, define c_ij=1[y_i=y_j]. Independent predicted
Bernoulli labels have same-label probability:

    a_ij = m_i*m_j + (1-m_i)*(1-m_j)
    L_A = mean_(i,j in E) BCE(a_ij,c_ij)
    da_ij/dm_i = 2*m_j-1

The edge likelihood follows from summing the two same-label assignments.
Compute stably from log-sigmoid joint terms; no clamp/epsilon coefficient.
Replace final Dice with this edge objective at inherited coefficient/reduction;
keep unary BCE so globally complemented labels cannot be an unpenalized solution.
Complexity O(occupied_voxels+E*matched_queries), not attention/routing/dedup.
Empty E gives connected zero; all-constant masks and disconnected components
remain degeneracies. Control: degree-preserving edge permutation, same labels.
Falsifier: reduced fragmentation without improved selected-mask grounding.
No demonstrated fragmentation prevalence in the bounded evidence; novelty OPEN.
HARD BLOCKER: same unchanged45 sparse conv calls71.045G >10G, irrespective
of graph memory/training complexity. No package/config or model ID created.

### 3.3 Direct Token-Span Supervision
Hypothesis: explicit target-word membership supervision helps target identity.
Using only existing positive token maps, let h_j be the final verbal embedding
and z_j be a binary target-span label. A token classifier yields v_j; independent
Bernoulli maximum likelihood gives:

    L_span = -mean_j [z_j log(sigmoid(v_j))
                     +(1-z_j) log(sigmoid(-v_j))]
    dL/dv_j = (sigmoid(v_j)-z_j)/L_valid

This is a language-side supervised graph, not a spatial loss, reranker,
language routing mechanism or annotation request. Existing maps are not
automatically contiguous spans; their semantic equivalence needs verification.
HARD NOVELTY BLOCKER: this proposed construction is the original
arXiv2411.03405 Eq(6), L_sp=H1(l,l_hat), not a new core mechanism.
Adding just a token Linear also fails the minimal-graph smell criterion.
Do not invent a weight or enlarge a module merely to evade that criterion.
It also retains the over-budget backbone. No package/config/ID created.
