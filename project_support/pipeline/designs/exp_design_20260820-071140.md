## 3. Analysis & Direction（方向分析）
  ### 3.1 哪些方向有效（> baseline）
    - CTF+HCG: best=0.5012, γ=+0.0118 vs baseline. 核心架构确定
    - CSORT: seed1999=0.5020 但跨 seed 证伪 (3/4 seed 负增益)
  ### 3.2 哪些方向失败（< baseline 或持平）
    - ORT: M97=0.4920, 在 champion 基底无效
    - Multi-layer: M96=0.4940, M86=0.4960 (均 < champion)
    - MEMBANK: M110=0.4950 高振荡不稳定
    - 50+ 方向均在 ~0.50 打转, 未突破
  ### 3.3 哪些尚未探索
    - **跨模态 cluster 级交互**: 当前 lang 只在 decoder 层与 point features 交互,
      cluster tokens 从未直接接收 language 信息 — 全新方向
  ### 3.4 结论
    - 已排队 CCL/CGA/BCF 聚焦视觉侧改进, LCC 开辟跨模态新轴
    - 如 LCC 有效: 可与视觉侧正交方向叠加, 追求 0.51
    - 如 LCC 无效: 排除 cluster 级跨模态路径
