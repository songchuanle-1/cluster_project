    bank aggregates point-cloud features, cluster attention writes multi-scale
    context back to inst_feats, and improves grounding accuracy. Explicit routing
    has been disproven; the gain comes from context. Target mIoU >= 0.51."

    variants have not exceeded 0.5020. Direct unconditional decoder access also failed.
  - Trigger: waiting=1 <= available GPU slots=5; required depth is >=6 waiting.
  - Batch role: test a new recurrent information path in which the previous decoder
    mask prediction retrieves object-specific context for the next query.

## 3. Analysis & Direction
  ### 3.1 Effective directions
    - Multi-scale context readback: +0.0118 over baseline.
    - CSORT at seed 1999: 0.5020, but seed-fragile.
    - PMD: 0.4990, showing receiver-side context remains useful.
  ### 3.2 Failed directions
    - Isolated CSORT scale pairs, refined operands, global scale, extra losses,
      direct geometry injection, direct decoder cluster access, and repeated
      CTF/HCG injection all fail to exceed the champion.
  ### 3.3 Unablated direction
    - Recurrent prediction-conditioned retrieval: use previous predicted object
      support to choose context for the next query.
  ### 3.4 Conclusion
    - The remaining bottleneck is not more generic context, but selecting the
      context relevant to each evolving object hypothesis. Existing BxQxN mask
      logits provide this selection signal at no new N^2 cost.

## 7. Risk Assessment
  - Code risk: medium. The recurrent path changes query state between decoder layers
    but reuses existing mask logits and point/cluster tensors.
  - Resource risk: low. MQF/MQC/MQU add O(BQN) weighted pooling using an already
    materialized BxQxN mask tensor; MQH adds O(BQK) with K<=256. No N^2 attention.
  - Data risk: none.
  - Failure fallback: up to three crash repairs per variant; if the batch stays
    below 0.5020, close prediction-conditioned retrieval and retain M161/M162 as
    the semantic-control evidence.

## 8. Smell Check
  - All five variants introduce a new recurrent information path from previous mask
    predictions to subsequent query states. They are not numeric sweeps, normalization
    changes, gates, or sub-5K cosmetic operators.
  - M161: causal hypothesis is object-conditioned foreground retrieval.
  - M162: pre-registered semantic control; failure/success separates mask meaning from capacity.
  - M163: causal hypothesis is foreground/background contrast.
  - M164: causal hypothesis is uncertainty-focused correction.
  - M165: causal hypothesis is hierarchical occupancy-based cluster retrieval.
  - M166: causal hypothesis is support-specific query-to-point recurrent feedback,
    the reciprocal direction of M161.
  - No new tunable coefficient is introduced; the residual update uses the existing
    transformer residual/norm convention.
