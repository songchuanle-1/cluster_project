## 3. Analysis & Direction（方向分析）
  ### 3.1 哪些方向有效（> baseline）
    - CTF+HCG: best=0.5012, γ=+0.0118, 核心架构
    - detail message: best=0.5003, γ=+0.0109, 增量有限
    - ORT (单独): best=0.5005, γ=+0.0111, 组合待验证
  ### 3.2 哪些方向失败（< baseline 或持平）
    - CSORT: 3/4 seed 负增益, 轴正式关闭 (08-19)
    - multi-layer: M96=0.4940, 退化 → banned
    - gate/residual/CCP: 全部 < baseline → banned
  ### 3.3 哪些尚未探索
    - cluster token 对比学习: 从未尝试 (新 loss 函数) → M115-CCL
    - cluster 间空间图: 从未尝试 (新 GNN 模块) → M116-CGA
    - 双向 context flow: 从未尝试 (新 attention 方向) → M117-BCF
    - 自监督 mask 重建: 从未尝试 (留到下一轮)
  ### 3.4 结论
    - CTF-HCG 到 ~0.50 天花板, 需要正交的新机制
    - 选择 ccl/cga/bcf: 分别测试训练信号(cluster对比)/信息聚合(图结构)/信息流向(双向)
    - 三个方向完全正交, 互不依赖, 可并行跑
