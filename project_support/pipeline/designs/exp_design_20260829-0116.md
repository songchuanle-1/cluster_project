## 1. Motivation（为什么设计这批实验）
  - 项目动机（直接引用 goal.json description）: "cluster: 多尺度 cluster context
    机制 — cluster bank 聚合点云特征→cluster_attn 把多尺度 context 回写更新
    inst_feats→提升定位精度。注: 原'聚类路由'假设已被证伪(routing 生效反降点),
    收益来自 context 而非 routing。目标 mIoU ≥ 0.51"
  - 故事线当前状态:
    已验证: context 回写有效 (+0.0118); 交互/注意力全灭 (C2C/CCP); loss 监督轴
            5 连败关闭 (M140-144, 本tick M144-LQA=0.4930); CSORT 是唯一破平台
            机制 (0.5020) 但跨 seed 脆弱 (mean~0.495)。
    未验证: **write-back 的互补性是否需从结构上保证**。champion 回写 feats+msg,
            msg 聚合自 inst_feats 天然相关 — 相关分量只 reinforce, 正交分量才
            complement。M150-OWC 用 loss 惩罚 (软); 无变体结构保证正交 (硬)。
  - 触发原因: M146 推送后 waiting=4 < 容量4+1=5 → 自主补设计 1 个
  - 这批变体在故事线中的角色: **验证假设Z6 (回写互补性的强制方式)** — 去相关轴
    (唯一有效方向) 的硬约束操作数。CSORT 去相关 token 之间 (输入侧), OWC 去相关
    fused msg vs inst_feats (输出侧, soft loss), ODW 在结构上保证回写 ⊥ inst_feats
    (输出侧, hard projection)。三者覆盖去相关轴的全部逻辑操作数。

## 3. Analysis & Direction（方向分析）
  ### 3.1 哪些方向有效（> baseline）
    - context 回写 (A1): 0.5012, γ=+0.0118 (核心, 已确认)
    - cross-scale orth (CSORT): 0.5020 (唯一破 0.5012 平台, 但 seed 脆弱)
  ### 3.2 哪些方向失败（< baseline 或持平）
    - 交互/注意力: C2C=0.4865 / CCP=0.4934 / CSF/FLM/pool 全灭
    - loss 监督轴: M140/141/142/143/144 五连败 (LQA 本tick 收尾) → 轴关闭
    - delivery×delivery 组合: 6 次不叠加 (关闭)
    - MFP: s42=0.4869 确认 seed 效应, 轴关闭
  ### 3.3 哪些尚未消融
    - **write-back 互补性的强制方式 (hard vs soft)**: OWC (M150, soft loss) 在队,
      ODW (hard projection) 未测 (本设计 M151)
    - champion CSORT 组合网格: M145-148 在队
    - CSORT seed 鲁棒性: M149-SG (本tick 修复 loss 收集 bug) 在队
  ### 3.4 结论
    - 去相关轴是唯一有效方向。逻辑操作数: token-token (CSORT/ALL/SG) →
      fused-msg vs inst_feats (OWC soft) → 回写结构正交 (ODW hard)。
    - 在队 M145-150 无一个从**结构上**保证回写互补 (全部是 loss 或 message 构造)。
      ODW 是唯一未覆盖的强制方式, 与 OWC 正交对照。

## 7. Risk Assessment（风险评估）

    投影), dec.py 加一行注册。无新参数。py_compile + 结构校验;
    若 crash → Phase 3b 自修复预算 ≤3 次。
  - 资源风险: 无。纯张量运算, 零新增参数/显存/FLOPs; ≤10G 约束满足。
  - 数据风险: 无。复用 point_feats + fm, 无需新数据。
  - 失败回退: 若 M151 1999 峰值 <0.5020 或提升 <0.002 → ODW 证伪, 记录为
    "reinforce 必要" (相关回写有独立价值) 证据; 与在队 M150-OWC 结果合并判定
    write-back 冗余假设的软/硬强制方式结论。

## 8. Smell Check (Phase 1.6)
  - 气味: 无新增模块 (非 LayerNorm/Linear/gate); 无新数值扫参; 唯一辩护点:
    它是 "在 write-back 上加了一个投影算子"。
  - 辩: ODW 是**确定性 Gram-Schmidt 正交投影** (非学习参数、非归一化/缩放/
    温度系数), 改变的是 write-back 与更新目标的**几何关系**: 移除平行分量 →
    回写必然正交。这是新的计算图结构 (定义 "msg ⊥ feats 由构造保证" 的信息流
    属性), 不是数值配置。零新增参数, 零新增超参。因果机制清晰: 相关回写 =
    reinforce (冗余), 正交回写 = complement (新增); 若失败, 结论是 "正交回写
    机制不成立" (reinforce 必要), 而非 "这个值不合适"。
  - 判: 无气味信号命中 + 通过三标准 (新计算图结构 / 零超参 / 因果机制清晰) →
    保留, 本段辩护。与 OWC (M150) 的关系: OWC 是软 loss 惩罚, ODW 是硬结构
    保证, 两者对照回答 "互补性是否需要结构保证"。
