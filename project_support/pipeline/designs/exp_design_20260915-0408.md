## 3. Analysis And Direction
For fixed undirected physical contacts E, logits z, p=sigmoid(z), binary target y:
d_ij=|y_i-y_j|, r_ij=p_i*(1-p_j)+(1-p_i)*p_j.
Independent endpoint Bernoulli variables imply r=P(Y_i != Y_j).
L_edge=mean_E[-d*log(r)-(1-d)*log(1-r)].
This product of edge marginals is a composite loss, NOT a normalized joint graph
likelihood; shared endpoints create dependencies. No partition-function claim.
dL/dz_i=sum_j[(r-d)/(r*(1-r))*(1-2*p_j)*p_i*(1-p_i)]/|E|.
Complementing all y in a connected component leaves d unchanged. Complementing
all z in a component leaves r unchanged. Edge labels alone identify at most a
partition up to a per-component orientation; isolated vertices receive no signal.
For one crossing edge y=(0,1), z=(4,-4), p is reversed but r nearly1.
Descent increases the wrong margin; at all z=0 the gradient is zero for any d.
Complexity O(|V|+|E|); no dense attention. Empty graph returns zero.
Historical adjacent pairwise losses already overlap this primitive; no new
independent innovation asserted. BCA uses oriented y in a count-conditioned
group likelihood and is not this objective; no edits to M196.
Primary-source lookup returned no usable content; arXiv:0911.5372 is an
UNVERIFIED lead this tick. Exact construction novelty remains INCOMPLETE.
