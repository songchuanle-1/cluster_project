## 3. Analysis & Direction（方向分析）
  ### 3.1 哪些方向有效（> baseline）
    - context message (champion): best=0.5012, γ=+0.0118, 机制: cluster→point 直接加回
    - detail message: best=0.5003, γ=+0.0109, 机制: inst_feats - cluster_message (差异信号)
    - 两者机制互补: context 给 "cluster 信念", detail 给 "偏离信念的细节"

  ### 3.2 哪些方向失败（< baseline 或持平）
    - refine 系 (C3=0.4931, M16-CSR=0.4875*): cluster token 进一步处理有害
    - gate 系 (M1-QGC=0.4939, M6-QSF=0.4866): query 驱动的门控无收益
    - residual 系 (B5=0.4944, E4=0.4944): 残差路径无增益
    - routing 系 (A3=0.4468, A4=0.4941): 路由本身降点

  ### 3.3 哪些尚未消融
    - context+detail 互补性: 未测试, 优先级 high (本批)
    - 尺度必要性: M18/M19 正在验证
    - 正交正则化: M17-ORT crashed, pending retry
    - detail 复现: M20-DET waiting

  ### 3.4 结论
    - context(0.5012) 和 detail(0.5003) 是最强的两个独立信号
    - 它们计算路径不同 (加法 vs 减法归一化), 可能互补
    - M21-HYB (sum) 是最简洁的互补性测试
    - 如果 sum>0.5012 → 故事线增加多信号融合; 如果 <0.5012 → 收敛到单信号主线
