## 3. Analysis & Direction
  ### 3.1 Effective directions
    - Multi-scale context readback: +0.0118 over baseline.
    - Content alignment: M157 exceeds its shuffled control M158 by 0.0040.
    - CSORT seed-1999 peak: 0.5020, though not robust across seeds.
  ### 3.2 Failed directions
    - Explicit routing, direct geometry, unconditional decoder cluster access,
      repeated injection, token transforms, and loss combinations failed.
  ### 3.3 Unablated directions
    - Query-to-query ownership competition over overlapping predicted support.
    - Cross-layer mask-change retrieval.
    - Coherent hierarchy-branch retrieval instead of occupancy averaging.
  ### 3.4 Conclusion
    - The strongest next question is whether overlapping queries retrieve the same
      points and contaminate one another. This differs from M161-M166, which alter
      how one query pools its own mask but do not subtract rival ownership.

## 7. Risk Assessment
  - M167 code risk: medium. It adds BxQxN query competition using existing
    masks; cost remains linear in point count and adds no N^2 point attention.
  - Candidate B code risk: medium-high. It must retain two consecutive mask states
    and preserve signed correction semantics without detaching the wrong state.
  - Candidate C code risk: medium. Hard branch selection may make gradients sparse,
    though the previous mask is already a recurrent prediction signal.
  - Resource risk: low for all candidates; no new dataset or large projection stack.
  - Failure fallback: normal patience=10 early stop. Candidates B and C remain
    deferred and are not part of this implemented batch.

## 8. Smell Check
  - A changes information interaction from independent query pooling to competitive
    ownership across queries. It is not a temperature, threshold, or weight sweep.
  - B introduces a temporal two-state correction path. It is not uncertainty
    weighting or a scalar schedule change.
  - C introduces discrete hierarchy-path selection rather than changing a pooling
    coefficient. It tests a coherence hypothesis.
  - No candidate adds a tunable coefficient or changes the training schedule.

## 9. Constraints And Banned Check
  - FLOPs <=10.0G: all proposed operations use existing BxQxN masks or hierarchy IDs.
  - No N^2 point attention: pass.
  - Phase 1 structural-only: pass.
  - No gate, language routing, explicit routing injection, large Q/K/V/O stack,
    residual message family, or numeric sweep.
