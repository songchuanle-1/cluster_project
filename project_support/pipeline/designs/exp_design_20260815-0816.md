## 3. Analysis & Direction（方向分析）
  ### 3.1 哪些方向有效（> baseline）
    - context 回写: 0.5012, γ=+0.0118 — 核心已确认
    - CTF×HCG (seed1999): 0.5012 tie champion; HCG alone 0.5002
  ### 3.2 哪些方向失败（< baseline 或持平）
    - SEF/gate 族 (M93): 0.4910, SE 通道注意力证伪 → 禁区 +1
    - CONS/QMOD/CCP/REAGG/ITER: 0.483-0.498, 约束/一致性/传播类未破顶
    - detail message 组合: 与强基底无正协同
  ### 3.3 哪些尚未消融 / 未验证
    - **champion 自身跨 seed (S42/S123)**: 本 tick 最高优先级 — 破顶判读的关键对照
    - ORT/CSORT 多样性: M97/M98 queued; MLAY: M86 running
    - CTF×HCG seed42 复现: M89 running (server-6)
  ### 3.4 结论
    - 选择理由: 08-14 定案"破顶需跨 seed 验证", 但 champion 自身无跨 seed 数据。
      M97/M98 即将以 champion 为基底测多样性 — 若 champion 真实水平 ~0.497 而
      M97 跑出 0.5012, 会被误判"破顶"。补齐 champion 自身 S42/S123 是任何
      champion 基底实验判读的前置条件, 也是论文证据链的必要项。
