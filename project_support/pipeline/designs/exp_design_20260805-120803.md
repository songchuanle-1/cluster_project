## 1. Motivation（为什么设计这批实验）
  - 项目动机（goal.json description）: cluster: 多尺度 cluster context 机制 — cluster bank
    聚合点云特征→cluster_attn 把多尺度 context 回写更新 inst_feats→提升定位精度。注: 原'
    聚类路由'假设已被证伪(routing 生效反降点), 收益来自 context 而非 routing。目标 mIoU ≥ 0.51。
  - 故事线当前状态: context 回写确认有效 (+0.0118); routing 证伪; readback expressiveness
    轴闭合; 融合权重形式轴本 tick 收束 (SWI/CSF/SCF 全 < champion); 聚合/message/投影/
    token 多样性轴在队列 (CCR/VAC/SAC/PSR/SSP/SCT/ORTG)。
  - 触发原因: 队列深度不足: waiting=5 (M58 srv6 + M61/62/63/64 srv4) < 可用槽 5+1=6 → 需补 1。
  - 这批变体在故事线中的角色: **验证故事根基声称 "多尺度 context 有效" 的真正形式** —
    代码审读发现 champion 的粗尺度 gather 长度错配, 多数点收不到中/粗尺度 context,
    0.5012 实为准单尺度增益。HCG 正确交付完整多尺度 context, 检验其是否超过准单尺度。

## 3. Analysis & Direction（方向分析）
  ### 3.1 哪些方向有效（> baseline 0.4894）
    - 多尺度 context 回写: DRP 0.5012, γ=+0.0118 — 核心机制 (但准单尺度, 见 §3.4)
    - detail message: 0.5003, γ=+0.0109 (D1)
  ### 3.2 哪些方向失败（< champion 或持平）
    - readback expressiveness: BIL/NLR/FILM/FLM/DGC 全 < champion (轴闭合)
    - 融合权重形式: SWI 0.4970 / CSF 0.4958 / SCF 0.4927 全 < champion (本 tick 收束)
    - 聚合双分支: DCA 0.4893 < mean
  ### 3.3 尚未消融 / 结构空白
    - **粗尺度 context 交付**: 所有 56 变体 (含 champion) 的 `_cluster_to_points` 中,
      `cluster_ids_list[lvl]` 对 lvl>0 存"父级 token→簇"映射 (长度 K_{lvl-1}), 而代码
      `msg[b, :n_valid]=cf[b, ids_b]` 把它写到前 K_{lvl-1} 个**点**槽。索引 > K_{lvl-1}
      的点 (绝大多数) 中/粗尺度 message = 0。docstring 声称 per-point ids, 实现不符。
      从未有变体逐级组合 点→lvl0→lvl1→lvl2 映射。
  ### 3.4 结论
    - 30+ 变体全收敛 ≤ 0.5012, 且所有失败集中在 message 内容/融合/投影/聚合 — 这些都在
      "残缺的粗尺度交付" 下测试。**故事核心声称 "多尺度 context" 从未被正确检验**。
      HCG 是第一个正确送达每点多尺度 context 的变体: 若粗尺度真有用, 破 0.5012 天花板;
      若无用, 则明确 "增益来自细尺度 256 簇" (故事修正, 同样是重要结论)。优先级最高。

## 7. Risk Assessment（风险评估）
  - 代码风险: 低。HCG 仅覆写 _cluster_to_points 的 gather 段 (~25 行), 复用融合逻辑与
    level_gate/point_out_proj。无新参数/CUDA 扩展/新依赖。gather 用 clamp 防越界。
  - 资源风险: 无。参数数与 champion 相同, FLOPs 增加仅 O(N) 索引 gather (可忽略),
    远低于 FLOPs≤10G。显存无增量。
  - 数据风险: 无。复用 ScanRefer, seed 1999 一致。
  - 失败回退: 若 crash 3 次 → 放弃 HCG, 标记 question, 队列深度回落 5 (需再补设计)。
    本变体与已跑通 DRP 仅差 gather 段, crash 概率极低。
  - 语义风险: 正确粗尺度 context 可能对多数点引入噪声 (gate 可学到降权), 结果 < 0.5012
    时结论为 "粗尺度 context 无益", 仍是故事修正的推进, 非白跑。
