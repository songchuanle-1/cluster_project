## 1. Motivation（为什么设计这批实验）
  - 项目动机（goal.json description）: cluster: 多尺度 cluster context 机制 — cluster bank
    聚合点云特征→cluster_attn 把多尺度 context 回写更新 inst_feats→提升定位精度。注: 原'
    聚类路由'假设已被证伪(routing 生效反降点), 收益来自 context 而非 routing。目标 mIoU ≥ 0.51。
  - 故事线当前状态: context 回写确认有效 (A1−A0=+0.0118) 但 champion 实为准单尺度 (粗尺度
    gather 长度错配); M61-SCT 本 tick 终态 (0.4854 < baseline) 闭合顺序依赖子维度;
    {message 构造}×{交付正确性} 3×2 矩阵已填满 (M63-PSR/M65-HCG/M66-DET-HCG/M67-PSR-HCG);
    投影放置轴只有 M64-SSP 一格 (仍在残缺交付下)。
  - 触发原因: 队列深度不足: M61-SCT 终态后 waiting=5 (M64/65/66/67 srv4 + M58 srv6)
    < 可用槽 5+1=6 → 需补 1。
  - 这批变体在故事线中的角色: **填补 {投影放置}×{交付正确性} 2×2 因子矩阵最后一格** —
    per-scale 独立投影 (SSP, M64) × 正确多尺度交付 (HCG, M65)。SSP 的因果机制依赖每尺度
    信号真实送达, 残缺交付下被零信号抑制; HCG 正确交付后 per-scale 投影才有机会工作。

## 3. Analysis & Direction（方向分析）
  ### 3.1 哪些方向有效（> baseline 0.4894）
    - 多尺度 context 回写: DRP 0.5012, γ=+0.0118 — 核心机制 (但准单尺度)
    - detail message: D1 0.5003, γ=+0.0109 — 独立有效
  ### 3.2 哪些方向失败（< champion 或持平）
    - 融合权重形式: SWI/CSF/SCF/DET-QSF/DET-CSF 全 < champion (融合轴闭合)
    - readback expressiveness: BIL/NLR/FILM/FLM/DGC 全 < champion (轴闭合)
    - 顺序 readback: M61-SCT 0.4854 < baseline (本 tick 终态, 顺序依赖闭合)
    - 聚合双分支: DCA 0.4893 < mean
  ### 3.3 尚未消融 / 结构空白
    - **per-scale 投影 × 正确交付**: M64-SSP 在残缺交付下测得 (粗尺度为 0, 机制被抑制),
      HCG 正确交付后 per-scale 投影未测 — **本次 M68**
  ### 3.4 结论
    - 30+ 变体全收敛 ≤0.5012, 失败集中在 message 内容/融合/投影/顺序 — 均在残缺交付下。
      M64-SSP (per-scale 投影) 的因果机制是尺度特异语义空间, 但粗尺度零信号使投影学不到
      粗尺度变换。HCG 正确交付是故事核心声称首测 (P0); 在其结果到达前, 把 SSP 与 HCG
      组合是最低成本的补格, 使 {投影}×{交付} 2×2 完整。M68 与 M66/M67 的差异是投影
      放置 (融合前 per-scale vs 融合后共享), 与已接受的 M64-SSP vs champion 的差异同构。

## 7. Risk Assessment（风险评估）
  - 代码风险: 低。ssp_hcg 包 = hcg 包物理拷贝 + 一个继承类 (组合 HCG 的 _cluster_to_points
    与 SSP 的 scale_projs 逻辑), 无新外部依赖; dec.py 仅加一个 dispatch 条目。与
    M66-DET-HCG (det_hcg = hcg 拷贝 + detail) 完全同构。
  - 资源风险: 无。新增 (num_scales−1)×d×d = 131K 参数 (2 个 Linear, 与 M64-SSP 相同),
    远低于 FLOPs≤10G 约束。
  - 数据风险: 无。复用 ScanRefer, seed 1999 一致。
  - 失败回退: 若 crash 3 次 → 放弃 SSP-HCG, 标记 question, 队列深度回落 5 (需再补设计)。
    但 ssp_hcg 与已跑通/已入队的 hcg、ssp 仅差组合逻辑, crash 概率极低。
  - 语义风险: 正确多尺度 + per-scale 投影可能不比 HCG 共享投影好 (per-scale 投影在真多尺度
    下可能被 level_gate 吸收) — 此时 2×2 给出 "SSP 与正确交付无协同" 的排除性结论,
    仍是故事推进。
