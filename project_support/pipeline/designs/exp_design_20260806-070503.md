## 3. Analysis & Direction（方向分析）
  ### 3.1 哪些方向有效（> baseline 0.4894）
    - 多尺度 context 回写: DRP 0.5012, γ=+0.0118 — 核心机制 (但准单尺度)
    - detail message: D1 0.5003, γ=+0.0109 — 独立有效, 残差 message 形式
  ### 3.2 哪些方向失败（< champion 或持平）
    - 融合权重形式: SWI 0.4970 / CSF 0.4958 / SCF 0.4927 / DET-QSF 0.4961 / DET-CSF 0.4973
      全 < champion (融合轴闭合, 本 tick M60 再证 detail+CSF 无协同)
    - readback expressiveness: BIL/NLR/FILM/FLM/DGC 全 < champion (轴闭合)
    - 聚合双分支: DCA 0.4893 < mean (mean 最优)
  ### 3.3 尚未消融 / 结构空白
    - **正确多尺度交付**: M65-HCG 已入队 (P0, 故事核心声称首测)
    - **{交付}×{message} 交互**: (correct, detail)=M66 已入队; (correct, per-scale
      residual)=**M67 本次** — 从未测过
  ### 3.4 结论
    - 所有失败集中在 message 内容/融合/投影, 均在残缺交付下测得。正确多尺度交付 (HCG)
      是最强未验证结构声称; 在其结果到达前, 把 PSR (逐尺度偏差 message, 独立假设) 与
      HCG 组合是最低成本的补格, 使 3×2 完整。M67 与 M66 的差异是信息流 (融合前逐尺度
      残差 vs 融合后单残差), 与已接受的 M63-PSR vs D1-detail 的差异完全同构。

## 7. Risk Assessment（风险评估）
  - 代码风险: 低。psr_hcg 包 = hcg 包物理拷贝 + 一个继承类 (组合 HCG 的 _cluster_to_points
    与 PSR 的残差逻辑), 无新外部依赖; dec.py 仅加一个 dispatch 条目。与 M66-DET-HCG
    (det_hcg = hcg 拷贝 + detail) 完全同构。
  - 资源风险: 无。无新增可学习参数 (LayerNorm 无参数, gather 为 O(N)); FLOPs/显存与
    champion 相同, 远低于 FLOPs≤10G 约束。
  - 数据风险: 无。复用 ScanRefer, seed 1999 一致。
  - 失败回退: 若 crash 3 次 → 放弃 PSR-HCG, 标记 question, 队列深度回落 5 (需再补设计)。
    但 psr_hcg 与已跑通/已入队的 hcg、psr 仅差组合逻辑, crash 概率极低。
  - 语义风险: 正确多尺度 + 逐尺度残差可能不比 HCG 绝对 token 好 (残差在真多尺度下可能被
    level_gate 吸收) — 此时 3×2 给出 "PSR 与正确交付无协同" 的排除性结论, 仍是故事推进。
