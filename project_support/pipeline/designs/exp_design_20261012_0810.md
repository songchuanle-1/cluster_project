# Experiment Design: Target Mention Rebinding

## 1. Motivation
goal.json: diagnose actual ScanRefer errors and design a falsifiable lightweight
mechanism; existing context is evidence, not a new mechanism. The observed
native parser role contradicts the annotated target noun in one frozen case
and actually changes native projected-tensor gradients under same-forward
intervention. This experiment tests whether a TRAIN-only positive-set correction
is executable; it does not establish trained gain or independent novelty.

## 2. Core Mechanism
For annotation a, literal label-name span S_a is eligible only when unique,
nonempty and disjoint from the parsed root noun span. Let p_a be its tokenizer
support distribution, P_a the original target token distribution and O_a the
original other-entity distribution:

P'_a=p_a; O'_a=clip(O_a+P_a,0,1)*(1-support(p_a)).

All other token-role maps, native matching/query masks/loss weights are
unchanged. Use the original native semantic alignment L(P',O') and original
total loss. Ground-truth TRAIN labels only construct training supervision;
predict never reads or uses them. Ineligible/unknown rows preserve original maps.
Gradient propagates through the existing native semantic alignment to projected
queries/text and existing trainable parameters; no new trainable tensor.
Degeneracies: no literal target, multiple mentions, original overlap => bypass.
Category equality never supplies physical co-reference labels.

## 7. Risk Assessment
Literal object_name can be inconsistent with description or scene identity;
one clear example does not establish population harm. Role modifiers/pronouns
are not automatically reassigned. This scoped noun intervention may be
insufficient or harmful. Original native stochastic/non-deterministic primitives
may prevent strict repeat; preserve the failure, do not loosen tolerances.
Data correction must not be misrepresented as a new generic alignment loss.
