## 1. Motivation（为什么设计这批实验）

    机制 — cluster bank 聚合点云特征→cluster_attn 把多尺度 context 回写更新
    inst_feats→提升定位精度。注: 原'聚类路由'假设已被证伪(routing 生效反降点),
    收益来自 context 而非 routing。目标 mIoU ≥ 0.51"
  - 故事线当前状态:
    已验证: context 回写有效 (+0.0118); **M86-MLAY 隔离出多尺度 context 深度是
    核心收益来源** (2层 legacy=0.5010); 组合线 (architecture×loss / loss×
    decoder-access) 多例不叠加 — **本tick M148-CSORT-DCM=0.4990 再证**;
    M145-ALL 证伪"多对更好" (扩展 CSORT 对范围有害)。
    未验证: **context 的尺度范围** — 当前 [256,64,8] 无场景级全局 token,
    readback 全局信息只经 level_gate 权重 (global_mean), 不进 message 本身。
  - 触发原因: M149 推送后 waiting=4 < 容量4+1=5 → 自主补设计 1 个
  - 这批变体在故事线中的角色: **验证假设X (多尺度 context 深度×尺度范围)** —
    若全局尺度破平台, "深度+完整尺度范围"补全 context 质量轴最后一格; 若失败,
    排除"更粗尺度有帮助"方向 (与 M145-ALL 共同构成"尺度扩展无益"证据)。

## 3. Analysis & Direction（方向分析）
  ### 3.1 哪些方向有效（> baseline）
    - context 回写 (A1): 0.5012, γ=+0.0118 (核心, 已确认)
    - 多尺度 context 深度 (M86 legacy 2层): 0.5010, γ=+0.0116 (深度=核心收益)
    - cross-scale orth (CSORT): 0.5020 (破平台, seed 脆弱)
    - masked feature prediction (MFP): 0.5020 (破平台)
    - decoder-access 单轴 (DCM): 0.5010 (平台饱和, 组合无协同)
  ### 3.2 哪些方向失败（< baseline 或持平）
    - 交互/注意力: C2C/CCP/CSF/FLM/pool 全灭
    - loss 监督轴: M140-144 五连败 → 轴关闭
    - **M148-CSORT-DCM (本tick)**: 0.4990 — CSORT×decoder-access 负交互,
      decoder-access×CSORT 组合关闭
    - M145-CSORT-ALL: 0.4920 — 全尺度对扩展失败 (更多 CSORT 对有害)
    - architecture×loss 组合: 6+ 次不叠加
  ### 3.3 哪些尚未消融
    - **context 尺度范围**: 从未加过全局场景尺度 (本设计) — 与 CSORT 对范围
      (M145-ALL/M152-F1) 不同维度, 前者是 context 源, 后者是 loss 范围
    - loss×loss 双机制: M153 在队
    - CSORT seed 鲁棒性: M149-SG 在队
    - write-back 正交 (soft/hard): M150/M151 在队
  ### 3.4 结论
    - 0.5020 平台证据链: 深度是核心收益, 解相关仅边际; 组合全不叠加; CSORT 对
      范围扩展有害。**剩下最后一个未检的 context 质量格: 尺度范围补全局**。
      全局 token 是零参新增 (K=1, 均值聚合) 的信息路径, 与 level_gate 的
      global_mean (只当权重) 正交 — 全局 context 首次进入 message 本身。

## 8. Smell Check (Phase 1.6)
  - 气味: 无新增 loss/超参 (csort_weight=0.01 不变); 不是"在 X 处加一个
    LayerNorm/Linear/scaling" (新增的是完整尺度层级 + 新 message 路径 + 新
    level_gate logit + 新 CTF FFN 分支); 不是数值扫参 (cluster_layer_nums 的
    结构值 [...,1] 由因果论证决定, 非试值); 不是改数值分布 (信息流多一条
    全局 message 路径)。
  - 辩: 1) 验证的是**因果假设** "全局场景尺度是否补全 context 质量", 失败结论
    是机制层面 (冗余/稀释), 不是"这个值不合适"。2) **新计算图**: 全局 token
    经 partitioner 新层级 → 级联聚合 → CTF FFN → HCG composed gather 广播 →
    level_gate 4 路融合, 是新的信息交互拓扑。3) **超参有依据**: cluster_layer_nums
    [...,1] 的 "1" 是"单个场景 token"的结构语义 (全局尺度 = 整场景), 非扫参;
    其余全沿用 champion 验证值。4) **参数增量**: 4th CTF FFN (d_model→hidden→
    d_model) 约 0.4M 参数, 远超 5K, 且伴随新计算图 → 不触发气味 #1。
  - 判: 无气味信号命中 + 通过三标准 (新计算图/超参有依据/因果机制清晰) → 保留,
    本段辩护。
