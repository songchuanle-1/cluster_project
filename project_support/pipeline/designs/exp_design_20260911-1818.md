## 3. Analysis And Direction

### 3.1 Selection Formula

For candidate q, define:

    u_q = indis_logits[q, 1] - indis_logits[q, 0]
    p_q = softmax(indis_q)[1]
    m_qn = sigmoid(mask_logits[q, n])
    IoU_q = IoU(sigmoid(mask_logits_q) >= .5, GT)

The diagnostic tested whether `p_q` is a useful ordering of `IoU_q`.
It is not reliable for the recoverable stratum, even though it is informative
for successful banks. The proposed candidate mechanism is a learned
language-mask support contrast, not another pooling or selector family:

    v_q^+ = sum_n m_qn f_n / (sum_n m_qn + eps)
    v_q^- = sum_n (1 - m_qn) f_n / (sum_n (1 - m_qn) + eps)
    e_q = g(v_q^+, l) - g(v_q^-, l)
    s_q = u_q + lambda e_q

The log-odds form is a hypothesis, not a theorem: it assumes the support
contrast is an additive evidence term. The primary-source review must test
whether existing work already defines this same support-versus-complement
contrast or an equivalent likelihood ratio.

### 3.2 Gradients And Degeneracies

For a listwise candidate loss

    L = -log softmax(s)_y,

the score gradient is

    dL/du_q = softmax(s)_q - 1[q = y].

The mask branch receives an additional selection path

    dL/dm_qn = lambda (dL/du_q) (dg(v_q^+, l)/dm_qn
                                  - dg(v_q^-, l)/dm_qn),

plus the existing mask matching loss. The exact matrix form depends on `g`.

Degeneracies that must be tested before training:

- A whole-scene mask makes `v_q^+` and `v_q^-` similar, so `e_q` collapses.
- A tiny high-confidence mask should not receive unbounded evidence; support
  normalization and area controls are required.
- Saturated sigmoid masks can kill the selection gradient through `m_qn`.
- If `v_q^+` and `v_q^-` retain global scene information, `e_q` can become a
  second unary classifier and provide no identity-specific evidence.
- If the language branch is shuffled, `e_q` must lose its ranking utility.

The following are nearest-source comparisons to verify from full text before
any admission:
