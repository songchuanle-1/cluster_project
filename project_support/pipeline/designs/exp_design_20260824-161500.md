## 3. Analysis & Direction（方向分析）
  ### 3.1 哪些方向有效（> baseline）
    - context 回写 (A1): 0.5012, γ=+0.0118 (核心, 已确认)
    - decoder-access 轴 DCM: 0.5010, γ=+0.0116 (方向①最优, qla 共享通路)
    - 多层注入 MLay: 0.5010, γ=+0.0116 (方向②, 2层)
  ### 3.2 哪些方向失败（< baseline 或持平）
    - MFP: 0.5020 (seed1999) 证伪 — 3-seed 均值 0.4950, s42 < baseline (本 tick 关闭)
    - encoder-side token 质量轴: CCL=0.4890, CGA=0.4926, BCF=0.4926, SRL=0.4912
    - DCA (decoder 独立分支): 0.4970 < DCM 0.5010
    - detail×DCM: 0.4990 (无协同); detail×DCA: 0.4870 (负交互)
    - CSORT 跨 scale: 3/4 seed 负, 轴关闭
  ### 3.3 哪些尚未消融
    - **{①qia×②多层注入} 组合: 从未测** (本次设计 M136)
    - **DCMV (qia) seed 稳健性: 从未验证** (本次设计 M137)
    - {qla,qia}×{cluster KV} 双通路叠加: M134-DUAL queued
    - DCM seed: M135-DCM-S42 queued
  ### 3.4 结论
    - 平台 ~0.501-0.502 由 seed-1999 决定, 单轴机制已到天花板。方向① (decoder-access)
      与方向② (多层注入) 是仅存两条已验证结构路线。
    - 其交叉组合矩阵 {①qla, ①qia}×{②}: M126 (②×①qla) queued, **②×①qia 缺格**。
      这是组合矩阵唯一未测格, 补格成本极低 (复用 dcmv 分支 + cluster_att_num_layers=2,
      零新模块)。
    - DCMV 作为方向① qia 侧最优候选, 无 seed 对照是硬性论文缺口 (与 DCM 对照 M135
      同型), 必须在机制结论之前补上。
