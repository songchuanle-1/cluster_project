## 3. Analysis & Direction（方向分析）
  ### 3.1 哪些方向有效（> baseline 0.4894）
    - cluster context (champion): 0.5012, γ=+0.0118 — 核心机制, ReLU + dropout=0.0
    - ORT orthogonality regularization (M17): 0.5005, γ=+0.0111 — GELU + cluster_att_num_layers=1 + orth_weight=0.01
    - detail message_type (D1): 0.5003, γ=+0.0109 — 替代 message type
  ### 3.2 哪些方向失败（< champion 或持平）
    - 所有机制组合 (ORT+detail, ORT+HYB, HYB alone) 均不及单机制
    - Cross-scale attention (XCA=0.4954), max-pool (CMX=0.4910), refine (REF=0.4892) — 均不及 champion
    - Scale ablation (S2FM=0.4933, S2FC=0.4944) — 3-scale 确有必要
  ### 3.3 关键观察: 正则化完全未探索
    - Champion 架构: dropout=0.0 everywhere (CrossAttentionLayer, SelfAttentionLayer, FFN, C2F_ClusterAttn), ReLU 激活
    - 标准 transformer 实践: dropout≥0.1 (Vaswani et al., BERT, ViT, DETR), GELU 激活
    - 所有实验的收敛模式: peak ep13-25 → decline → early-stop — 经典过拟合信号
    - ORT (GELU+dropout=0.0) 0.5005 vs champion (ReLU+dropout=0.0) 0.5012 — GELU 在 ORT 组合中未能超越 ReLU 在 champion 中，但非隔离测试
  ### 3.4 结论
    - 下一步选择: dropout 正则化 + GELU 激活 — 最明显的未探索维度
    - 理由: (1) 过拟合信号强烈且一致 (2) dropout=0.0 在 transformer 中极不寻常 (3) YAML-only 零代码风险 (4) 不违反任何 banned[]/constraints[]
