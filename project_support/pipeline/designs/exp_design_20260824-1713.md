## 3. Analysis & Direction（方向分析）
  ### 3.1 哪些方向有效（> baseline）
    - context 回写 (A1): 0.5012, γ=+0.0118 (核心, 已确认)
    - decoder-access 轴 DCM (qla): 0.5010, γ=+0.0116 (方向①最优)
    - 多层注入 MLay (2层): 0.5010, γ=+0.0116 (方向②)
  ### 3.2 哪些方向失败（< baseline 或持平）
    - DCMV qia 单轴: 0.4950, γ=-0.0060 vs DCM — qia 视觉通路访问 cluster KV 弱
      (本 tick 新证据)
    - encoder-side token 质量轴: 0.489-0.495 全灭
    - MFP/CSORT: 3-seed 证伪
    - detail×DCM: 0.4990 (无协同)
  ### 3.3 哪些尚未消融
    - **{②层}×{DUAL 双通路} 满强度组合: 从未测** (本次设计 M138)
    - {双通路}×{1层} = M134 queued (在测)
    - seed 矩阵: M135/M137/M122 queued
  ### 3.4 结论
    - 平台 ~0.501-0.502 由 seed-1999 决定, 单轴机制已到天花板。
    - 剩余唯一未测的结构空间: 两个已批准突破方向的满强度组合。
      若该格不破顶, 则当前机制空间已探尽, 是转向新范式的关键判据。
