## 3. Analysis & Direction（方向分析）
  ### 3.1 哪些方向有效（> baseline）
    - context 回写 (A1): 0.5012, γ=+0.0118 (核心, 已确认)
    - decoder-access 轴 DCM: 0.5010, γ=+0.0116 (方向①最优, qla 共享通路)
    - 多层注入 MLay: 0.5010, γ=+0.0116 (方向②, 2层)
    - MFP aux loss: 0.5020 (seed1999), M129 已证伪倾向 → 机制性待定
  ### 3.2 哪些方向失败（< baseline 或持平）
    - encoder-side token 质量轴: CCL=0.4890, CGA=0.4926, BCF=0.4926, SRL=0.4912 (掉点)
    - CSORT 跨 scale: 3/4 seed 负, 轴关闭
    - DCA (decoder 独立分支): 0.4970 < DCM 0.5010, decoder-access 内对比淘汰
    - detail×DCM: 0.4990 (无协同); detail×DCA: 0.4870 (负交互)
  ### 3.3 哪些尚未消融
    - **{qla,qia}×{cluster KV} 双通路叠加 DUAL: 从未测试** (本次设计 M134)
    - **DCM seed 稳健性: 从未验证** (本次设计 M135)
    - MFP 机制性: M130 seed123 判定中 (M131/M132 conditional)
  ### 3.4 结论
    - 平台 ~0.501-0.502 由 seed-1999 决定 (M95 已证伪), 单轴机制已到天花板。
    - decoder-access 轴是当前最有效方向 (DCM 0.5010 > DCA 0.4970)。该轴的 2×2
      {context/detail}×{DCA/DCM} 矩阵已满格; 剩下的自然扩展是 {qla,qia} 双通路
      叠加 (DUAL) — 补格成本极低 (config-only, 零新模块), 且是唯一能判定"通路
      可叠加性"的实验。
    - 同时 DCM 作为轴内最优机制, 缺乏 seed 稳健性证据。M90/M91 (CTF-HCG seed)
      证明核心 writeback 机制跨 seed 脆弱, M120/M122 (MLay seed) 正在验证多层注入;
      DCM 的 seed 对照是 decoder-access 轴能否进论文的硬性缺口。

## 7. Risk Assessment（风险评估）
  - 代码风险: 极低。纯包复制 + config 参数变更。
    M134-DUAL 依赖 DCMV 已验证的 use_cluster_mem_visual 分支 (M133 running 正常)
    与 DCM 的 use_cluster_mem 分支 (M124 跑通 0.5010)。两个 if 分支在
    Decoder_layer.forward 中相互独立 (qia 扩展 → query_qia; qla 扩展 → query_qla),
    无交互副作用。M135 纯 seed 变更 (M90/M91/M120 先例)。
  - 资源风险: 低。与 DCM/DCMV 相同显存/FLOPs 量级 (零新增参数, 仅 KV concat),
    满足 FLOPs ≤ 10G 约束; server-4 RTX5090 显存充足。
  - 数据风险: 无。同一 ScanRefer 数据。
  - 失败回退: 两变体均不依赖 MFP seed 或 DCMV 结果, 独立保持队列深度。
    若 crash 3 次 → 放弃标记 question, 聚焦排队中组合实验 (M125/M126/M131/M132)
    与 MFP 判定结果。
