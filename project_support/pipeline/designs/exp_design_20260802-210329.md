## 3. Analysis & Direction
  ### 3.1 What works (> baseline)
    - Context readback (champion/DRP): +0.0118 vs baseline, confirmed effective
    - Token regularization (ORT): 0.5005, modest gain
    - Token FFN refinement (CTF): 0.4995, token quality helps but doesn't break ceiling
    - Soft assignment readback (NCR): 0.4980, soft readback feasible

  ### 3.2 What failed
    - Learned weights: WCA(0.4890), gate-series — learned weighting consistently underperforms
    - Normalization only: CLN(0.4930) — pure norm insufficient
    - Inter-cluster attention: C2C(0.4865) — cross-token interaction not beneficial

  ### 3.3 Being tested (in queue / running)
    - Per-channel modulation: M47-FILM (running, GPU0)
    - Point-conditional bilinear: M48-BIL (waiting)
    - Nonlinear MLP readback: M49-NLR (waiting)

  ### 3.4 This batch: M50-DGC
    - Hypothesis: The 0.5012 ceiling stems from single-path additive readback — cluster context is always ADDED regardless of whether the point already agrees. DGC uses a difference-based gate to adaptively balance cluster-context vs self-preservation.
    - Why now: DGC is the 4th dimension of readback expressiveness (conditionality, nonlinearity, modulation, adaptivity). Testing all 4 in parallel maximizes exploration efficiency.
    - Distinction from gate-series: Unlike cag/cfe/layerscale (pure learned scalar weights), DGC has a genuine computation graph: difference computation → gate → dual-path with complementary blending.
