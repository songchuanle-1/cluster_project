## 1. Motivation（为什么设计这批实验）
  - 项目动机: cluster 多尺度 context 机制 — cluster bank 聚合点云特征→cluster_attn
    把多尺度 context 回写更新 inst_feats→提升定位精度。目标 mIoU ≥ 0.51。
  - 故事线当前状态: context 回读已确认有效 (+0.0118); routing 已证伪; 读回 expressiveness
    轴闭合 (BIL/NLR/FILM/FLM); token 质量非瓶颈 (CTF); CTF 分析将剩余瓶颈指向
    "readback/融合机制"; 融合机制轴已试 token 级 (XCA/CSF) 与静态 gate 形式 (SWI), 但
    从未探过各尺度融合权重间的"顺序依赖"。

  - 这批变体在故事线中的角色: 验证假设 "readback 融合机制需要顺序依赖 (粗→细条件注入)"。

## 3. Analysis & Direction（方向分析）
  ### 3.1 哪些方向有效（> baseline 0.4894）
    - 多尺度 context 回读: champion/DRP 0.5012, γ=+0.0118 — 核心机制
    - token 多样性: ORT 0.5005, γ=+0.0111 — 有帮助但非瓶颈
    - detail message: 0.5003, γ=+0.0109 — message 质量提升
  ### 3.2 哪些方向失败（< baseline 或持平）
    - readback expressiveness: BIL(0.4919)/NLR(0.4948)/FILM(0.4936)/FLM(0.4865) 全 < 0.5012
    - token 级跨尺度交互: XCA(0.4954)/CSF(0.4958) 无益
    - 组合: M24-ORT-D(0.4955)/M26-ORT-HYB(0.4998)/E4(0.4944) 无叠加
  ### 3.3 尚未消融
    - point-level 内容自适应尺度选择 (SCF, 已入队 M55) — 覆盖"内容匹配"子维度
    - 组合可叠加性 (M56-M60 已入队) — 覆盖"组件叠加"子维度
    - 顺序依赖 readback (M61-SCT, 本次) — 覆盖"尺度间信息流依赖"子维度
  ### 3.4 结论
    - 下一步选择理由: 队列已覆盖 内容自适应(SCF)+组合(M56-60)+聚合/级联/空间 (DCA/CCR/VAC/SAC)。
      仅需补 1 个达到深度下限 6。顺序依赖 readback 是融合机制轴最后一个未探的结构性子维度,
      与 SCF 正交 (SCF=内容匹配, SCT=顺序依赖), 二者并行给出融合机制瓶颈的完整判定。
