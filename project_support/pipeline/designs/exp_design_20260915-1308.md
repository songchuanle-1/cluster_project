## 3. Analysis And Direction
For disjoint components C covering boundary B, n=|B|, k=sum(y),
k_C=sum(y_C), and Z_k(z)=sum_{|S|=k} exp(sum_{i in S} z_i).
Global BCA L_g=(log Z_k-y.dot(z))/n.
Component loss L_c=(sum_C log Z_kC(z_C)-y.dot(z))/n.
Let A be the event that every component has exactly its observed count,
under the global fixed-k distribution. Disjoint factorization gives
P(A|k)=prod_C Z_kC/Z_k. Therefore L_c=L_g+log P(A|k)/n.
Since P<=1, L_c<=L_g; a smaller loss is not evidence of better predictions.
Global likelihood decomposes as P(y|k)=P(A|k)P(y|A,k).
Component conditioning removes the component-count-event NLL, retaining
within-component assignment. It does not add supervision to global BCA.
This is not a general rejection: removing a nuisance count allocation may
help optimization, while retained BCE can supervise absolute counts.
Gradient: dL_c/dz_i=(P(i selected|A,k)-y_i)/n; independent constant shifts
on each C leave L_c invariant. The corresponding global gradient uses only k.
Mixed components satisfy the 1110 boundary-domain invariant; construct them
as disjoint paths with alternating labels. Connected control has L_c=L_g.
Production DP complexity O(sum_C |C|min(k_C,|C|-k_C)) plus graph traversal;
the offline enumerator is exponential and MUST NOT become production code.
Prior-art original-source verification remains incomplete after empty web
retrieval; this elementary derived identity is not presented as novel.
