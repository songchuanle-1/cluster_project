### M17-ORT 详细设计
  - 机制: 在 cluster attention forward 中, 计算每尺度 cluster tokens 的 pairwise cosine similarity,
    加正则项: L_orth = λ * Σ_s mean(|cos_sim(T_s[i], T_s[j])| for i≠j)
    其中 s ∈ {fine(256), medium(64), coarse(8)} 为尺度, λ 为可学习权重(init=0.01)
  - 仅对 coarse 尺度(K=8 tokens) 施加: fine/medium 维度太大且 token 天然多样,
    coarse 尺度 token 少(8个)更可能冗余, 正则化效果最明显
  - 实现: 复制 champion 模型包 → _ort 包;
    在 hier_postprocess.py 中新增 C2F_ClusterAttn_ORT(C2F_ClusterAttn_Lite);
    forward 末尾追加 orth loss 到 extra_losses dict
  - config 新增: model.dec.cluster_mode=ort, criterion.orth_weight=0.01
