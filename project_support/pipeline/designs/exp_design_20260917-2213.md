`q_positive * (1 - q_hardest_nonreferenced)`, where all values are detached
mask-overlap quantities. It kept the existing two-way referent logits and

hard-negative referent ranking, both explicitly closed. ConcreteNet already
uses contrastive supervision to separate repeated same-class instances, and
arXiv 2411.03405v1 already adds per-instance offsets to the referred object and
documents cross-modal instance-separation losses. The proposed multiplication
changes target parameterisation, not the causal supervision unit.
