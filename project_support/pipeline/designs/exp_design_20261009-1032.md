## 3. Analysis And Direction
- Fixed TRAIN32-scene/128-expression population,123 cut-bearing expressions,789 cut edges. All eligible groups included; geometry/label repeat exact.
- Original XOR realization fails label-orientation identifiability and zero-logit activity. Preserve it,do not mislabel as PASS.
- For each prediction-blind unique undirected centroid1NN edge(i,j),native target y defines s=y_i-y_j. On s!=0, predict preference P(target-side greater)=sigmoid(s*(z_qi-z_qj)).
- L_edge=mean softplus(-s*(z_qi-z_qj)); add at native unit mask-NLL coefficient to the original matched-query mask BCE at final/auxiliary layers. Existing loss normalization and auxiliary schedule remain.
- dL/dz_i=-s*sigmoid(-s*(z_i-z_j)); dL/dz_j=-dL/dz_i. Each edge moves endpoints in the intended direction,including equal logits. Offset direction is deliberately unconstrained by this term; unary BCE/Dice anchor it.
- Mixed second derivative=-sigmoid(d)*sigmoid(-d) is nonzero. Four-state independent joint CE would factor to unary reweighting,and is not this implementation.
- O(N log N) CPU graph search,O(QE) sparse loss; no new trainable tensors,no N-by-N attention or inferred graph merge.
- Original literature differences/limitations are in the review. The loss primitive is standard,not a novelty claim; full novelty remains unverified.

## 7. Risk Assessment
-1NN graph is sparse and may omit important target-boundary pairs; five frozen expressions have no eligible cuts and retain original loss.
- Derived label cuts could overemphasize annotation artifacts. Original native target binding is retained,no relabeling; subgroup evaluation is mandatory.
- Generic pairwise-ranking/affinity ideas are prior art; task-specific value is empirical and not guaranteed. No generic affinity novelty claim.
- Shared GPU affects latency; FLOPs and per-process allocated memory are directly measured,but latency uncertainty remains explicit.
- A new loss can change convergence even with unchanged schedule. Keep existing convergence/branch-stop rules; do not tune coefficient after seeing results.
