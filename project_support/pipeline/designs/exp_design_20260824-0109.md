## 1. Motivation（为什么设计这批实验）
  - 项目动机（直接引用 goal.json description）: "cluster: 多尺度 cluster context 机制 —
    cluster bank 聚合点云特征→cluster_attn 把多尺度 context 回写更新 inst_feats→提升
    定位精度。注: 原'聚类路由'假设已被证伪(routing 生效反降点), 收益来自 context 而非
    routing。目标 mIoU ≥ 0.51"
  - 故事线当前状态:
    已验证: context 回写有效 (+0.0118); decoder-access 轴 DCM=0.5010 最优;
            2层注入 MLay=0.5010; MFP=0.5020 tie champion (机制性未定, M129/M130 判定中)
    已证伪: routing / CSORT 跨 seed / encoder-side token 质量轴 (CCL/CGA/BCF/SRL)
    已排队: M125/M126 (MLay×DCA/DCM), M130 (MFP seed123), M131 (MFP×DCM), M122 (MLay seed)
    缺口: 多个独立机制均收敛于 ~0.501-0.502 平台, 且 M95=0.5020 已归因 seed 红利
          → 单一机制无法破顶, 依赖"正交机制组合"。{MFP, MLay, DCM} 三角两两组合
            中 MFP×MLay 是唯一未测格。
  - 触发原因: waiting=5 ≤ 可用卡数5 (集群容量 server-4 2槽 + server-6 3槽 = 5),
    深度不足 (要求 waiting ≥ 容量+1=6) → 自主补设计
  - 这批变体在故事线中的角色: 验证组合假设 — MFP (encoder 特征完整性 aux loss) ×
    MLay (2层 context 写回深度) 两条 encoder-side 正交有效轴叠加能否破 ~0.501 平台。

## 3. Analysis & Direction（方向分析）
  ### 3.1 哪些方向有效（> baseline）
    - context 回写 (A1): 0.5012, γ=+0.0118 (核心, 已确认)
    - decoder-access 轴 DCM: 0.5010, γ=+0.0116 (方向①最优, qla 共享通路)
    - 多层注入 MLay: 0.5010, γ=+0.0116 (方向②, 2层)
    - MFP aux loss: 0.5020, γ=+0.0126 (机制性待 seed 判定)
  ### 3.2 哪些方向失败（< baseline 或持平）
    - encoder-side token 质量轴: CCL=0.4890, CGA=0.4926, BCF=0.4926, SRL=0.4912 (掉点)
    - CSORT 跨 scale: 3/4 seed 负, 轴关闭
    - DCA (decoder 独立分支): 0.4970 < DCM 0.5010, decoder-access 内对比淘汰
  ### 3.3 哪些尚未消融
    - MFP × MLay 组合: 从未验证 — 本次设计 ({MFP, MLay, DCM} 三角唯一缺格)
    - MFP × detail: 低优先 (detail=0.5003 最弱, detail×DCA=0.4870 硬失败)
  ### 3.4 结论
    - 平台 ~0.501-0.502 由 seed-1999 决定 (M95 已证伪), 单轴机制已到天花板。
    - 破顶路径 = 正交机制组合。已排队 MFP×DCM (M131) 与 MLay×DCA/DCM (M125/M126)
      覆盖 decoder 访问轴; MFP×MLay 补全 encoder 侧内容×深度格 — 两轴都是各自
      轴的最优实现且从未同时激活, 是当前未测格中机制上最可辩护的一个。

## 7. Risk Assessment（风险评估）
  - 代码风险: 极低。纯包复制 + config 参数变更 (cluster_att_num_layers 1→2),
    无逻辑改动。MFP 已在 M119 跑通, MLay 已在 M86 跑通, 组合不引入新算子。
    唯一注意点: mfp_loss 聚合是各层平均 (dec.py:520-521), 2层不会翻倍 — 已核实。
  - 资源风险: 低。与 MFP 相同显存/FLOPs 量级 (2层 cluster attn 增加的计算量
    与 MLay 相同, MLay 已跑通), 满足 FLOPs ≤ 10G 约束。
  - 数据风险: 无。同一 ScanRefer 数据。
  - 失败回退: 依赖 M129/M130 (MFP seed 判定) — 若 MFP 被判 seed 红利 (同 CSORT),
    M132 撤回 (移出 queue.json) 不跑; 若 crash 3 次 → 放弃标记 question,
    聚焦 decoder-access 叠加结果 (M125/M126/M131)。
