## 3. Analysis & Direction（方向分析）
  ### 3.1 哪些方向有效（> baseline）
    - Context 注入 (champion): best=0.5012, γ=+0.0118 vs baseline, 机制: 多尺度 cluster bank→inst_feats 回写
    - Orthogonality Regularization (ORT): best=0.5005, γ=+0.0111 vs baseline, 机制: cluster token 正交约束增加 diversity
    - Detail message: best=0.5003, γ=+0.0109 vs baseline, 机制: 点-簇残差消息替代 context
  ### 3.2 哪些方向失败（< baseline 或持平）
    - Hybrid context+detail (M21-HYB): best=0.4898, γ=+0.0004, 组合无协同
    - Cluster Self-Refine (M16-CSR): best=0.4875, γ=-0.0019, 单机制无效
  ### 3.3 哪些尚未消融
    - ORT orth_weight 敏感性: 当前仅测试 0.01, 更强/更弱强度未探索 → P0
    - ORT+detail 组合: M24-ORT-D running → 等待结果
    - refine mode: M25-REF waiting → 等待运行
  ### 3.4 结论
    - ORT 机制已证明有效(0.5005)但未超越 champion(0.5012)
    - orth_weight=0.01 是当前唯一测试值, 其敏感性完全未知
    - 探索 orth_weight∈{0.05, 0.001} 可建立 ORT 强度-性能曲线, 确定最优范围
    - 均为 config-only 变更(复用 ORT 模型包), 零代码风险
