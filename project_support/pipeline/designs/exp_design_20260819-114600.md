## 3. Analysis & Direction（方向分析）
  ### 3.1 哪些方向有效（> baseline）
    - CTF+HCG: best=0.5012, γ=+0.0118, 核心架构
    - detail message: best=0.5003, γ=+0.0109, 增量有限
    - ORT (单独): best=0.5005, γ=+0.0111, 组合有害
  ### 3.2 哪些方向失败
    - CSORT: 3/4 seed 负增益, 轴关闭
    - multi-layer: M96=0.4940, 退化
    - gate/residual/CCP: 全部 < baseline
  ### 3.3 哪些尚未探索
    - cluster token 对比学习: 从未尝试 (新 loss 函数)
    - cluster 间空间图: 从未尝试 (新 GNN 模块)
    - 双向 context flow: 从未尝试 (新 attention 方向)
    - 自监督 mask 重建: 从未尝试 (新 auxiliary loss)
  ### 3.4 结论
    - CTF-HCG 到 ~0.50 天花板, 需要正交的新机制
    - 选择 ccl 和 cga: 一个改训练信号 (对比 loss), 一个改信息聚合 (图结构)
    - bcf 和 mfp 留到下一轮 (需要更多代码改动)
