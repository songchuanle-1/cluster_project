# Experiment Design - PCE / cluster_project

## 1. Motivation
cluster: 面向 ScanRefer 三维语言定位，回归用户最初的点云特征更新主线，研究不同层级承担不同注意力/信息交互作用的轻量结构机制，目标 mIoU ≥ 0.51。核心路径是分层信息交互真实更新点云/超点 inst_feats，再与 query 特征共同生成 mask；不能把仅修改监督损失、沿用已有层级骨架或无效路由计算称为该主线创新。以多尺度 context-only 和 M95 为既有对照，先诊断层级互补性、局部细节及跨层信息是否真正进入 mask 特征，再依据证据选择一个可推导、可证伪的结构机制。监督与关系绑定仅作辅助诊断/匹配对照，不再取代主线。覆盖机制对照、泛化稳健性和同口径效率验证；已有收益不证明新的分层注意力有效，也不自动重开历史失败或禁止的路线。

## 2. Current Best Results
Historical M95 .5020; baseline .4894; target .5100; gap .0080. M203/FLE and M204/CPA are terminal and not reopened. Frozen M95 epoch16 used for diagnosis is not a new trained candidate.

## 3. Analysis And Direction
Fine-leaf FLE excludes cross-leaf donors. PCE tests a distinct geometry-only contact path; source differentiation and native causal masks/gradients are observed, task improvement is not. Prior selected-mask feature contrast/anchor relation/BCCA supervision are not resumed.

## 4. Experiment Plan
Let E be all co-occupied/six-face voxel superpoint contacts and E_cross={(i,j) in E:leaf(i)!=leaf(j)}. For each existing head, a_ij=softmax_j(x_i^T x_j/sqrt(d)); fine_i=sum_j a_ij*x_j when cross-leaf donors exist, otherwise the original fine FFN bank value. Preserve middle/coarse readback, original scale fusion/projection/normalization and outer inst_feats update. Final native mask uses query and the updated inst_feats. No new gate, large QKV projection, residual branch, top-k/radius/seed/schedule sweep.
Source graph identity, row relabeling and deleted-contact controls; native fixed-query masks with original selected query versus one-position donor-value rotation; original native criterion backwards; independent-package integration. All fixed controls remain 1e-6.

## 6. Implementation Checklist
Independent _pce package and unique config exist; eight Python files parse and no cross-variant import is used. Independent native Network/criterion forward/backward ran without forward-replacement hooks. No optimizer step, commit, push, production sync, admission or training. Uniform total FLOPs, bs1 warmup20/repeat100 efficiency and full-source numerical controls remain pending.

## 7. Risk Assessment
Two scenes/eight unique expressions only; mixed task errors, no generalization claim. Binary same-label contacts mostly background, not proof of same-instance donors. CPU graph construction/inference cost and autograd E*C storage require uniform tests; sparse observed E is not a worst-case bound. Work O(V+P+E+E_cross*C), storage O(V+P+E+E_cross*C) for this unoptimized autograd implementation. Degenerate/coincident-donor and full-source controls remain risks. Native full-loss gradient and finite parameters establish feasibility, not efficacy. Post-training comparison, if admitted: fixed ScanRefer split, M95/baseline, scene-cluster uncertainty, preregistered boundary/error subsets and original Pareto rule; no test-selected tuning.

## 8. Smell And Literature Check
New directed information path is demonstrated; zero new learned parameters is not a numerical-only tweak. Existing nhead/scale/schedule remain unchanged. Basic graph attention/contact adjacency must not be called new research by themselves. Complete original-paper whole-mechanism comparison and novelty are unverified; preserve that limitation.
