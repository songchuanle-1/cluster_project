## 1. Motivation（为什么设计这批实验）
  - 项目动机（直接引用 goal.json description）: "cluster: 多尺度 cluster context
    机制 — cluster bank 聚合点云特征→cluster_attn 把多尺度 context 回写更新
    inst_feats→提升定位精度。注: 原'聚类路由'假设已被证伪(routing 生效反降点),
    收益来自 context 而非 routing。目标 mIoU ≥ 0.51"
  - 故事线当前状态:
    已验证: context 回写有效 (+0.0118); 结构变换全灭 (C2C/CSF/FLM/pool/TrueRoute);
            通路组合不叠加 (M125/M126/M134/M136/M138); 多层对 HCG 有害
            (M96-CTF-HCG-2LAY=0.4940 < 1层 0.5012); 判别性 loss 轴饱和
            (M140-CLICA=0.4970 < base 0.5012)。
    唯一被证明有效且尚有扩展空间的机制: **champion 的 cross-scale orthogonality
            (CSORT, M95=0.5020)** — 只对相邻尺度对去相关, 非相邻对 (8↔256) 未测。
  - 触发原因: M141 推送后 waiting=4 < 容量4+1=5 → 自主补设计 1 个
  - 这批变体在故事线中的角色: **扩展获胜机制** — 把 CSORT 的跨尺度去相关从
    相邻对扩展到全尺度对 (含 8↔256), 单变量在 champion base 上, 与 loss 监督轴
    (M141-144) 正交, 独立下注破 0.5020 平台。

## 3. Analysis & Direction（方向分析）
  ### 3.1 哪些方向有效（> baseline）
    - context 回写 (A1): 0.5012, γ=+0.0118 (核心, 已确认)
    - **cross-scale orthogonality (CSORT): 0.5020, 破 0.5012 平台 (champion)**
    - legacy 2 层 (MLay): 0.5010, γ=+0.0116
    - detail message (D1): 0.5003, γ=+0.0109
  ### 3.2 哪些方向失败（< baseline 或持平）
    - 结构变换: C2C/CSF/FLM/pool/TrueRoute 全灭
    - 多层注入 HCG: M96-CTF-HCG-2LAY=0.4940 (HCG@2 有害; legacy@2 有效)
    - 通路组合: M125/M126/M134/M136/M138 全不叠加
    - 判别性 loss: M140-CLICA=0.4970 < base 0.5012
  ### 3.3 哪些尚未消融
    - **champion CSORT 全尺度对去相关 (8↔256)**: 未测 (本设计 M145)
    - cluster token 跨尺度一致 (CSIC): M141 running
    - CLICA×CSIC 双监督 (M142) / OBJG (M143) / LQA (M144): queued
    - legacy@2 组合轴: M139 running (M138 修正版)
  ### 3.4 结论
    - 四轴 (结构/组合/多层/判别 loss) 已灭。唯一被证明有效且未扩展的机制是
      champion 的 cross-scale orth。直接扩展获胜机制 (相邻→全尺度对) 是当前
      最高概率的破平台赌注, 且与 loss 监督轴正交, 不占用正在检验的方向。

## 7. Risk Assessment（风险评估）
  - 代码风险: 中。新 loss 逻辑含子簇映射组合 (256→8), 需正确构造逆映射避免越界
    (M140 前车: cluster_ids 组合映射 IndexError)。py_compile + 结构校验; 若 crash
    → Phase 3b 自修复预算 ≤3 次。
  - 资源风险: 低。新增 loss 仅 (8×256) 对级 abs-cosine, 显存/FLOPs 增量可忽略;
    ≤10G 约束满足。
  - 数据风险: 无。复用现有 cluster_feats_list + child_cluster_maps。
  - 失败回退: 若 M145 增益 <0.002 或 ≤ champion → orth 扩展轴停止, 作为 CSORT
    边界消融证据记录; 若与 loss 轴四维全部不破 → 范式级 question, 暂停自主设计。
