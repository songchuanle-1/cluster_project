## 3. Analysis & Direction（方向分析）
  ### 3.1 哪些方向有效（> baseline）
    - context 回读 (champion/DRP): +0.0118 vs baseline, 确认有效
    - token 正则 (ORT): 0.5005, 接近但未破 ceiling
    - token 精炼 (CTF): 0.4995, token 质量有帮助但非瓶颈
  ### 3.2 哪些方向失败（< baseline 或持平）
    - 读回形式: additive 系全收敛 0.5012 (DRP/ORT/CTF/NCR)
    - 调制类: FILM(0.4936)/FLM(0.4865) 死胡同
    - 交互类: C2C(0.4865)/CSF(0.4958) 无益
    - 选择类: NCR(0.4980) 不优于 own-cluster gather
    - 融合类: SWI(0.4970) 无关紧要
    - 聚合池化: max(0.4910)/weighted(0.4890) 差于 mean
  ### 3.3 哪些尚未消融
    - **dual(mean+max) 池化** — 07-27 设计 (M29) 从未入队/运行 (priority: P0)
    - **级联中间层精炼** — 全新机制 (priority: P0)
    - 多 seed 稳定性 (Phase 2 再做)
  ### 3.4 结论
    - 读回形式批次 (BIL/NLR/DGC) 已在跑, 不需要补充该方向。
    - 聚合质量是唯一未探明的"消息内容"结构方向, 且 M44/M47 分析明确推荐。
    - DCA 与 CCR 覆盖聚合的两个正交子维度 (池化信息量 / 级联噪声), 均为结构性机制,
      无超参扫参, 不触碰 banned[] 任何条款。

## 8. Smell Check (Phase 1.6)

  ### M51-DCA:
  - Smell signals: 无直接命中
    - #1 (params<5K): 131K params (Linear(2C,C) ×2 + LayerNorm), PASS
    - #2 (单算子): 双分支池化(mean+max)+concat+2层MLP = 多元素计算图, 非单一 LayerNorm/Linear/Scaling, PASS
    - #3 (数值分布): 新增双池化信息路径(显著信号), 非纯缩放/归一化, PASS
    - #4 (超参): 无可调超参, PASS
    - #5 (换名绕过): dual(mean+max) 与 banned 的 gate系/语言路由/attnpool 无重叠, PASS
    - #6 (找数值配置): 新聚合计算图, 非同一信息流改数值, PASS
  - 因果机制: "mean 池化只保留簇内分布中心, 边界/显著点特征被平均掉; max 分支显式保留簇内
    最显著信号, concat+投影使 cluster token 同时携带分布与显著信息, 提升 context 对边界点的可区分度。"
  - Verdict: PASS

  ### M52-CCR:
  - Smell signals: 无直接命中
    - #1 (params<5K): 131K params (2层FFN), PASS
    - #2 (单算子): pre-norm FFN + 残差连接插入级联聚合循环 = 新处理路径, 非单算子, PASS
    - #3 (数值分布): 非线性精炼改变信息流(粗层由精炼 token 构建), PASS
    - #4 (超参): 无超参 (FFN hidden=2×d_model 同网络约定), PASS
    - #5 (换名绕过): 与 CTF 位置不同(聚合管线内部 vs 读回前), 非任何 banned 机制, PASS
    - #6 (找数值配置): 新级联精炼路径, PASS
  - 与 M41-CTF 的区别: CTF 在 C2F_ClusterAttn 读回前对已建好的簇 token 做 FFN 精炼(0.4995);
    CCR 在 SharedClusterBank 级联聚合过程中每层池化后精炼, 直接影响 coarse token 的构建 —
    信息流位置不同, 因果不同(减少级联噪声传播 vs 提升最终 token 表达)。
  - 因果机制: "mean 级联聚合逐级放大池化平滑误差, coarse token 由被平均过的噪声特征聚合;
    层间精炼清理信号, 使 coarse token 由更清晰的 fine token 构建, 减少 context 噪声。"
  - Verdict: PASS
