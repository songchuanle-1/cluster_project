## 3. Analysis And Direction
- Full TRAIN denominator36665; previous root-connected1511/two-direct675.
  Do not require a guessed true witness label or modify existing annotations.
- For native support s with count n_s, w_q(s)=n_s sigmoid(m_qs)/sum_s
  n_s sigmoid(m_qs), with w_GT using original criterion GT masks.
- For valid reference pair p, axis e_p and nonoverlapping support bounds a_p,b_p,
  phi_p(s)=((relu(a_p-x_s.e_p)+relu(x_s.e_p-b_p))/(b_p-a_p))^2.
- L_event=min_p relu(E_wq phi_p-E_wGT phi_p). Average available events;
  sum ORIGINAL matched queries and divide by ORIGINAL num_boxes. Unit loss,
  no added coefficient/temperature/seed; final decoder only, no auxiliary edits.
- New information: stored relation events plus native physical reference
  supports couple the entire predicted mask to one candidate pair per event.
  Gradients through w_q reach original decoder/backbone, not detached masks.
- Away from min/relu ties: dE/dm_qs=w_q(s)(phi_p(s)-E)(1-sigmoid(m_qs)).
  Ties/zero excess follow Torch subgradient; do not change thresholds.
- Complexity O(N + S*P + Qpos*S*P); no point-pair attention. P is the actual
  finite reference candidate-pair count, not a tuned top-k.

## 7. Risk Assessment
- SP-majority reference ownership, class-only candidate IDs, absent true
  witnesses and overlap omissions limit semantics. No false-label claim.
- Tiny valid gaps can create large losses; log finite values and paired gradient
  magnitude rather than silently clipping or selecting convenient pairs.
- Runtime CPU geometry adds training overhead; record separately from inference.
- Candidate-local sparse-op patch is synchronous single-GPU only; concurrency
  in one process is not certified. Historical repeat failures remain preserved.
