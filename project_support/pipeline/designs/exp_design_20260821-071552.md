## 1. Motivation（为什么设计这批实验）
  - 项目动机（直接引用 goal.json description）: "cluster: 多尺度 cluster context 机制 —
    cluster bank 聚合点云特征→cluster_attn 把多尺度 context 回写更新 inst_feats→提升
    定位精度。注: 原'聚类路由'假设已被证伪(routing 生效反降点), 收益来自 context 而非
    routing。目标 mIoU ≥ 0.51"
  - 故事线当前状态:
    已验证: 多尺度 context 有效 (+0.0118); CTF+HCG 1层 ~0.501; MLay (2层 legacy) 单 seed
      0.5010; detail 独立有效 (D1=0.5003)
    已证伪: routing / CSORT / ORT / MEMBANK / SRL / QMOD(gate) / CSF/XCA / gate系
    已排队: M115-M119 (encoder-side 机制) + M123-DCA (decoder 专用分支)
    缺口: **decoder 侧从未通过「语言共享通路」直接读到 cluster tokens** —
      M123-DCA 测的是专用分支 (dedicated qca), DCM 测共享通路 (扩展 qla KV),
      两者共同覆盖"writeback 有损瓶颈"假设的完整证据空间
  - 触发原因: 队列深度 waiting=5 < 可用卡数5+1=6; server-4 队列 4 waiting,
    server-6 队列 1 waiting, 需补 1 个新方向
  - 这批变体在故事线中的角色: 验证假设X — "若 writeback 是单通道有损瓶颈,
    decoder 通过任何直接 cluster 访问通道 (专用分支或共享语言通路) 都应破 0.501 平台"

## 3. Analysis & Direction（方向分析）
  ### 3.1 哪些方向有效（> baseline）
    - 多尺度 context 深度 (2层 legacy): M86=0.5010, γ=+0.0116
    - CTF+HCG 1层: M81=0.5012, γ=+0.0118
    - detail message: D1=0.5003, γ=+0.0109
  ### 3.2 哪些方向失败（< baseline 或持平）
    - QMOD (gate 版 decoder query 调制): 0.4930 — gate 实现失败
    - CSORT / ORT / MEMBANK / SRL / CSF / XCA: 均关闭
    - ctf_hcg 模式 2层 (M96=0.4940): 多层注入退化仅限该模式
  ### 3.3 哪些尚未消融
    - **decoder 直连 cluster tokens**: M123-DCA (专用分支) 排队中
    - **decoder 通过共享语言通路读 cluster (DCM)**: 从未尝试 — 扩展 qla KV 记忆
    - MLay seed 稳健性 (M120/M122): 已运行/排队
  ### 3.4 结论
    - 0.501 平台不随 encoder-side 机制变化 → 瓶颈在 writeback→decoder 通路
    - M123-DCA 覆盖"专用分支"证据; M124-DCM 覆盖"共享通路"证据
    - 两个变体信息流路径完全正交, 并行运行不冲突; 若 DCA 崩溃, DCM 提供
      同一假设的第二实现兜底 (崩溃独立性)

## 7. Risk Assessment（风险评估）
  - 代码风险: 中低。新 model 包 (复制 DCA) + dec.py 修改 (qla source 扩展)。
    复用现有 CrossAttentionLayer/qla, 无新增模块; cluster_pad 掩码与 encoder 侧
    bank 填充一致 (zeros→pad)。lang_masks 与 cluster_pad 维度对齐即可 concat
  - 资源风险: 低。qla KV 长度从 lang_len (~78) 增到 lang_len+ΣK (328), 注意力
    计算量微增; FLOPs 增量 <3%, server-4 RTX5090 显存充足
  - 数据风险: 无。同一 ScanRefer 数据
  - 失败回退: 如 crash 3 次 → 放弃 DCM, 标记 question; 资源回已排队 M115-M119
    批次 + M123-DCA
