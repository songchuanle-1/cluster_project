## 1. Motivation（为什么设计这批实验）
  - 项目动机（直接引用 goal.json description）: "cluster: 多尺度 cluster context
    机制 — cluster bank 聚合点云特征→cluster_attn 把多尺度 context 回写更新
    inst_feats→提升定位精度。注: 原'聚类路由'假设已被证伪(routing 生效反降点),
    收益来自 context 而非 routing。目标 mIoU ≥ 0.51"
  - 故事线当前状态:
    已验证: context 回写有效 (+0.0118); M86 隔离出多尺度 context 深度是核心收益;
    组合线 (architecture×loss / loss×decoder-access) 多例不叠加; 写回正交轴
    (M150-OWC/M151-ODW) 软硬双证伪关闭; loss 监督轴 (M140-144) 五连败关闭;
    **特征池化统计量轴 (mean/max/var/dual/weighted) 已封顶**。
    M134-DUAL 诊断: "瓶颈在 cluster token 信息量, 不在通路数量"。
    未验证: **cluster token 的几何锚定** — 分划器已计算簇 centroid 但
    build_cluster_feats 只聚合特征均值, 位置信息被丢弃。
  - 触发原因: 队列深度 waiting=4 < 容量4+1=5 → 自主补设计 2 个
    (server-4 队尾 1 + server-6 队尾 1, 平衡两机)
  - 这批变体在故事线中的角色: **验证假设Z7 (cluster token 几何锚定)** — M134
    "token 信息量瓶颈"在 loss 监督轴关闭后的最后一个结构性检验: 注入被丢弃的
    位置模态 (centroid/radius), 而非二次变换已聚合的特征。

## 3. Analysis & Direction（方向分析）
  ### 3.1 哪些方向有效（> baseline）
    - context 回写 (A1): 0.5012, γ=+0.0118 (核心, 已确认)
    - CSORT (champion M95): 0.5020 — 唯一破平台机制, seed 脆弱但对称项 load-bearing
  ### 3.2 哪些方向失败（< baseline 或持平）
    - 交互/注意力/loss 监督: 全灭 (C2C/CCP/CSF/FLM/pool + M140-144 五连败)
    - 写回正交轴: M150-OWC=0.4920 / M151-ODW=0.4970 — 软硬双证伪 (本 tick 关闭)
    - 非对称去相关: M149-SG=0.4940 — 对称项是收益负载 (本 tick 关闭)
    - 组合线: M146/147/148/134 — 多例不叠加
    - 特征池化统计量: M42-WCA/M51-DCA/M53-VAC/CMX — 轴封顶
  ### 3.3 哪些尚未消融
    - **cluster token 几何锚定 (centroid/radius 注入)** — 分划器算 centroid 却丢弃,
      从未注入 token (本设计 M159/M160) ← M134 诊断的结构性解
    - CSORT 操作数: 在队 M155-RF (精炼) / M157-PMD (receiver) 覆盖中
  ### 3.4 结论
    - 0.5020 平台前所有"对已聚合特征做二次变换"的路径已关闭。剩余唯一结构性
      信息增量是**注入被丢弃的独立模态 (位置)**。点级有 posA 位置编码, 但
      cluster token 级没有任何空间锚 — 这是架构上缺失的一环。
    - 分划器 cluster_layer 已计算 center = aggregate_cluster(pos, cid) (用于
      FPS), 实现零新增计算, 只需把 centroid + radius 投影注入 token。
    - M160 控制组隔离"几何内容" vs "结构注入容量", 防 M145-ALL 式误读。

## 8. Smell Check (Phase 1.6)
  - M159-GEO: 气味检查 —
    1) 参数增量 1K (Linear 4→C) **但新计算图**: 注入被丢弃的独立模态 (位置),
       非"对已聚合特征加 Linear/scaling"。信息路径: sp_pos → 级联 centroid/radius
       → 投影 → token。这是新的信息交互 (token 首次携带空间锚), 不是"在 X 处
       加一个 LayerNorm/Linear 微调"。
    2) 验证的是**因果假设** "cluster token 缺几何锚定 → 写回缺空间基准 →
       定位受限" (M134 诊断的直接检验), 失败结论是机制层面 ("几何非瓶颈"),
       不是"这个值不合适"。
    3) **超参有依据**: 无新增超参 (centroid/radius 来自分划器既有计算, 归一化
       用半径中位数常数); 无"先试 0.1"。
    4) 不是数值分布变更: 注入新模态, 不改现有特征的归一化/缩放。
    → 无气味信号命中 + 通过三标准 (新计算图 / 零新超参 / 因果机制清晰) → 保留。
    与特征统计量轴 (M42/M51/M53) 的本质区别: 那些是对**已聚合特征**的二次
    变换 (冗余), GEO 注入**独立位置模态** (分划器已算却丢弃)。
  - M160-GEO-SH: 气味 — 控制组 (同 M159 换固定偏移重排), 零新增参数/超参,
    验证"GEO 收益几何内容驱动 vs 结构注入容量"。与 M158-PMD-SH / A4-shuffle
    控制组同构 (均已被接受)。→ 无气味信号 + 通过三标准 → 保留。

## 9. Banned/Constraints 校验

    - 禁单变体改 schedule: epochs=50/max_iters=70 不变 ✓
    - Phase1 禁调参: 非参数微调, 非数值分布变更, 非超参扫参; 是结构性新模态

    - 分支停止 <0.002: 1999 首筛, 不达标即停 ✓
    - 收敛定义/结构首筛 seed 1999: seed=1999 ✓

      multi/prune/nomask/3-4-6层注入/大型QKV/true_route ✓
    - **非 residual 系**: 残差加到 token 是 CTF FFN 既有风格 (cf + ffn), 与 banned
      residual 系 (message_type=residual, B5/E4) 不同 — 不改变 message 构造 ✓
    - **与特征统计量轴区分**: banned "agg/multi" 指对已聚合特征的注意力/统计
      变换; GEO 注入独立位置模态, 非聚合统计量 ✓
    - **与 M155-RF 区分**: RF 换 CSORT 操作数 (token→精炼); GEO 换 token 内容
      (加几何) — 操作数 vs 内容, 正交 ✓
    - **与 QMOD/DCM 区分**: 那些是 decoder 侧访问; GEO 是 encoder 侧 cluster
      token 表示增强, 不增加通路 ✓
