超点 → 体素化 → Backbone 处理流程

ScanNet 点云特征提取管线  |  (N,3) → (V,32) → (B*M, 32)

1
超点（Superpoint）
🔺 Mesh 分割生成超点
使用 Felzenszwalb 图分割算法 对 3D mesh 进行分割。根据面片法线夹角和凸凹性计算边权重，自适应合并相似面片。
segmentator.segment_mesh(vertices, faces) // kThresh=0.01, segMinVerts=20 // 边权重: w = (1 - n₁·n₂)² (凸边)
输入 vertices (N,3) faces (F,3) 输出 superpoint (N,) int
保存为 _refer.pth
🔄 Dataset Transform
随机采样（最多 max_npoint 个点）后，对超点 ID 进行连续重编号，确保 scatter 操作正确。
unique, superpoint = np.unique(superpoint[valid_idxs], return_inverse=True) // unique: 原始 ID (索引 CLIP 特征) // superpoint: 连续 [0, S'-1]
输出 superpoint (N',) unique (S',)
▸ 展开：超点标签生成
sp_ins_label: 多数投票 scatter_mean(ref_lbl.float(), superpoint) > 0.5 // 超过半数的点属于某实例 → 该超点归属该实例
collate_fn 批处理
📦 Collate：批处理偏移
不同 scene 的超点 ID 加上偏移量，确保全局唯一。
superpoint = src_superpoint + superpoint_bias superpoint_bias = superpoint.max().item() + 1
输出 superpoints (B*N,) 全局唯一 [0, ΣS-1] feats (B*N, 6) [RGB, XYZ]
2
体素化（Voxelization）
📐 坐标准备
将原始坐标缩放为整数体素坐标。scale=50 意味着 1 个体素单位 = 2cm。
xyz = xyz_middle * scale // ×50 xyz = xyz - xyz.min(0) // 平移到非负 coord = torch.from_numpy(xyz).long() coords = cat([batch_idx_col, coord], dim=1) // 结果: (N, 4) [batch_idx, x, y, z]
输入 xyz_middle (N,3) float, 米 输出 coords (N,4) long, 体素单位
pointgroup_ops.voxelization_idx
🗂️ 体素化索引
通过哈希表将点映射到体素格子，建立双向映射。mode=4 表示取均值。
voxel_coords, p2v_map, v2p_map = pointgroup_ops.voxelization_idx(coords, B, mode=4) // 遍历每个点 → 查哈希表 → 分配/复用 voxel_idx
voxel_coords (V,4) 非空体素坐标
p2v_map (B*N,) 点→体素 v2p_map (V, max+1) 体素→点列表
pointgroup_ops.voxelization
⚡ 特征体素化 (CUDA)
对每个体素内的所有点特征取均值，由 CUDA kernel 并行执行。
voxel_feats = pointgroup_ops.voxelization(feats, v2p_map) // V_v = (1/|P_v|) × Σ F_i for i ∈ P_v
输入 feats (B*N, 6) 输出 voxel_feats (V, 6)
SparseConvTensor
🧊 构建稀疏张量
只存储非空体素，大幅减少计算量。spatial_shape 根据数据自适应计算。
input = spconv.SparseConvTensor(voxel_feats, voxel_coords.int(), spatial_shape, batch_size)
SparseConvTensor (V, 6) 稀疏, 仅非空体素
3
Backbone（稀疏卷积 U-Net）
📥 输入卷积
SubMConv3d（子流形稀疏卷积）：只在已激活体素上计算，不改变稀疏结构。
input_conv = SubMConv3d(6 → 32, kernel=3, padding=1)
(V, 6) → (V, 32)
UBlock U-Net
🏗️ UBlock 编码器-解码器（5 层递归）
递归 U-Net 结构，5 层通道数 32→64→96→128→160，每层含 2 个 ResidualBlock + skip connection。
↓ 32 Level 1: 2× ResBlock → SparseConv3d(32→64, s=2)
↓ 64 Level 2: 2× ResBlock → SparseConv3d(64→96, s=2)
↓ 96 Level 3: 2× ResBlock → SparseConv3d(96→128, s=2)
↓ 128 Level 4: 2× ResBlock → SparseConv3d(128→160, s=2)
■ 160 Level 5 (Bottleneck): 2× ResBlock
↑ 128 SparseInverseConv3d(160→128) + cat(skip) → 2× ResBlock
↑ 96 SparseInverseConv3d(128→96) + cat(skip) → 2× ResBlock
↑ 64 SparseInverseConv3d(96→64) + cat(skip) → 2× ResBlock
↑ 32 SparseInverseConv3d(64→32) + cat(skip) → 2× ResBlock
▸ 展开：ResidualBlock 结构
conv_branch: BN → ReLU → SubMConv3d(3×3) → BN → ReLU → SubMConv3d(3×3) i_branch: Identity (通道相同) 或 SubMConv3d(1×1) (通道不同) output = conv_branch(input) + i_branch(input) // 残差连接
SubMConv3d：子流形稀疏卷积，只在已激活体素上计算，不膨胀激活区域
SparseConv3d(s=2)：标准稀疏卷积 + 下采样
SparseInverseConv3d：转置稀疏卷积，上采样恢复分辨率
(V, 32) → UBlock → (V, 32) 分辨率不变
output_layer: BN + ReLU
🔙 体素 → 点 映射
通过 p2v_map 将体素特征广播回每个点。
x = x.features[p2v_map.long()] // p2v_map[i] = 点 i 所属的体素索引 // 每个点获得其所在体素的特征
(V, 32) → (B*N, 32)
scatter_mean 超点池化
🎯 超点均值池化
对同一超点内的所有点特征取均值，得到最终的超点特征 sp_feats。
sp_feats = scatter_mean(x, superpoints, dim=0) sp_coords_float = scatter_mean(coords_float, superpoints, dim=0) // f_s = (1/|P_s|) × Σ f_i for i ∈ superpoint_s
(B*N, 32) → (B*M, 32) sp_feats (B*N, 3) → (B*M, 3) sp_coords
expand + FPS → DEC
✅ 输出：超点特征
sp_feats 经过 FPS 采样 512 个种子超点后，传入 DEC 解码器生成 inst_feat。
sp_feats (B*M, 32) fps_seed_sp (B, 512) feats_2d (B*M, 1024) CLIP
